1. Context And Objective

当前项目目标是在节点级图学习/图标签噪声场景中，探索 Granular Ball Computing 是否可以作为一种有效的去噪机制。这里的任务不是图对比学习论文最终版，而是先在 NoisyGL 框架下，把普通 GCN 加入普通粒球模块，验证 ordinary granular ball 是否能提供比 noisy-label CE 更好的训练信号。

本轮方法名为 OrginGB-GCN。这里的 “OrginGB” 沿用用户文件命名，含义是 ordinary granular ball，不是 graph-aware GB，也不是之前失败较多的 GAGB。

核心问题

  • 普通粒球能否在 GCN warmup embedding 空间中形成对标签噪声有用的局部区域？
  • ball-level soft target 是否能修正 noisy labels，或至少降低噪声样本的训练伤害？
  • 这种收益是否超过随机大小匹配分组，还是只是普通分组/soft-label 正则的效果？

当前 v1 结论

当前 v1 已能运行，但 Cora uniform 0.4 seed=3000 smoke test 不支持直接进入正式三数据集 5-seed。原因是 best checkpoint 来自 warmup 阶段，GB 阶段没有超过普通 GCN；真实 GB 的 NCR 很低，说明当前 ball-level soft target 尚未形成可靠纠错机制。

2. Prior Experiment Chain

2.1 为什么暂停 GAGB

前期 GAGB 经验显示，直接把 same-ball membership 用作 hard semantic relation 风险很高。强制同球同类、hard positive、hard relabel 或过强 target 更新都容易引发分类边界间接移动。局部 smoothing 在 Cora 有一些信号，但 CiteSeer 不稳；而且很多收益可能被随机分组、kmeans 或 top-k 近邻解释。

2.2 从经验文档继承的硬约束

经验 本实验如何吸收

4. 原始 OrginGB-GCN 方案

原始 OrginGB-GCN.html 的核心定位是：静态普通粒球 + 软标签修正 + 轻量样本降权。它不是最终论文方法，而是验证 ordinary GB 是否能作为图标签噪声任务中的 weak denoising prior。

4.1 原始设想中的流程

  1. 先用普通 GCN 在 noisy train labels 上 warmup，例如 30 epoch。
  2. 从倒数第二层取 hidden embedding H。
  3. 只在 embedding 空间构造 ordinary granular balls，不用图拓扑、不用 clean label、不用 val/test label。
  4. 球内同时统计 warmup GCN 平均预测分布 pbar_B 和 noisy train label 分布 yhat_B。
  5. 生成球级 soft target q_B。
  6. 对每个 train node 做轻量 target mixing 和 sample reweighting。

4.2 原始公式

q_B = normalize((1 - eta_B) * pbar_B + eta_B * yhat_B)
target_i = (1 - alpha_i) * onehot(noisy_y_i) + alpha_i * q_B
weight_i = 1 - gamma * alpha_i

原始建议：alpha_max=0.5、gamma=0.5、eta_max=0.4、min_train_per_ball=2、full_train_per_ball=4、静态构球、不动态刷新。

4.3 原始方案中明确不做的事

  • 不直接替换 noisy label。
  • 不把同球节点当同类。
  • 不做 hard positive / prototype pulling。
  • 不改图结构。
  • 不改 split。
  • 不引入 PPR、K-hop 或 graph-aware ball。

5. 当前真实实现

当前实现已经落在 NoisyGL 中，包含两个方法： orgingb_gcn orgingb_gcn_random

5.1 文件与入口

文件 作用
predictor/OrginGB_GCN_Predictor.py 实现 warmup、构球、soft target、weighted soft CE、diagnostics CSV。
utils/ordinary_gb.py 实现 ordinary GB 构造和 random-size-matched assignment。
utils/soft_targets.py 实现 q_B、alpha_i、target_i、weight_i 和 NCR/CDR/AUROC。
predictor/module/GNNs.py 为 GCN 增加 forward_with_hidden()，原 forward() 仍只返回 logits。
single_exp.py, total_exp.py 注册 orgingb_gcn 和 orgingb_gcn_random。
config/orgingb_gcn/*, config/orgingb_gcn_random/* 提供 Cora/CiteSeer/PubMed 配置。

5.2 当前构球算法

Input: hidden embeddings H from warmup GCN
1. Convert H to numpy float32.
2. L2 normalize all node embeddings.
3. Start from one ball containing all nodes.
4. Repeatedly choose splittable balls with large average distance.
5. Split a candidate ball by KMeans(n_clusters=2, n_init=10).
6. Reject split if either child is smaller than min_ball_size.
7. Accept split only if weighted average distance decreases by at least split_improvement.
8. Stop when max_balls is reached or no split is accepted.
9. Return node-to-ball assignment and ball stats.

默认自适应参数：

  • max_balls = min(64, max(8, train_count // 3))
  • min_ball_size = max(32, ceil(num_nodes / max_balls))
  • split_improvement = 0.05

5.3 当前 soft target 真实公式

当前实现和原始设计一致地计算 pbar_B 和 yhat_B，但具体的 confidence/alpha 定义如下。

coverage_B = 0, if |T_B| < min_train_per_ball; else min(1, |T_B| / full_train_per_ball)
eta_B = eta_max * coverage_B
q_B = normalize((1 - eta_B) * pbar_B + eta_B * yhat_B)
quality_B = coverage_B * 0.5 * (max(yhat_B) + max(pbar_B))
alpha_i = clip(alpha_max * quality_B * (1 - q_B[noisy_y_i]), 0, alpha_max)
target_i = (1 - alpha_i) * onehot(noisy_y_i) + alpha_i * q_B
weight_i = max(1 - gamma * alpha_i, 1e-6)

注意：当前 alpha_i 只让 soft distribution 改变；在 smoke 中 target_argmax_changed_ratio=0，说明 target 的 argmax 没有被改掉。这是一个重要诊断信号：当前方法更多是 soft regularization，而不是真正纠正 label argmax。

5.4 当前训练流程

  1. 同一个 GCN 从 epoch 1 开始训练。
  2. epoch 1-30 使用 noisy CE warmup。
  3. epoch 30 后从当前模型取 hidden 和 logits，构造静态 GB targets。
  4. epoch 31-200 使用 weighted soft-label CE。
  5. 全程用 NoisyGL 的 validation metric 选择 best checkpoint，不强制使用 GB 阶段 checkpoint。
  6. 记录 best_epoch 和 best_phase，用于判断最终性能来自 warmup 还是 GB 阶段。

5.5 Random-size-matched control

orgingb_gcn_random 先构造真实 ordinary GB，保留真实 ball size distribution，然后随机打乱节点 assignment，再重新计算 q_B、alpha_i 和 loss。该控制用于排除“只要有分组或 soft regularization 就有效”的伪贡献。

6. Clean-Label And Data-Leakage Boundary

  • 构球只使用 GCN hidden embedding，不使用 clean labels。
  • q_B 只使用 warmup prediction 和 train nodes 的 noisy labels。
  • validation/test labels 不参与构球、target 构造或训练。
  • clean labels 只用于 test evaluation 和诊断指标 NCR/CDR/AUROC。
  • train/validation/test split 保持 NoisyGL 原始设置。
当前实现没有把 clean labels 用于训练目标或构球，因此从设计上没有 clean-label leakage。

9. Metrics And Definitions

metric definition why it matters
test acc 最终 best checkpoint 在 clean test labels 上的准确率。 主性能指标。
best_epoch / best_phase 验证集 metric 选出的最佳 epoch 及其阶段：warmup 或 gb。 判断收益是否真的来自 GB 阶段。
alpha_mean / alpha_max train nodes 上 target mixing 强度的均值/最大值。 判断模块是否实际介入，以及介入强弱。
target_changed_ratio alpha_i > 0 的 train node 比例。 衡量 soft distribution 是否被改变。
target_argmax_changed_ratio soft target argmax 是否不同于 noisy label 的比例。 衡量是否发生“实际标签方向改变”。当前 smoke 为 0。
NCR noisy train nodes 中，ball target argmax 等于 clean label 的比例。 衡量潜在纠错能力；clean label 仅用于诊断。
CDR clean train nodes 中，ball target argmax 不等于 clean label 的比例。 衡量误伤风险。
suspicion AUROC 用 1 - warmup_conf * q_B[noisy_y] 区分 noisy/clean train nodes 的 AUROC。 衡量粒球信号能否识别可疑噪声。

11.2 诊断解释

  • 不是实现崩溃：训练无 NaN/OOM，GPU 正常，单测和编译检查通过。
  • 不是 GB 完全没信号：suspicion AUROC=0.6492，说明真实 GB 对噪声识别有一定弱排序能力。
  • 但没有形成纠错：NCR=0.0208，target_argmax_changed_ratio=0，说明 soft target 没有实际把 noisy label 推向 clean label。
  • GB 阶段没有提升验证集：best_phase=warmup，说明后续 soft-label CE 没有提供更好的 validation checkpoint。
  • random control 暴露风险：random 的 CDR=0.5870，说明错误分组会严重误伤 clean labels；所以必须加强 gating。

12. Supported Conclusions

  • 当前 v1 实现可以作为代码基础继续迭代，方法入口、配置、诊断和 random control 都已具备。
  • 当前普通 GB soft target 的干预方式没有在 Cora uniform 0.4 seed=3000 上超过 GCN。
  • 当前结果不支持直接进入三数据集正式 5-seed，因为 smoke test 已触发失败条件。
  • 真实 GB 的 suspicion AUROC 高于 random control，说明普通 GB 可能包含弱噪声排序信号。
  • random-size-matched 控制非常必要，因为随机分组会造成明显 CDR，证明错误 membership 的伤害很大。

13. Unsupported Or Still-Hypothetical Claims

  • 不能说 ordinary GB 已经证明有去噪效果。
  • 不能说 same-ball membership 对应语义同类。
  • 不能说 GB 阶段提升了 GCN，因为 best checkpoint 来自 warmup。
  • 不能说当前方法缩小了与 RNCGLN 的差距。
  • 不能说 PubMed 上会有效，因为 PubMed 尚未跑 OrginGB-GCN。
  • 不能说 target mixing 策略正确，因为当前 target argmax 没有改变，NCR 也很低。

14. Missing Information / Residual Risk

  • 当前只有 Cora uniform 0.4 seed=3000 smoke，没有 5-seed。
  • 没有系统调参 alpha_max、eta_max、coverage gate、entropy gate。
  • 没有记录 ball-level noisy entropy、clean purity、class balance 等更细粒度诊断。
  • 没有检查 GB 阶段每个 epoch 的 delta 是否短暂超过 warmup 后又回落。
  • 没有 pred-only / label-only 消融，无法判断 pbar_B 和 yhat_B 谁在主导。
  • 没有 graph-aware GB，因此不能评价拓扑信息是否是必要条件。

15. Questions For GPT

请让 GPT 围绕这些问题深度思考，而不是直接写一个新模型名：

  1. 当前 v1 为什么能产生 AUROC=0.6492 的弱噪声排序信号，却不能转化成 test accuracy 提升？
  2. target_argmax_changed_ratio=0 是否说明 alpha 过弱，还是说明 q_B 本身与 noisy label 方向高度一致？
  3. NCR 低、CDR 低的真实 GB，和 NCR 略高但 CDR 极高的 random control，分别说明什么？
  4. 下一版应该先增强纠错强度，还是先增强 gating，避免误伤？
  5. 应该如何设计 ball-level confidence：entropy、train coverage、prediction agreement、node-center distance、neighbor consistency 哪个最优先？
  6. 是否应该只对 high-suspicion nodes 启用 target mixing，而不是几乎所有 train nodes 都有 alpha？
  7. 是否应该把 q_B 作为辅助 KL/consistency loss，而不是直接混入 supervised target？
  8. 是否应该把 ordinary GB 只用于样本权重，而暂时不用于 soft target？
  9. 在保持 ordinary GB 不引入图拓扑的前提下，最小机制修正是什么？
  10. 如果 ordinary GB v2 仍然失败，什么证据足以说明必须进入 graph-aware GB？

原始 OrginGB-GCN 设计：
- 目标：静态普通粒球 + 软标签修正 + 轻量样本降权。
- 不是 hard relabel，不把 same-ball 节点当同类，不做 prototype pulling，不改图结构。
- Warmup GCN 30 epoch 后，从倒数第二层取 hidden embedding H。
- 在 L2-normalized H 上构 ordinary granular balls。
- 对每个球 B，计算：
  pbar_B = warmup GCN 在球内节点上的平均预测分布
  yhat_B = 球内 train nodes 的 noisy label 分布，加全局 prior 平滑
  q_B = normalize((1 - eta_B) * pbar_B + eta_B * yhat_B)
- 对 train node i：
  target_i = (1 - alpha_i) * onehot(noisy_y_i) + alpha_i * q_B
  weight_i = 1 - gamma * alpha_i
- 默认参数：warmup_epochs=30, alpha_max=0.5, gamma=0.5, eta_max=0.4, min_train_per_ball=2, full_train_per_ball=4。

当前真实实现：
- 方法入口：orgingb_gcn 和 orgingb_gcn_random。
- orgingb_gcn_random 保留真实粒球的 size distribution，但随机打乱节点 assignment 后重算 q_B/alpha/weight。
- 构球算法：
  1. 从 warmup GCN 获取 hidden embedding。
  2. L2 normalize。
  3. 从一个包含所有节点的大球开始。
  4. 对可分球使用 KMeans(n_clusters=2, n_init=10) 二分。
  5. 子球小于 min_ball_size 则拒绝。
  6. weighted average distance 至少下降 split_improvement=0.05 才接受。
  7. 默认 max_balls=min(64, max(8, train_count//3))。
  8. 默认 min_ball_size=max(32, ceil(num_nodes/max_balls))。
- 当前 soft target：
  coverage_B = 0 if |T_B| < min_train_per_ball else min(1, |T_B| / full_train_per_ball)
  eta_B = eta_max * coverage_B
  q_B = normalize((1 - eta_B) * pbar_B + eta_B * yhat_B)
  quality_B = coverage_B * 0.5 * (max(yhat_B) + max(pbar_B))
  alpha_i = clip(alpha_max * quality_B * (1 - q_B[noisy_y_i]), 0, alpha_max)
  target_i = (1 - alpha_i) * onehot(noisy_y_i) + alpha_i * q_B
  weight_i = max(1 - gamma * alpha_i, 1e-6)
- 训练：
  epoch 1-30 使用 noisy CE warmup。
  epoch 31-200 使用 weighted soft-label CE。
  全程按 validation metric 选择 best checkpoint，并记录 best_phase。

重要解释：
- 当前 v1 没有 NaN/OOM，GPU 正常，单元测试、py_compile 和 diff check 均通过。
- 真实 GB 的 suspicion AUROC=0.6492，高于 random 的 0.5444，说明它可能有弱噪声排序信号。
- 但 orgingb_gcn 的 best checkpoint 来自 warmup epoch 6，不是 GB 阶段。
- target_argmax_changed_ratio=0，说明 soft target 虽然几乎都被轻微改变，但没有实际改变任何 train node 的 target argmax。
- NCR=0.0208 很低，CDR=0.0543 也低，说明真实 GB 当前既没有强纠错，也没有强误伤。
- random control 的 CDR=0.5870 很高，说明错误分组会严重误伤 clean labels，因此下一版必须加强 gating。

当前已支持的结论：
- OrginGB-GCN v1 代码可以作为继续迭代的基础。
- 当前 soft target 设计没有在 Cora uniform 0.4 seed=3000 上超过 GCN。
- 当前结果不支持直接进入三数据集 5-seed 正式实验。
- 普通 GB 可能包含弱噪声排序信号，但还没有转化为有效训练收益。
- random-size-matched 控制必须保留。

不能声称的结论：
- 不能说 ordinary GB 已经证明可以去噪。
- 不能说 same-ball membership 有语义同类含义。
- 不能说 GB 阶段提升了 GCN。
- 不能说已经缩小与 RNCGLN 的差距。
- 不能说 PubMed 会有效，因为 PubMed 尚未跑 OrginGB-GCN。
