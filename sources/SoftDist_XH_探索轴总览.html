二、SoftDist 之上的机制增强（7 轴，全部判死）

在 SoftDist 定型后，尝试在它之上叠加增强。核心结论：在低覆盖(20%)+高噪声(40%)下，球校正候选集内部"干净 vs 噪声"在多个信号维度上本质不可分，软分布校正已是最优形态。

合并机理（论文 §7 核心论点）：上述机制各依据不同信号试图区分"该翻的噪声"与"不该动的干净标签"，但没有一个能将 CDR 相对降 30% 而保持 NCR 损失 ≤10%。在该数据稀疏度下，硬性二分必然误伤过多或放过过多。SoftDist 的连续 α 软组合不做这个不可能的二分——这正是它最优的根本原因。

三、三类独立置信信号的系统否定（"不可分性"的硬证据）

为验证"球校正候选内干净/噪声不可分"，用三个相互独立的信号维度做裁决诊断，预注册门槛：CDR 相对降≥30%、NCR 损失≤10%、保护精度≥70%。

九、总结：探索全图与最终定位

探索轴计数（全部探尽，无正 ROI 开放方向）

机制增强 ×7 · gate 信号 ×3 · 逐节点分辨率 ×1 · SSL 方法 ×4 · SSL 目标(uniformity)×1 · 噪声类型 ×3 · 噪声率 ×3 · 覆盖率 ×4 · backbone ×2 · 外部对比 ×9方法 · 数据集广度 ×10数据集（含 LastFM 诊断边界） · 大图两种用法(soft-target/selection) · adaptive proxy ×3候选

论文资产（KEEP）

  • 主方法：SoftDist [X‖H]——frozen GRACE 双重利用（球几何 + [X‖H] 分类）+ multiclass-α 软分布校正 + 端到端 GCN，非迭代单遍
  • 3 个成功数据集：Cora / CiteSeer / Coauthor-CS（含 18k 大图），球增量 5/5 over CE 与 shuffled
  • 完整外部对比 + 公平性对照：NRGNN[X‖H]/TFR/7 NoisyGL 方法；claim 诚实校准为"受控增量"非 SOTA
  • C3 表示二维性：可分性≠可聚类性，三次独立确认，"为什么是 GRACE"的原理分析
  • 二维 size×class 适用域边界 + ball-clusterability 中介证据（诊断量强相关，proxy preliminary）
  • 异常彻底的负结果分析：每个判死轴都有预注册门槛 + 机理 + 诊断——方法论严谨度的展示
  • 效率/敏感性/oracle/噪声谱等稳健性补强

判死清单（KILL，附机理，勿复活）

  • GRACE encoder 微调（破坏 frozen 表示 0.80→0.57）· 二值 gate（无 universal 阈值）· 可靠性加权（权重≈1）
  • 动态α/模型预测反馈（自强化）· ball consistency（无逐节点信息）· NRGNN杂交（信号冗余）
  • 自适应粒度 E1（票密度不足）· 无标签扩展（无逐节点分辨率）· 多粒度/early-learning/逐节点裁决（干净噪声不可分）
  • 换 SSL 方法 / 可学习τ / 显式uniformity（probe≠clusterability，球塌缩）
  • 大图 soft-target 与 selection 两种用法（下游被吸收/样本损失抵消）· 伪标签回流（precision不足）

最终定位

诚实定位：一个简单、非迭代、低方差的粒球去噪管线，在 3 个数据集（含大图）上有受控粒球增量，配异常彻底的适用域刻画与边界机制分析。不声称 SOTA（给对手同样 H 后持平/略逊）。贡献 = 概念 + 效率 + 分析。适合 KBS / Neural Networks / Pattern Recognition。
