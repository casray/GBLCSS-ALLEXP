OrginGB-GCN

第一版普通粒球模块：Ordinary Granular Ball + GCN，用于图标签噪声鲁棒节点分类。

设计日期：2026-06-03
实验框架：NoisyGL + GCN
第一批数据集：Cora, CiteSeer, PubMed
核心定位：soft denoising prior, not hard label

0. 一句话结论

OrginGB-GCN 的第一版应做成“静态普通粒球 + 软标签修正 + 轻量样本降权”。 它只把普通粒球作为弱去噪先验，不把同球节点当成同类，不直接替换 noisy label，不改图结构，不改数据划分，不接入复杂 GAGB。

这个版本的目的不是立刻形成最终论文方法，而是回答一个最小问题： 在普通 GCN 的图标签噪声训练中，ordinary granular ball 是否能提供比普通 noisy-label CE 更好的局部去噪信号。

1. 前因后果

1.1 为什么先不继续 GAGB

之前的 GAGB 方向已经暴露出几个问题：机制复杂、target 更新强度敏感、Cora 0.4 下会出现间接分类边界移动，并且很多收益很难和随机分组、kmeans、top-k local smoothing 区分开。 所以当前不适合继续在 GAGB 上叠公式，而应该先回到一个更干净的问题：普通粒球本身在标签噪声任务里有没有价值。

1.2 为什么选择普通 GCN 做宿主

当前 NoisyGL 中的 GCN 是最基础、最清晰的监督 baseline。它的训练逻辑是：在 noisy train labels 上做 cross entropy，validation 用 NoisyGL 默认流程，test 用 clean label 评估。 因此它非常适合做第一版宿主：如果粒球模块连 GCN 都不能稳定改善，就不应该过早接入 RNCGLN、RTGNN 或 UnionNet 这类复杂鲁棒方法。

1.3 为什么是 ordinary GB，而不是 graph-aware GB

graph-aware GB 是更强但更复杂的第二阶段方向，需要引入拓扑邻近、预测一致性、PPR 或 K-hop 结构。当前用户明确提出“加入普通粒球模块”，所以第一版必须保持普通粒球定义：只在 embedding 空间构球，只用中心、半径、球大小、平均距离等普通粒球统计量。

2. 当前 Baseline 状态

现有 NoisyGL baseline 已经足够支撑本轮方法设计：

数据集 当前主 baseline 关键边界
Cora GCN + RNCGLN Cora uniform 0.4 上 RNCGLN 明显强于 GCN，是第一批高价值验证点。
CiteSeer GCN + RNCGLN CiteSeer uniform 0.2 上 RNCGLN 强于 GCN，适合验证中噪声条件下普通 GB 是否有效。
PubMed GCN RNCGLN 默认实现因 dense NxN 相似度矩阵在 PubMed 上 OOM；UnionNet/Forward/Backward 未稳定强于 GCN。
本方法第一版在 Cora/CiteSeer 上不能只和 GCN 比，还要观察是否缩小与 RNCGLN 的差距；PubMed 上则以 GCN 为主 baseline。

3. 来自经验文档的硬约束

历史教训 对 OrginGB-GCN 的约束
same-ball membership 不能等价于语义标签。 不做 hard relabel，不做同球 hard positive，不直接替换 noisy label。
严格 GB local smoothing 在 Cora 有局部信号，但 CiteSeer 不稳定。 必须同时跑 Cora、CiteSeer、PubMed；不能用单数据集结果做结论。
target 更新太弱会 NCR=0，太强会引发边界移动。 第一版用受控的 soft target mixing，并记录 NCR/CDR/changed ratio。
随机分组、kmeans、top-k 常能解释一部分收益。 必须加入 size-matched random ball 或 shuffled ball 控制。
hard compactness、prototype pulling、view generation 修改反复不稳。 第一版只改监督 loss，不改 GCN 结构、不改图增强、不加中心拉近。
小于 std 的提升不能作为论文结论。 所有结果必须 5 seeds，报告 mean/std 和 paired delta。

4. 本轮研究目标

4.1 研究假设

在带 uniform label noise 的节点分类中，GCN warmup 后的 hidden embedding 空间可能已经形成一定局部语义结构。 普通粒球可以把这些局部区域压缩成软的局部标签分布和节点置信度，从而降低错误 noisy label 对训练的影响。

4.2 粒球扮演的角色

粒球只扮演三个弱角色：

  • local region unit：描述 embedding 空间中的局部节点集合。
  • soft target generator：生成球级软标签 q_B。
  • confidence signal：决定节点 target mixing 和 loss weight 的强度。

4.3 非目标

  • 不证明普通粒球一定是语义聚类。
  • 不声称 same-ball 节点同类。
  • 不追求第一版超过所有鲁棒 baseline。
  • 不把 PubMed 上超过 GCN 的小幅波动写成显著结果。

5. 算法设计

5.1 输入与输出

输入：

  • 图 G=(A,X)。
  • 训练集 noisy labels y_tilde。
  • 普通 GCN encoder/classifier。
  • NoisyGL 默认 train/validation/test split。

输出：

  • 训练后的 GCN 分类器。
  • 每个 train node 的 soft target target_i。
  • 每个 train node 的样本权重 weight_i。
  • 粒球诊断：球数量、大小、半径、覆盖率、NCR、CDR 等。

5.2 Warmup GCN

先使用原始 noisy labels 训练普通 GCN 若干 epoch，例如 E_warm=30。 这一步只为了得到一个比 raw feature 更贴近任务的 hidden embedding 空间。

L_warm = CE(f_theta(A, X)[train], y_tilde[train])

5.3 普通粒球构造

从 GCN 的倒数第二层取 hidden representation H，对每个节点表示做 L2 normalization。 然后在 H 空间构造 ordinary granular balls。构球过程只依赖 embedding，不依赖标签。

每个球记录：

  • B：球内节点集合。
  • c_B：球中心向量。
  • r_B：球半径，建议用球内到中心的最大 cosine/angular distance。
  • ad_B：average distance，球内到中心的平均距离。
  • |B|：球大小。
  • T_B：球内属于 train mask 的节点集合。

5.4 球级软标签 q_B

对球 B，计算两个分布：

  • pbar_B：warmup GCN 在球内节点上的平均预测分布。
  • yhat_B：球内 train nodes 的 noisy label empirical distribution，加全局 prior 平滑。
q_B = normalize((1 - eta_B) * pbar_B + eta_B * yhat_B)

其中 eta_B 由球质量和球内 train label 覆盖率控制。低质量球、train nodes 太少的球，更多依赖 pbar_B，少依赖 noisy local majority。

5.5 节点 soft target

对训练节点 i，假设它属于球 B(i)。如果球级分布与 noisy label 冲突，并且球质量足够高，就把训练目标轻微混向 q_B。

target_i = (1 - alpha_i) * onehot(y_tilde_i) + alpha_i * q_B

第一版建议 alpha_i 不超过 0.5。这比 GAGB 中强替换更安全，也比过小 alpha 更容易产生可测 NCR。

5.6 样本权重

对冲突且低置信节点，适度降低其 loss 权重，避免错误标签主导训练。

weight_i = 1 - gamma * alpha_i, 其中 gamma 建议先取 0.5

这意味着被粒球强烈怀疑的节点，不会被完全删除，只是降低训练强度。

5.7 最终训练损失

L = mean_i weight_i * CE_soft(logits_i, target_i), i in train_mask

这里 CE_soft 是 soft-label cross entropy。 验证和测试逻辑保持 NoisyGL 原样，不用 soft labels 评估。

6. 粒球质量与置信度

6.1 球质量 Q(B)

第一版只使用 ordinary GB 的无标签质量，不引入图拓扑项。

Q(B) = size_gate(B) * compact_gate(B)

建议定义：

  • size_gate(B)：球大小过小则降权，避免 1-2 个节点形成伪高质量球。
  • compact_gate(B)：基于 ad_B 或半径的归一化紧凑度。
size_gate = 1 - exp(-(max(|B|-1, 0) / m0))
compact_gate = exp(-ad_B / tau_ad)
Q_B = clip(size_gate * compact_gate, 0, 1)

6.2 alpha_i

alpha_i 应该由三个因素共同决定：

  • 球质量 Q_B。
  • 节点到球中心的接近程度。
  • 球级分布对 noisy label 的冲突程度。
conf_i = Q_B * exp(-dist(h_i, c_B) / tau_node)
conflict_i = max(0, max(q_B) - q_B[noisy_y_i])
alpha_i = alpha_max * conf_i * conflict_i

第一版推荐 alpha_max=0.5，后续只在 smoke test 显示 target 过弱或过强时再微调。

6.3 低覆盖球处理

如果球内 train nodes 太少，不能可靠估计局部 noisy label 分布。第一版建议：

  • |T_B| < 2：不启用 target mixing，alpha_i=0。
  • 2 <= |T_B| < 4：降低 eta_B。
  • |T_B| >= 4：正常计算 q_B。

7. 训练流程

Input:
  G=(A, X)
  noisy train labels y_tilde
  train/val/test masks
  GCN config from NoisyGL

Stage 1: Warmup
  Train ordinary GCN for E_warm epochs using noisy CE.
  Save hidden embedding H and prediction P.

Stage 2: Build ordinary granular balls
  Normalize H.
  Build ordinary embedding-space balls.
  Compute center, radius, average distance, size, Q(B).
  Compute q_B from warmup prediction and noisy train-label distribution.
  Compute target_i and weight_i for train nodes.

Stage 3: Final training
  Reinitialize GCN or continue from warmup.
  Train with weighted soft-label CE.
  Keep validation/test protocol unchanged.

Stage 4: Diagnostics
  Save test accuracy, NCR, CDR, changed ratio, ball stats.
  Compare against GCN and random-size-matched control.
第一版建议先采用静态粒球：warmup 后构球一次，后续训练不刷新。动态刷新会引入 assignment churn，需要单独诊断，不适合作为 v1 默认。

8. 必做对照与消融

方法 说明 目的
gcn NoisyGL 原始 GCN。 基础参照。
orgingb_gcn 普通粒球 + soft target + sample weight。 主实验方法。
random_size_matched_gcn 保留真实粒球的 size distribution，但随机分配节点。 排除“只是分组/球大小正则”带来的收益。
shuffled_ball_gcn 打乱真实粒球 assignment。 检查真实 membership 是否有额外价值。
pred_only_gcn eta_B=0，只用 warmup prediction。 检查粒球 noisy label distribution 是否真的有帮助。
label_only_gcn 主要使用球内 noisy label distribution。 检查是否退化成危险的 local majority smoothing。
最小第一轮至少要有 gcn、orgingb_gcn、random_size_matched_gcn。如果没有随机大小匹配对照，不能声称收益来自粒球结构。

9. 第一批实验设置

用户指定的第一批实验点是合理的：

数据集 噪声类型 噪声率 为什么选
Cora uniform 0.4 GCN 与 RNCGLN 差距明显，是检验去噪能力的首选高噪声点。
CiteSeer uniform 0.2 中等噪声下 RNCGLN 强于 GCN，用来判断普通 GB 是否只在高噪声有效。
PubMed uniform 0.4 RNCGLN 默认实现 OOM，因此检验 OrginGB-GCN 是否能在大图上超过 GCN。

9.1 推荐运行顺序

  1. 先跑 Cora uniform 0.4 seed=3000 smoke test。
  2. 检查是否 NaN、是否显著拖慢、target_changed_ratio 是否合理。
  3. 如果 smoke test 通过，三组实验都跑 5 seeds：3000-3004。
  4. 只在三组结果显示正信号后，再考虑 pair noise 或更多噪声率。

9.2 推荐配置初值

参数 建议初值 说明
E_warm 30 足够形成初步 hidden space，不让 warmup 过度记忆噪声。
alpha_max 0.5 避免强替换，同时允许 target argmax 有机会改变。
gamma 0.5 样本降权强度。
min_train_per_ball 2 或 3 避免低覆盖球误导。
ball_refresh off 第一版静态构球。

10. 指标与诊断

10.1 性能指标

  • test_acc_mean / test_acc_std：5 seeds test accuracy。
  • paired_delta_vs_gcn：同 seed 下相对 GCN 的差值。
  • paired_delta_vs_random：同 seed 下相对随机大小匹配分组的差值。

10.2 去噪指标

  • NCR：Noise Correction Rate。被污染 train nodes 中，target argmax 修正为 clean label 的比例。clean label 只用于诊断。
  • CDR：Clean Damage Rate。原本干净 train nodes 中，target argmax 被改错的比例。
  • changed_ratio：target argmax 或 target distribution 发生明显变化的训练节点比例。
  • AUROC：用 suspicion score 区分 noisy/clean train nodes 的能力。

10.3 粒球诊断

  • num_balls
  • mean_ball_size
  • max_ball_size
  • singleton_ratio
  • mean_radius
  • mean_average_distance
  • effective_train_coverage
  • mean_Q_B

10.4 suspicion score

建议第一版使用：

u_i = 1 - conf_i * q_B[y_tilde_i]

u_i 越高，说明球级 soft target 越不支持该节点 noisy label，且节点本身越不可靠。

11. 成功标准与失败标准

11.1 Smoke test 通过标准

  • 训练不 NaN，不 OOM。
  • target_changed_ratio 不为 0，也不能异常大；初步建议 1%-30% 区间内再细看。
  • NCR > 0，且 CDR 不明显升高。
  • Cora uniform 0.4 seed=3000 不显著低于 GCN。

11.2 第一批 5-seed 成功标准

  • 至少两个设置的 5-seed mean 高于 GCN。
  • 至少两个设置的 paired delta 多数 seed 为正。
  • 真实 ordinary GB 必须优于 random-size-matched 控制，否则不能说是粒球贡献。
  • Cora/CiteSeer 至少缩小与 RNCGLN 的差距，最好在某个设置接近 RNCGLN。
  • PubMed 上若只比 GCN 高一点，必须结合 std 和 paired seeds 谨慎解释。

11.3 失败标准

  • 三组中只有 Cora 有收益，CiteSeer/PubMed 没有。
  • random-size-matched 和真实 GB 表现接近或更好。
  • NCR 为 0，说明机制没有实际纠错。
  • CDR 明显升高，说明误伤干净标签。
  • 提升小于 std 且 paired seeds 不稳定。
  • 需要大量调参才能在单点超过 GCN。

12. 风险边界

最大风险：把普通局部分组、teacher smoothing 或额外正则的收益误写成“粒球语义结构有效”。

12.1 机制风险

  • 普通 GB 只看 embedding 距离，可能不能区分边界节点和真正同类节点。
  • 球内 noisy label distribution 可能被噪声 majority 污染。
  • GCN warmup 本身可能已经过拟合 noisy labels，导致 pbar_B 自确认。
  • target mixing 会改变分类边界，即使 CDR 低，也可能间接伤害测试类。

12.2 结果解释风险

  • 单 seed 不能作为结论。
  • 只赢 GCN 但不赢 random-size-matched，不能证明 GB 有独立价值。
  • 只在 PubMed 超过 GCN 一点，可能只是 GCN 方差。
  • 如果 CiteSeer 不稳，不能写跨数据集稳定。

13. NoisyGL 实现建议

13.1 推荐文件组织

external/NoisyGL/
  predictor/
    OrginGB_GCN_Predictor.py
  predictor/module/
    GNNs.py                 # 如需支持 return_hidden，可小改 GCN
  utils/
    ordinary_gb.py          # 普通粒球构造、质量、随机控制
    soft_targets.py         # q_B, alpha_i, weight_i
  config/orgingb_gcn/
    orgingb_gcn_cora.yaml
    orgingb_gcn_citeseer.yaml
    orgingb_gcn_pubmed.yaml

13.2 最小代码改动原则

  • 不要改 NoisyGL 的数据加载和噪声注入。
  • 不要改 split。
  • 新增 predictor，而不是直接覆盖原始 GCN。
  • GB 逻辑放进独立 utils，便于之后复用到 graph-aware GB。
  • 所有新增配置必须保存到 YAML 和 raw log。

13.3 GCN hidden embedding

当前 NoisyGL 的 GCN.forward() 只返回 logits。实现 OrginGB-GCN 时建议增加一个可选接口： 

logits, hidden = model.forward_with_hidden(features, adj)

或者在新的 predictor 中复制一段前向逻辑拿到倒数第二层输出。推荐前者，因为更清晰、可复用，也不会改变默认 forward() 行为。

14. 论文表述边界

14.1 可以说的

  • 普通粒球被设计为一种低侵入的局部软去噪先验。
  • 该方法不依赖 clean labels 构球或训练。
  • 该方法通过球级 soft target 和节点级 confidence 减弱疑似 noisy labels 的训练影响。
  • 如果实验成功，可以说 ordinary GB 在部分 uniform label noise 设置下提供了有效辅助信号。

14.2 不能说的

  • 不能说同球节点一定同类。
  • 不能说普通 GB 已经证明为图语义粒球。
  • 不能说超过 GCN 就一定超过鲁棒 baseline。
  • 不能说 PubMed 上击败 RNCGLN，因为 RNCGLN 默认实现没有跑通 PubMed。
  • 不能把小于 std 的提升写成显著改进。

14.3 推荐保守 claim

We introduce an ordinary granular-ball assisted GCN for noisy-label node classification. The method uses embedding-space granular balls as conservative local denoising priors, producing ball-level soft targets and node-level confidence weights without treating same-ball membership as hard semantic labels.

中文表述可以写成：本文提出一个普通粒球辅助的 GCN 标签噪声鲁棒训练模块，将 embedding 空间中的粒球作为保守局部去噪先验，用于生成球级软标签和节点级置信权重，而不是把同球关系作为硬语义标签。
