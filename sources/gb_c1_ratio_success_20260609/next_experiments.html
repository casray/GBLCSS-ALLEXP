Phase A: Coverage-Aware Gated Soft Correction (最高优先级)

A.1 算法改动

在 losses.py 中新增 gated_ball_soft_correction 函数，替代当前的 ball_majority_vote：

y_soft_i = (1 - α) · onehot(y_noisy_i) + α · p_B(i)
仅当 n_train(B_i) ≥ τcov 且 margin(B_i) ≥ τconf 时启用
否则保留 onehot(y_noisy_i)

其中：

  • p_B(i) = 球 B_i 内 train 节点 noisy label 的归一化分布（现有 ball_label_smoothing 已实现）
  • n_train(B_i) = 球内 train 节点数量
  • margin(B_i) = 最高票数 / 总票数（多数投票的置信度）
  • τcov = coverage 阈值（默认 3）
  • τconf = confidence 阈值（默认 0.6）
  • α = soft correction 强度（默认 0.3，区别于现有的 label_smoothing=0.1）

Phase B: Graph-Supported Coverage Compensation (Phase A 通过后)

B.1 算法改动

在 losses.py 中新增 graph_neighbor_soft_prior：

graph_prior_i = mean( onehot(y_noisy_j) )   for j ∈ N1-hop(i) ∩ train_mask

agreement gate：

启用 soft correction 的额外条件：argmax(graph_prior_i) == argmax(p_B(i))
关键约束：
  • 只用 1-hop 邻居，不做多步传播（避免噪声扩散）
  • 只看 train_mask 邻居（避免标签泄漏）
  • graph prior 只作为 agreement 验证，不直接参与 target 构造
  • 如果节点无 train 邻居，agreement gate 自动通过（回退到 Phase A 的 coverage+confidence gate）
