提出了一种粒计算中新的粒度划分的方法：粒椭球。
并非所有现实生活中的数据都符合球形。
我们能否改变GB的形状，或者找到一种新的粒度模型来替代GB，一种能够覆盖数据集中所有样本的模型？文本就提出了粒椭球的概念。
有两种方法可以用来生成粒椭球。
一种方法是通过根据粒球内的数据在特定方向上拉伸粒球，将其转换为粒椭球。
另一种方法是直接从划分的粒度单元生成粒椭球。
本文选择后一种方法，即直接生成GE。
GE的中心c和形状矩阵H可以通过一个优化问题来确定，即最小体积包围椭球（MVEE）问题。
对于粒椭球的定义：GE(H,c) = {x ∈ Rⁿ|(x − c)ᵀ H (x − c) ≤ 1}
H是一个正定矩阵。c为中心。
x ∈ Rⁿ：表示数据集 D 是存在于一个 n 维空间中的一群点。
≤ 1代表点在粒椭球边界或内部上。
标签：
即粒椭球中多数样本的标签。
纯度：
粒椭球中多数样本所占的比例。
批判性思考与引申（优点与启发、局限与不足、展望等）
粒椭球可以通过改变不同方向上半轴的长度来改变其自身生成的形状，每个基本粒度的信息都可以被准确地描述，所以更加灵活，能够适应非球形数据。
当一个模型无法很好地拟合数据时，应该要思考是否有更好的数学模型更适合这个任务。
MVEE：
设X = {x1, x2, …, xn}是n维欧几里得空间中的点集。
X的MVEE是所有包含X的椭球中体积最小的一个。
MVEE问题具体假设任何椭球GE(H,c)都可以由其中心和形状矩阵H表示（即上述定义）
在H进行Cholesky分解后，就存在一个下三角矩阵L使得H = LLᵀ
所以椭球GE(H,c)可以表示为{x∈Rⁿ | ||Lᵀ(x-c)|| ≤ 1}
即{x∈Rⁿ | x = c + L⁻ᵀz, ||z|| ≤ 1}
所以椭球可以看作是单位球经过仿射变换x' = L⁻ᵀx + c的结果
我们使用表示中心在原点的单位球的体积
因为平移不改变单位球的体积，
所以经过线性变换L⁻ᵀ后，单位球的体积变为det(L⁻ᵀ)Vol(B)
因此，一个n维椭球的体积可以表示为Vol(B)/√det(H)。det(H)越大，椭球GE(H,c)的体积就越小。所以接下来问题就转变为求det(H)的最大值。（det为行列式）。
Khachiyan 指出，任意点集X的MVEE可以从一个中心对称点集的MVEE中获得。因此，我们只需要考虑关于原点中心对称的集合X，即X = -X，且c = 0。

对于一个椭球x，他可以是由一个圆u经过一个变换矩阵M得到的

M 可以是一个任意的线性变换，他可以包含旋转和拉伸的操作，但其特征向量可能并不是互相垂直的，而对于H⁻¹ = M Mᵀ，它永远是一个对称矩阵，所以其特征向量是相互垂直的，可以说抵消了“旋转的过程”。一个变换的主方向是由特征向量来描述的，所以H⁻¹ 的特征向量，就是那个创造了椭球的几何变换的“主方向”。在最终的几何图形上，就体现为椭球的主轴方向。
第二种方法：马氏距离
马氏距离：一个点 x 到一个数据分布中心 μ (即 c) 的马氏距离 D_M 的平方被定义为：
D_M²(x) = (x - μ)ᵀ Σ⁻¹ (x - μ)
μ是数据分布的均值（即中心）。
Σ是数据分布的协方差矩阵。
Σ⁻¹是协方差矩阵的逆矩阵，它必须是一个正定矩阵。
可以看到粒椭球的定义与马氏距离的定义完全相同。
所以粒椭球就是一个等马氏距离面所包围的区域。
