对于粒椭球的定义：GE(H,c) = {x ∈ Rⁿ|(x − c)ᵀ H (x − c) ≤ 1}
MVEE：
设X = {x1, x2, …, xn}是n维欧几里得空间中的点集。
X的MVEE是所有包含X的椭球中体积最小的一个。
MVEE问题具体假设任何椭球GE(H,c)都可以由其中心和形状矩阵H表示（即上述定义）
在H进行Cholesky分解后，就存在一个下三角矩阵L使得H = LLᵀ
所以椭球GE(H,c)可以表示为{x∈Rⁿ | ||Lᵀ(x-c)|| ≤ 1}
即{x∈Rⁿ | x = c + L⁻ᵀz, ||z|| ≤ 1}
所以椭球可以看作是单位球经过仿射变换x' = L⁻ᵀx + c的结果
使用表示中心在原点的单位球的体积
因为平移不改变单位球的体积，
所以经过线性变换L⁻ᵀ后，单位球的体积变为det(L⁻ᵀ)Vol(B)
因此，一个n维椭球的体积可以表示为Vol(B)/√det(H)。det(H)越大，椭球GE(H,c)的体积就越小。所以接下来问题就转变为求det(H)的最大值。（det为行列式）。
进而可以转化为求-ln det H的最小值（可能好计算一点？）（1）

所以公式变为xⱼᵀ H xⱼ ≤ 1。（2）

计算MVEE的方法大致可分为两类：
内点法（牛顿型算法）和条件梯度法（Frank-Wolfe [FW]型算法）。
内点法 主要用于求解模型(3)，而FW方法 用于求解模型(4)。
本研究采用FW型算法来计算MVEE，因为实验证明FW型算法在处理大样本量和高样本维度方面优于牛顿型算法。
而FW-K和FW-KY算法只能获得一个ε-原始可行解，这未必满足近似最优性条件。
所以在此基础上，提出了ε-近似最优解的概念：
假设u是(4)的一个可行解，如果H(u) = (XUXᵀ)⁻¹满足xⱼᵀ H xⱼ ≤ 1 + ε, j = 1, 2, ..., m，则u被称为一个ε-原始可行解，其中ε是一个足够小的正数。
在实际计算中，很难得到一个完美的解。所以这个ε将算法的标准放宽，得到一个合格的结果即可。计算速度更快，也提高了鲁棒性。它允许生成的椭球可以有数据点在它的边界之外，但超出边界的距离不能超过 ε。
如果u是模型(4)的一个ε-原始可行解，并且u还应满足uⱼ > 0, xⱼᵀH(u)xⱼ ≥ 1 − ε, j = 1, 2, ..., m，则u被称为一个ε-近似最优解。
对于那些分配权重的外围数据点，它们到边界的距离不能超过ε。

样本的最近邻椭球集（NGES）
给定一个GE集 {GEⱼ(Hⱼ, cⱼ)}, j = 1,2,…,m，其中包含k类标签，以及一个样本x。如果x在一个GEₐ内部，即满足dis{x, GEₐ(Hₐ, cₐ)} ≤ 1，那么x的NGES就是那个GEₐ。如果x位于所有GE之外，即满足dis{x, GEⱼ(Hⱼ,cⱼ)} > 1, j=1,2,…,m，那么x的NGES {GEᵢ(Hᵢ, cᵢ)}, i=1,2,…,k，是由每个类别中离x最近的GEᵢ组成的集合。
简而言之有两种情况。
1:x在一个椭球内部，其NGES为这个椭球。
2:x不在任何一个椭球内部，其NGES为每个类别中离x最近的GEᵢ组成的集合。

GEC Algorithm的时间复杂度
对k个类别，n个样本，d个特征纬度的数据集，执行k-means聚类算法，每次迭代的时间复杂度是knd。可以认为是O(knd)
在l个样本上，求解MVEE模型，然后计算其形状矩阵H和中心c，这个过程所需的时间复杂度是ld²，(最坏情况l=d)生成椭球的总时间复杂度可以表示为O(nd²)。
3.最后需要进行NGES的计算。确定一个待预测样本与单个椭球之间的距离需要d²的时间。在最不利的情况下，NGES计算所需的时间将达到kmd²。假设有n₁个样本待预测，那么在预测阶段，所需的时间复杂度将是O(n₁kmd²)。
GEC算法的总体时间复杂度是O(knd + nd² + n₁kmd²)。
所以GEC算法可以在线性时间复杂度内完成模型训练过程，效率更高。

可以理解如果三维空间中只有三个样本无法生成三维空间的椭球，因为三个样本一定可以是共面的。但为什么一定要在n维空间内生成n维的椭球？
椭球定义中H是一个正定矩阵，但正定矩阵必须是满秩的，如果有一个纬度没有，那么他的秩就是n-1了。所以所有样本数少于维度的椭球都会被丢弃
对于样本点到一个椭球的距离：椭球的尺寸越大，它在样本空间中的权重就越高。这种定义距离的方式可以将相似性与椭球的权重结合起来。如何理解？
椭球的尺寸越大，样本点越分散，其方差也就越大，协方差矩阵（H的逆）的特征值越大，对应的H越小，dis就更容易变得更小，所以点就更容易的分配给这个尺寸更大的椭球，所以认为其权重越大。
至于相似性：在粒球中，欧式距离越近的粒球有较大可能标签一致，所以他们有“相似性”，所以在椭球中（x-c）和其转置 就代表其相似性。可以这么理解吗？
