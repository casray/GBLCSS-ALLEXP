# Datasets

Pass the dataset key below to `--datasets`. The loader in `src/gblcss/data.py` downloads public graph data through PyTorch Geometric (PyG). Raw datasets are not bundled with this repository.

| Paper name | Dataset key | PyG loader and `name` argument | Experiments |
|---|---|---|---|
| Cora | `cora` | `Planetoid`, `Cora` | Main |
| CiteSeer | `citeseer` | `Planetoid`, `CiteSeer` | Main |
| CoraFull | `corafull` | `CitationFull`, `Cora` | Main |
| Coauthor-CS | `coauthorcs` | `Coauthor`, `CS` | Main |
| Amazon-Photo | `amazonphoto` | `Amazon`, `Photo` | Main |
| PubMed | `pubmed` | `Planetoid`, `PubMed` | Additional |
| CoraML | `coraml` | `CitationFull`, `cora_ml` | Additional |
| CiteSeerFull | `citeseerfull` | `CitationFull`, `CiteSeer` | Additional |
| Coauthor-Physics | `coauthorphysics` | `Coauthor`, `Physics` | Additional |
| Amazon-Computers | `amazoncomputers` | `Amazon`, `Computers` | Additional |
| Attributed Wiki | `attributedwiki` | `AttributedGraphDataset`, `Wiki` | Additional |

Cora and CoraFull are different graphs, as are CiteSeer and CiteSeerFull. Do not substitute one loader for another. The loader documentation provides the underlying dataset sources:

## Preparation

The first run requires access to the dataset download host; subsequent runs reuse `data/`. Use `--data-root PATH` to select another cache. Dataset licensing and attribution remain with the respective providers.

The experiment loader uses PyG's node order and constructs the paper's random, non-stratified 20% training, 10% validation and 70% test split for each seed. It does not use the built-in Planetoid split masks. Synthetic label noise is generated by `data.py` from the selected noise type, rate and seed. The main comparison corrupts training labels only; the noisy-validation experiment is selected separately.

## Frozen representations

`representations/<dataset-key>/grace/H.pt` contains the frozen GRACE node representations. Rows correspond to the graph loader's node order; do not reorder nodes independently of this file. These tensors are intermediate features, not stored classification results. The downstream commands construct targets and train models from them.

The supplied representations support all eleven datasets. Optional GRACE pretraining settings for the five main datasets are in `configs/representations/grace.yaml`; see the pretraining command in the main README.
