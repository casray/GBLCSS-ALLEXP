## 二、优先恢复或修正

### 1. MLP具体结构被完全删除，建议恢复（3.3.3，行265，PDF第12页）

原稿说明了隐藏线性层、ReLU、batch normalization、dropout和输出层。新稿只剩：

> The deployed two-layer MLP f is trained by soft cross-entropy:

全文和附录中已检索不到 ReLU 或 batch normalization 的替代说明。4.1.4只有层数、宽度和dropout率，不能完整替代结构说明。Batch normalization不是所有两层MLP默认都有，不能作为可推知信息删掉。

建议恢复原句：

> The two-layer MLP consists of a hidden linear layer followed by ReLU, batch normalization, and dropout, and an output layer that produces class logits. It is trained by soft cross-entropy:

### 2. 恢复摘要和讨论的论断边界（行63、518）

摘要把“generally retain”改成了“retain”，把“have largely been studied with clean training labels”改成“largely assume clean labels”。前者从通常如此变成无例外式概括；后者把研究和评测侧重点变成方法假设，不是严格同义改写。

建议：

> Existing noise-robust graph methods generally retain graph-dependent inference, whereas graph-free methods have largely been evaluated with clean training labels.

讨论把“support the importance”改成“confirm that this choice matters”。没有新增实验，没必要增强口径；改回 support 即可。2.1中的“JoCoR ... enforces prediction agreement”也建议用“encourages prediction agreement”，避免把损失正则化写成硬约束。

摘要“among seven ... baselines”不如原来的“compared with seven ... baselines”准确，GB-LCSS不是这七个baseline之一。建议恢复 compared with。

### 3. 新增BNO-GB后，应明确新的比较边界（2.5，行122–124，PDF第6页）

BNO-GB本身使用label-agnostic、unsupervised granular-ball clustering。新增它是合理的，但接下来仅以“GB-LCSS instead forms balls geometrically ... and only then aggregates labels”作对比，会让读者以为“无标签构球”就是与前述工作的关键区别。该表述并非直接声称所有前人都用标签，但对最近邻工作的区分不足。

建议在BNO-GB介绍后明确用途差异，例如替换现有对比句：

> BNO-GB uses granular-ball structure to identify noise types for open intent classification; GB-LCSS uses frozen graph representations to construct leave-one-out soft targets for an attribute-only node classifier.

引言行80中的“GB-LCSS instead ...”也删掉了原有对比对象“supervised granular ball classifiers that use label purity”。可改用“In GB-LCSS, ...”，避免将普通方法介绍写成不清楚的创新性对比。

出处：BNO-GB出版社页面明确介绍无监督、标签无关构球及噪声类型识别。
https://www.sciencedirect.com/science/article/pii/S0031320326002487

### 4. 蒸馏基线的适配身份应在正文保留（4.1.3，行393，PDF第18页）

新稿删除了FF-G2M的“reimplemented with the common backbones”和KRD、VQGraph的“mechanism adaptations”。只说“retains ...”不够清楚，读者可能按原始完整方法理解表中的结果。

Table F.1仍如实记录适配方式，因此这不是附录虚假或实验被改变，而是正文说明被压得过度。

建议替换为：

> FF-G2M is reimplemented with the common backbones; adaptations of KRD and VQGraph retain reliability-based selection and soft-codebook distillation, respectively.

另在graph-assisted MLP段的“all using graph information only during training”后恢复“in our protocol”，以明确这是本文的评测接口，不是对所有原始方法的无条件定义。

### 5. 2.2末尾新增概括的指代过宽（行106，PDF第5页）

“These methods retain graph-dependent predictors”紧跟NoisyGL基准和LLM节点选择框架。NoisyGL不是一种预测器；仅从节点选择框架的摘要和引言也不能推出它要求任意下游分类器必须在推理时访问图。

最小修复是删除该总括前半句，直接保留本文定位：

> GB-LCSS uses the training graph to construct supervision for an attribute-only classifier deployed without graph access.

不是认定新增论文采用graph-free推理，而是现有材料不足以支持这句一概而论的表述。

### 6. 恢复导师特别要求的少量符号解释（3.1–3.3）

这些不是数学公式错误，但与此前导师要求相比出现了可读性回退。

- 行128附近：3.1“本节定义学习任务与符号”的开场被删除。若严格遵守导师要求，可恢复一句并与Table 1引导合并，不必恢复长段。
- 行133：“Bold symbols denote vectors or matrices”删掉了大小写的区别。恢复“Bold lowercase and uppercase letters denote vectors and matrices, respectively”更明确。
- 行160：删掉了B_j是节点子集以及M是最终球数的解释。当前写成“partition of G”，而G是矩阵，后续B_j又与节点集合相交，虽然可推知，但对象类型不如原稿清楚。建议写成“partition of the node set in representation space”，并补“where M is the number of balls and B_j contains their member nodes”。
- 行173：“minimum child-ball size”又回到了用户曾认为抽象的说法。恢复“minimum number of nodes in each child ball”。
- 行212：I只解释为“class indicator”，删除了1/0含义。建议恢复“equals 1 when z_l=i and 0 otherwise”；z_l可顺便点明是投票节点的观测标签，不必重抄整段。

其中权重alpha的区间、uniform/unanimous两个端点、beta不改变alpha、软目标凸组合、投票不足保留原标签等关键解释仍在，不需要全部回退。

### 7. Table 7范围的统计含义被删掉（4.3.3，行479，PDF第23–24页）

表中保留52–53、63–64和50–59，但解释“Ball counts are reported as ranges across these seeds”被删除。表题中也没有补回。

建议原句恢复即可。这是统计口径，不是冗余文字。
