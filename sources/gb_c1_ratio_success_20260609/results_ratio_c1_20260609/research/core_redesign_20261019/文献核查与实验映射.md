## 2. 必须修正的文献理解

- 既有`文献文件/深度学习+粒球/论文详细总结.md`将SGBGC年份写为2018，与官方AAAI2025矛盾；该目录部分条目是模板提取，不可充当精读。只在新报告纠错，未改外部原文件。
- AW-GBGAE是给一般数据造相似图，构造出来的边不是已有天然图的真值。其√N用于邻居规模等参数，不能等同最终球数。
- SGBGC监督纯度与GBGC结构质量不同；GBGCL又是另一篇，不可因缩写相近混用公式。
- 无监督训练不直接拟合训练错标，但仍可能受图、属性、预训练目标偏差影响。
- “高维导致距离集中”需要分布条件，不等于任何高维表示都无用；也推不出10维最佳。
- “同球”“同类”“相邻”“关系模式相似”“可共享计算”是五种不同关系；新论文须先选要保持哪一种。
- 本轮发现2027卷期的`Granular-ball graph coarsening for graph representation learning`页面，DOI10.1016/j.ins.2026.124198。全文与online-first时间需核查，列为检索待办，不以未来卷期宣称本轮已验证的已发表结论。

## 4. 聊天建议的当前处置

| 聊天建议 | 当前处置 |
|---|---|
| 再换GRACE为更强空间 | 只在有特定机制问题时做；不是下一篇的核心贡献 |
| 中心/半径/支持数产生新损失 | 必须先定义要保持的信息，避免几何量堆损失；旧统计增量路线已有负结果 |
| 多尺度+有效票数+一致性 | 暂缓作为主线，已有相关负结果；不能称从未验证 |
| 增加图知识蒸馏 | 简单区域KL增量弱；某些新关系蒸馏尚未穷尽，但须击败强DIST，不能只对旧MLP比 |
| 改球数到√N | 仅作参考预算；已经有反方向响应的直接证据 |
| 用异配模式代替同类投票 | 保留为研究问题；需要可辨识假设，不先同时估所有未知矩阵 |
| 粒球实现高效粗计算 | 推荐重定义主问题，但必须对照SGBGC/GBGC/ConvMatch/传播保证/CPF/ACE |
| RL或神经网络构球 | 工具候选；先验证评价目标与复杂度收益，后研究学习策略 |

1. 精读ConvMatch、FGC、传播保证论文的完整目标/假设与实现，明确关系失真细化究竟新增哪一点；当前未完成排他性新颖性证明。

3. 查明ACE代码可运行性及其训练/推理成本，不能只与弱粗化比较。
4. 现有数据主要为探索数据；进入正式确认需新的数据/严格锁定协议，并包含足够规模支撑效率命题。
5. 硬球、软归属、层次树的额外成本需实测。固定一个预算指标，不以球数同时冒充时间、存储和精度。
