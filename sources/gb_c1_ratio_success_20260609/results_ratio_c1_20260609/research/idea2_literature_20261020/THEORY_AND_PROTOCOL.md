# 理论核验与阶段1修订草案

日期：2026-10-20。**本文件是研究设计草案；没有启动数据集训练，没有得到ACC提升结果。**

## 1. 两种随机模型必须分开

令两个固定组为B、D，总体大小N，组大小n、m，共同成员数c。组必须在同一统计总体中定义，例如都来自全数据集，或都来自同一个批次。不能使用批内交集却以全数据集N计算期望。

### 模型A：完全随机关联的零假设

固定组大小，在N个位置上随机放置D，则

\[
 C\sim\operatorname{Hypergeom}(N,m,n),\qquad
 \mathbb E_0 C=nm/N,
\]

\[
 \operatorname{Var}_0 C=n\frac mN(1-\frac mN)\frac{N-n}{N-1}.
\]

观察到c后，富集检验使用右尾概率Pr(C≥c)，对应表格
`[[c,n-c],[m-c,N-n-m+c]]`的一侧Fisher检验。

出处：[SciPy官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.fisher_exact.html)。该模型问“随机交集能否解释这个数”，不直接问“两个组语义是否相同”。

### 模型B：保留一部分真对应，只打乱选中的位置

令真实交集为t。均匀选出大小为k的集合S，再在S内部做均匀随机置换，允许不动点；S外保持原对应。给定S：

\[
 c=|(B\cap D)\setminus S|+X,\quad
 X\mid S\sim\operatorname{Hypergeom}(k,|D\cap S|,|B\cap S|).
\]

因此，给定S时，打乱部分的随机期望是
`|B∩S|·|D∩S|/k`，不是直接用nm/N。再对S取期望，k≥1时可得：

\[
 \boxed{\mathbb E[c]-\frac{nm}{N}
 =\frac{N-k}{N-1}\left(t-\frac{nm}{N}\right).}
\]

k=0时c=t，应单独处理。若η=k/N且N很大，系数才近似1−η。

**简短推导。** 对任意不同位置i、j，
Pr(π(i)=j)=Pr(i,j∈S)/k=(k−1)/(N(N−1))，记为a。
故Pr(π(i)∈D)=(1−Na)1(i∈D)+am。对i∈B求和得到
E[c]=(1−Na)t+anm，整理即上式。

实际移动的位置数也不等于k。k≥1时，均匀置换在S内的期望不动点数为1，因此实际移动比例的期望为(k−1)/N。还要再区分“移动到了另一个实例”和“移动到了不同类别”。

这是针对上述随机生成器的推导；不适用于所有人为挑选的难负对、类别内打乱或结构化错配。

## 3. 为什么不保留“最优球大小必然单调增大”

“关联信号衰减”与“需要更多样本”之间，还隔着条件：每个新增样本提供同样质量的证据，干净语义间隔不下降。

实际扩大球时，组的类别构成、边际、半径、样本权重都会改变，可能把原来分开的类别合并。即便统计方差减小，语义偏差也会增大。`1/(1−η)^2`只能在固定信号间隔等简化条件下解释样本需求，不能当最优容量定律。

修订：测量容量×错配率的二维曲线，允许上升、平台、非单调；分析纯度与证据量的变化。不把单调性列为项目生死门槛，也不假设部署时知道真实η。

## 4. 低成本诊断该比较什么

各视图独立重构得到冻结表示；使用完全相同的表示、分组、置换和随机种子比较：

| 规则 | 分数或处理 | 检查目的 |
|---|---|---|
| R0 | c/min(n,m)，复核原阈值和实现 | MGBCC原关系 |
| R1 | c−nm/N | 简单扣除随机期望是否已足够 |
| R2 | log(cN/(nm))；c=0单独处理 | 对照经典log-PMI，检查稀疏单次交集的偏好 |
| R3 | (c−nm/N)/sqrt(Var₀C)；零方差单列 | 是否主要需要尺度校正 |
| R4 | 超几何右尾概率，记录多重检验处理 | 精确离散计数是否有额外价值 |
| R5 | 软原型共现；后续加可靠性权重/传输 | 对照PLCI式机制，不能声称是完整PLCI复现 |

R0–R4是严格同分组的规则消融；R5若改变软分配或原型数，应单独列为机制对照，不混进“只改评分”的表。

显著性不是免费保护：小球一次偶然相交也可能有较小p值；同时检查大量组对时会积累误报。至少记录全部被检验的组对数、交集支持数、边覆盖率和完全置换下误报。固定边缘零假设成立时，可用Bonferroni或BY作保守参照；若用BH，应说明其依赖条件，不能默认任意相关检验都受控。对多个p值网格择优还会增加选择问题。

固定组之后只评估一次关系，避免先用错配对训练表示，再拿同一批对应关系证明该表示的“显著性”。未来若迭代更新组，必须重新处理选择偏差。

## 5. 指标与门槛如何修改

用户附件建议：两个方法各取最优p、F1提升0.1，并要求最优p单调增大。修改为：

1. **先看固定p的配对比较。** p∈{2,5,10,30,100}作探索网格；原阈值点之外，比较PR曲线和相同保留边数下的正确率。各方法择优的结果另标“诊断最优”，不作无监督部署成绩。
2. **多数类相同的F1保留，但仅作一个诊断。** 51%与99%纯度不能等价。再报告组类别分布的相似度、错误关联携带的跨类样本质量、样本覆盖率；类别不平衡时分开报告大类与小类。
3. **真实类别与真实身份仅用于事后评价。** 交集计数必须使用受污染的观测配对行号，不能使用恢复后的真实ID；否则错配已经被暗中修复。
4. **保留有实际意义的幅度要求。** 原“F1+0.1”可保留为同p下的强信号标准，但必须连同覆盖率与种子稳定性解释；不能靠只留下极少数边达标。不把某个阈值当领域标准。
5. **取消单调性硬门槛。** 是否存在稳定有效的容量区间，比曲线必须单调更重要。
6. **增加竞争门槛。** R4只胜R0而与R1/R3打平时，优先简单方法，不继续包装复杂统计检验。关系质量改善后才进入端到端。

建议先以Scene15及一个明确版本的Caltech20做探索；正式确认再锁定另一数据集/新种子。数据文件尚未下载和校验，这里不声称已确定可运行的数据资源。NoisyMNIST继续后置。

跨p挑选依赖真实类别时属于研究诊断，不能把该选择直接拿去报无监督测试结果。最终需要固定设置，或另行验证不读类别的选择准则；本轮不提前添加该机制。

## 6. 进入端到端之前冻结的协议

- 固定第一视图；在第二视图均匀选择floor(ηN)个位置，在该集合内均匀置换，保留不动点。η取0/.2/.4/.6，并记录实际实例错配率与实际跨类错配率。
- 所有方法共享同一批置换；所有输入视图使用自己的真实内容，不把错配后的第二视图特征与未置换标签混作其事后类别。
- 保存数据哈希、特征来源、视图维数、样本/类别数、种子、分组数及球大小分布。
- 先只研究NC；不同时叠加缺失视图、图结构噪声和标签噪声。
- 评价以锚视图实例为基准；不允许用真实排列还原其他视图后再融合。
- 推理是否允许学习式重匹配、可搜索集合/批大小、最后聚类方式，统一并公开。直接拼接与合法重匹配分开报告。
- 干净数据损害≤1pp、40%错配下较原MGBCC提高≥3pp、与强NC基线差距≤2pp，可沿用为阶段2候选门槛；必须同输入、同协议、多种子验证。尚未冻结或执行。
- k-means是有效分组器，不预设必须败给粒球。只有层次或自适应粒度确有增量时，才把它写为粒球机制贡献。

## 7. 下一版算法的最小形态

独立预热 → 各视图局部分组 → 观测配对构成列联表 → 对照随机重叠并量化支持 → 保留可信多对多联系、其余标为未知 → 在冻结关系上加入跨视图训练。

“未知”不自动作为负对。为避免只拉近而坍缩，保留原本的视图内学习约束，并通过消融检查跨视图项。可信组关系也不自动允许把两个混合大球的所有成员强行拉近；“对齐哪些部分”是关系规则有效以后再研究的分支。

本阶段只检验：原比例是否产生可观测错误；简单校正能否减少错误；减少这些错误能否转化为聚类提升。若前两项不成立，就停止该关联规则路线，不靠继续加模块延长实验。
