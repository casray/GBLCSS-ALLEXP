# A 路线：从传统粒球分类与聚类的具体问题出发

日期：2026-10-21。状态：文献与算法草案；没有启动新的性能实验。本文的建议门槛尚未成为正式预注册协议。

## 1. 决策

优先诊断 **固定压缩预算下，抽样构球是否遗漏可识别的小簇**，直接对接 SAGBC。第二候选是 **只在可能改变密度连通性的区域细化粒球**。第三候选是 **分类压缩时保留稀有类内子群，同时限制噪声占用预算**。

三条都不是“首次处理不平衡/边界/密度”的主张。要争取的新增贡献是：找出特定压缩决策丢掉的信息，设计针对该决策的修复，并在相同资源预算下证明收益。现在只推荐推进第一条的缺口诊断，不同时开发三套算法。

研究方法参考 DARPA 的 Heilmeier Catechism：先用日常语言说问题，再解释现有方法不足、改进为何可能有效、风险、成本与中期检查。来源：https://www.darpa.mil/about/heilmeier-catechism 。它是选题检查框架，不是论文贡献。

## 2. 已核实事实与本轮避免的重复

- SAGBC 在抽样数据上产生中心，之后建立全数据到中心的稀疏软隶属关系，以球连接分量决定输出簇。论文采用均匀抽样，公开代码明确使用无放回抽样。未抽中数据在后续仍会被关联到已有中心。
- SAGBC 论文 §4.4 使用 `t=min(20000,N)*tau`，推荐 tau=0.2/0.3；当前公开示例代码固定 `k=5000`，并分裂到球内样本数不大于8。论文算法的阈值写法与这份代码不同。复现前须分别记录，不能混写成同一版本。
- 公开 SAGBC 的分裂函数构造 `squareform(pdist(data))` 后找最远对。不能仅沿用论文的近似成本表述，就声称该实现建树必然近线性；也不能把替换这段实现的工程收益全算成新算法收益。
- GB-DBSCAN §3 的实际半径是最大成员距（背景 §2 的平均半径不是它的实际定义）。它用球半径区分 Core-GB，再以球中心距离不大于半径和建立直接可达关系。球相交不是点级 DBSCAN 连通的充分条件。它本来就重新定义了球级可达关系，因此这是近似目标的潜在代价，不是已证明的实现 bug。
- GBG++ 会删除单点 orphan ball。被删的是构球结果中的单点球，不能把它直接解释成“所有少数类都会被删”。
- GBS 已在不平衡与20%标签噪声共存条件下做实验。INGB 也明确处理 noisy imbalanced classification，且讨论 small disjuncts。不能把“不平衡＋噪声”组合本身当作空白。
- 2026 年 MDL-GBG/MDL-GBC 预印本已通过模型选择组织分裂、保留、残差/边界处理。统一评分或 MDL 本身不是新的切口。
- MG-GBC 的2026年预印本已明确保护稀有小核心。本文仅核到作者摘要及索引，尚未取得全文，不能声称其没有覆盖我们的后续方案。
- BLOCK-DBSCAN 和 AnyDBC 已有块处理、局部查询、逐步细化以及精度/效率控制的先例；第二候选必须直接比较这些方法。
- GB-FuzzyStream 已有遗忘衰减、模糊边界与漂移处理。本轮没有找到足够具体且经核实的剩余缺口，因此不把“粒球＋概念漂移”列为近期主线。

## 3. 第一候选：发现并修复抽样压缩遗漏的小簇

### 3.1 用例和问题

假设一百万个对象中有一个100个样本组成的真实小群体。它内部紧凑，与其他群体可区分，但只占0.01%。若均匀无放回抽5000个样本建球，这100个点一个也没有被抽中的概率为

`P_miss = C(N-K,s)/C(N,s) = product_{j=0}^{s-1}(1-K/(N-j))`。

取 N=1,000,000、K=100、s=5,000，直接数值计算得到 **0.6057553675**；有放回近似 `(1-K/N)^s` 为0.6065154956。这是数学示例，不是 SAGBC 的实测失败率，也不说明一般占比的小簇都容易漏掉。

需要分别检查三种失败：

1. **没有抽到**：抽样阶段完全没有代表。
2. **抽到但被合并**：少数点进入一个主要描述大簇的叶球，失去独立中心。
3. **已有代表但后续连错**：问题来自球间连接，而不是抽样。这种结果应转向第二候选，不能继续把错误归给采样。

没有抽到小簇不严格意味着最终绝无可能恢复它；中心也可能偶然落在适当位置。真正待验证的是“小簇的代表覆盖不足是否稳定导致最终恢复失败”。

### 3.2 研究问题

在固定代表数量、内存和可比总时间下，能否用一次覆盖审计，把预算从冗余的大区域移到缺少代表但有真实局部结构的区域，从而保留小簇？

这属于“已有粒球聚类方法，在簇规模极不均衡时的改进”。如果成功，贡献是预算下的小结构保留与修复，不是一般的不平衡聚类，也不是泛泛的自适应球数。

### 3.3 最简流程草案

1. 以原 SAGBC 规则抽样建球，保持后续连接算法作为第一版固定下游。
2. 使用全数据到球中心的距离，找出没有被当前代表充分描述的候选点。距离须结合局部尺度：远离中心不等于遗漏小簇，也可能是离群点。
3. 只在候选区域内检验局部支持：候选点是否成片、是否存在相互邻近的多个成员、是否有与已有代表的结构差异。第一版不引入神经网络或伪标签。
4. 对有支持的遗漏区域新增粒球；从重复描述同一大区域的球中回收等量预算。单纯增加球数不能算胜过原方法。
5. 更新受影响的隶属关系和球间连接，输出聚类；记录插入、合并和局部扫描成本。

先验证“检测到的遗漏是否可恢复”，再设计完整的预算交换规则。预算固定不代表必须牺牲任何现有小簇：若没有可安全回收的冗余预算，应报告预算不足。

粒球的角色：可新增、可细分、可合并的局部表示与计算单元。不是给标签投票，也不要求同球样本被强制赋予同一语义训练目标。k-means微簇、BIRCH等同样可承担这种角色，因此必须比较，不能预设粒球不可替代。

### 3.4 最接近先例与潜在差异

| 先例 | 已经做到 | 我们必须额外证明的内容 |
|---|---|---|
| SAGBC | 抽样构球、全数据软隶属、结构连接 | 发现初始代表遗漏，并在相同预算下修复 |
| DBSCAN++ | 在子集上做密度估计，含均匀与k-center初始化 | 不是简单换抽样器，修复须胜过覆盖型初始化 |
| ARP-GB | 密度驱动代表选择、半径调整、重叠传播 | 后验覆盖修复是否超出一次密度选点 |
| MG-GBC 预印本 | 作者摘要称保护小而密的核心、连接稀有碎片 | 全文待核；暂定差异为补足未形成代表的区域与固定预算交换 |
| MDL-GBG 预印本 | 保留/分裂/核心残差模型竞争、残差重分配 | 固定资源下的覆盖恢复不能仅是MDL规则换名 |

### 3.5 假设和最危险的反例

- 小簇在使用的特征空间中可辨识，且有足够的多个样本。没有可识别的几何结构，任何无监督修复都无从判断。
- 遗漏区域只占一部分数据，局部审计开销不会退化成全量重聚类。
- 密集异常群也可能有局部支持。无监督算法不能仅凭几何把“有意义罕见群体”和“语义上不要的异常群”普遍分开；必须预先定义任务把哪些群体视作簇。
- 大簇中确有冗余预算，否则保小簇和保持总体质量可能冲突。
- 全局欧氏距离对混合类型/高维数据未必合适；首轮限定标准化数值特征，不同时声称解决所有表格类型。

### 3.6 首轮诊断，不直接铺开新方法训练

先以原版 SAGBC 检查三阶段覆盖。对照包括：均匀抽样、k-means++初始化、farthest-first/k-center代表、BIRCH微簇，以及简单补样；相同最终代表预算，另给相同总时间比较。

数据：可控混合分布只用于分离大小/密度/间隔因素；真实数据优先从 SAGBC 的 Penbased、Letter、Htru2 中核验可获取版本。Htru2类别是语义标签，不自动等同几何簇。可额外使用 sklearn Digits 的预先固定不平衡抽样；不得看新方法结果后才挑容易赢的类别。

第一版不加标签噪声。可控数据独立改变小簇比例（如1%、0.1%、0.01%）、密度比和间隔；在相同配置上加离群点对照，防止补样只是在追异常。小簇绝对数量应超过诊断使用的局部支持需求。

指标：抽样成员数、独立代表覆盖、在构球/连边各阶段的小簇丢失率、按簇宏平均恢复率、ARI/NMI、错误碎分数、离群点误建簇率、完整耗时/内存。不能只看样本加权ACC，也不能用每个真类都匹配同一大预测簇的“召回率”美化结果；采用一对一匹配或同时报告纯度与覆盖。

建议推进条件：覆盖不足在至少两类真实数据或其预先定义的不平衡版本上可复现，并确实解释恢复损失；固定预算的朴素修复能较强的简单选点对照改善小簇恢复，且没有靠大量碎分或成本暴涨换来。

可讨论的效应门槛：小簇恢复率增加10个百分点、整体ARI下降不超过0.02、总时间不超过1.5倍。它们是本轮提出的工程取舍，不是领域定律；正式运行前根据用途冻结，不能看到结果后改口径。

停止/改题条件：原方法没有稳定覆盖缺口；k-center或k-means++已消除缺口而修复没有额外收益；问题实际出在连边；或者修复成本接近全量高质量聚类而质量仍更差。

## 4. 第二候选：对可能改变聚类连接的粒球做局部精化

### 4.1 例子

两条相邻的细长密集带可以各自被大球包住。包围球的空白部分相交，原始点却仍被低密度间隙隔开。如果把球相交直接当成连接，两类可能被并为一类。

这说明球级连接判断存在信息不足，不证明实际 GB-DBSCAN 的生成器一定产生这种球。第一张诊断图必须用作者算法实际生成的球；不能只手画一个永远不会出现的反例。

### 4.2 方法草案与可验证性质

固定点级密度标准（例如给定 epsilon 和 minPts 的 DBSCAN* 核心点连接），以粒球做批量查询与局部细化单元。对球B、D，中心距d，包围所有成员的最大半径r_B、r_D，任意跨球点距离均满足：

`max(0,d-r_B-r_D) <= distance(x,y) <= d+r_B+r_D`。

- 下界大于epsilon：整对球没有epsilon边，跳过逐点比较。
- 上界不大于epsilon：整对球的点均在epsilon邻域内，可批量计数。
- 上下界夹住epsilon：暂不确定，进一步细分或检查少量真实成员。

这些是已有几何界，不是本项目新定理。平均半径或SAGBC的软半径不能代入包围界；重叠球必须去重，否则邻居计数错误。

需要同时处理核心点身份与连接：由邻居数上下界确认核心/非核心，剩余未知保留为未知。仅有一条跨球近邻边不足以合并整球，除非球内核心连通性已获确认。可优先处理影响多个暂定连接分量的未知关系，而非把所有球统一细分到很小。

输出可以是具有确定边界的粗结果与尚未确认的部分；预算足够时继续至预先定义的点级参考结果。若只得到部分保证，不得宣传完整等价DBSCAN。边界点归属有歧义，优先验证核心点组件与噪声集合，或固定统一的边界点分配规则。

### 4.3 增量在哪里

“只检查重要点”和“逐步逼近DBSCAN”已经由AnyDBC做过，BLOCK-DBSCAN也已用球形块和可达性近似。可争取的增量应是：利用已有粒球层次，按仍会影响连通结果的不确定关系分配细化成本，在相同误差/时间下优于这些方法。

这条的优势是正确性目标清楚；风险是很容易重新实现一个普通ball tree，或者只比未经优化的Python DBSCAN快。NaGB-DBSCAN改善了自适应邻域，SAGBC已结合结构连接，均是粒球侧的必要参照。

### 4.4 最先检查什么

在实际GB-DBSCAN分区上记录：可能导致误合并的球对、核心点分类变化、需要回到点级检查的比例，以及不同球大小下误差—耗时曲线。将全量细球、随机细化、按半径细化、按连接不确定性细化做配对比较。

另与优化的DBSCAN/HDBSCAN、BLOCK-DBSCAN、AnyDBC比较完整成本。HDBSCAN目标不同，只作实际聚类质量基线；不拿它作为固定epsilon的等价性参考。

建议推进条件：需要精查的区域确实稀少，并能用少量细化明显修复误合并；相同质量下比强加速对照节省有意义的时间/内存。若大多数球都需拆回点，或通用树索引等好更简单，则停止开发此实现，不将整个几何压缩领域判死。

## 5. 第三候选：分类压缩保留稀有子群，而非简单保留少数类

### 5.1 问题

一个故障类别有100个样本，其中90个来自常见工况，10个来自另一个真实工况。仅保证“故障类总共留下20个样本”仍可能全部选自前90个。类间数量平衡了，类内的小区域却消失了。

GBG++删除单点球提供了具体可审计入口，但不是已经证实其在这种数据上失败。GBS会保留边界真实样本，INGB、EvoSampling和小子群过采样文献已处理相关问题，因此不能宣称“首次保护少数类”或“首次兼顾噪声”。

### 5.2 最简设计

把压缩单位从“类别总配额”细化为“有训练证据支持的类内局部子群”。在固定保留样本数下，密集重复区域多压缩，小而有内部支持的区域少压缩；用真实成员作为代表，候选边界点暂缓删除。首先比较保留所有orphan、类别分层抽样、类内k-means代表和原GBS，不能用复杂方法打一个可以一行修好的缺陷。

粒球在这里是分配保留预算和存储局部证据的单位。要证明树层次在成本/恢复上有用，不能只证明聚类后分配样本有效。

假设：小子群具有多个彼此相近的可信训练样本；标签污染不是完全按整个小子群一致翻转。若一个纯净小子群和一个一致错标的小子群在观察数据中完全相同，无额外信息就不可辨识。

### 5.3 诊断与排序

先做干净标签分类压缩，确认小子群被删及测试召回损失，然后才加入训练标签噪声。所有缩放、构球、采样在训练折内部完成；测试保持原始分布，不重采样；禁止测试标签参与子群保留规则。

报告子群保留率、类/子群召回、宏F1或balanced accuracy、完整压缩与训练时间。固定至少两个不同分类器检验压缩器泛化，加入全数据强表格分类器作为实际基线。

若保留orphan或类内k-means配额已经同样有效，这个具体粒球设计就没有增加复杂度的理由。这条与已有工作重合较多、噪声/稀有边界较难辨识，因此只列第三，暂不启动。

## 6. 执行优先级与范围约束

1. 首选第一候选：审计SAGBC的抽样→构球→连边三阶段小簇覆盖。这一步即可区分抽样缺口与连边缺口。
2. 若第一候选缺口存在，先测朴素代表覆盖修复，并让k-center等强简单控制先上；有增量后再设计预算交换算法。
3. 若覆盖不是瓶颈、连边是瓶颈，研究第二候选。不是看到结果不好就无条件换模块。
4. 第三候选只在明确转向监督分类压缩时立项。

本轮没有预测哪条必然达到CCF-B，也没有宣称传统粒球天然优于非粒球方法。当前推荐的依据是：问题明确、能定位到具体决策、与现成文献/代码衔接好、首轮证伪成本低。

## 7. 证据状态

**已核实**：上述原文规则、SAGBC公开示例关键代码、若干强先例存在、抽样遗漏概率公式与示例数值。

**合理机制解释**：稀有结构可能在抽样、合球或连边时丢失；按几何范围批量判定可能省计算；删单点球可能误伤某些真实小子群。

**尚未验证**：这些缺口在目标真实数据上的频率；建议修复是否胜过强简单基线；局部审计成本；粒球相对其他微簇是否有额外价值。

**不从旧负结果推导**：旧的深度表示/图噪声结果不能证明本轮三条必败；本轮传统聚类先例也不能反过来撤销旧路线的停止决策。
