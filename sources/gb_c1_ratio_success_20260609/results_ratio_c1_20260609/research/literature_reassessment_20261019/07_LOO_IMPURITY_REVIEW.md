# 对留一不纯度与成本优先建议的独立复核

日期：2026-10-19。关联：05_DESIGN_REASSESSMENT.md、06_THEORY_WORKING_NOTE.md。

结论：采纳成本核算优先；将留一不纯度 U 加入第一优先级候选目标，与 D、D+Gini 比较。它去掉普通经验 Gini 的自配对效应，且对固定分区具有明确的噪声关系，但没有自动解决小支持、选择偏差、全部碎片化或实际高噪声回退。尚未开展模型训练，本次只有有限枚举和代数验证。

## 1. 准确定义与证明

n_B 指球内训练标签数量，不是球内所有节点数量；c_Bc 是带噪训练标签的类别计数。定义 a=1−1/C。

- n_B≥2：U_B=1−Σ_c c_Bc(c_Bc−1)/[n_B(n_B−1)]。
- n_B=1：约定 U_B=a。它是缺少成对证据时的先验代价，不是从一个标签估计出的纯度。
- n_B=0：标签代价 n_B U_B=0，无需定义 U_B；仍保留几何/关系代价。

对 n_B≥2，有 U_B=n_B Gini_B/(n_B−1)，也有 U_B=1−(1/n_B)Σ_i r_{i,z_i}，其中 r_i 的分母为 n_B−1。这确实与 GB-LCSS 的留一计数相联系。

固定图、干净标签、训练位置和分区，设各节点独立受到同一对称标签噪声污染，错误类别在其他 C−1 类均匀选择。令 γ=1−Cη/(C−1)。任意不同节点满足：

E[1{z_i≠z_j} | y_i,y_j] = γ² 1{y_i≠y_j} + (1−γ²)a。

对球内不同节点对取平均，再按 n_B 加权，得到：

E U_noisy(P) = γ² U_clean,LOO(P) + (1−γ²)a L，

其中 U(P)=Σ_B n_B U_B，L=Σ_B n_B。单标签球在左右两边都用 a，因 γ²a+(1−γ²)a=a，等式继续成立。

**clean 项必须是相同定义的干净留一不纯度，并沿用单标签球先验；不能换成普通干净 Gini。** 单标签先验使等式闭合，不意味着获得了单样本真实不纯度的无偏估计。一个样本统计量的期望对类别概率是线性的，而总体 Gini 是二次函数，因此不能无条件由一个样本无偏恢复。

对于 D(P)+β U(P)/L+λ|P|，噪声下期望为 D(P)+βγ² U_clean,LOO(P)/L+λ|P|+常数。因此：无需知道 η 即可计算评分；但标签项相对于 D 和复杂度项的权重仍随 η 改变，不能宣称整个联合目标的最优切面不变。

### 2.1 不再单调奖励细分，不等于禁止碎片化

反例：C=3，父球仅有两个不同类别的训练标签，父球 nU=2；拆成两个单标签球，总代价为 2×(2/3)=4/3。因此留一目标仍可能奖励拆成单标签球。准确结论是去掉普通 Gini 的系统性自配对优势，而不是所有细分偏好都消失。预算/复杂度、最小标签支持以及先验敏感性仍需保留。

单标签球也不等于单节点球。可能有许多无标签节点却只有一个训练标签，报告中两者必须分开。

### 2.2 期望失去区分力，不等于实际自动退回 D

C=3、η=2/3 时噪声标签完全均匀，已不包含真实类别信息。两标签球 U 是成功概率 2/3 的 Bernoulli 变量，方差为 2/9，并不趋于零。

在预先固定的四节点树上，只允许根球与两个二节点子球两个切面：两种固定切面的期望代价都是 8/3；按照观测标签选择较小值后，期望代价变成 2.271605；有 2/9 的概率子切面得分严格更低。这是没有真实标签信号时仍出现的选择性改善。

因此严格陈述应为：噪声增大至 γ=0 时，固定分区标签风险的期望差异消失。若要让实际算法退回无标签分配，需要另行控制支持、稳定性或选择复杂度。固定无标签树只隔离候选生成，不能消除用同一批标签选切面的偏差。

## 3. 三分类循环 pair 噪声是特殊情况

一般类别转移矩阵 T 满足 E[1{z_i≠z_j}|y_i=a,y_j=b]=1−(TTᵀ)_ab。

若 TTᵀ=κI+(1−κ)11ᵀ/C，则同样得到 κ 倍干净成对不一致率加常数。对称噪声是 κ=γ² 的特例。

三类循环 pair 噪声 T=(1−η)I+ηS 恰好满足该条件，κ=1−3η+3η²。η=.4 时 κ=.28，因此表格的 pair 排序也有严格代数依据，并不只是偶然的数值结果。

但四类循环 pair 噪声在 η=.4 时，不同干净类别对的观测不一致概率分别可以是 .76 和 1，已不存在统一的正比例缩放。后续应包含 C≥4 的循环 pair 与非循环转移，不能把三类例子推广到任意类别依赖噪声。

这是本轮独立推导及枚举核查，不据此声称新的统计学定理或优先权。

## 4. 文献核查边界

已读取 Andreas Tiffeau-Mayer, “Unbiased estimation of sampling variance for Simpson’s diversity index”, Physical Review E 109, 064411 (2024)，DOI 10.1103/PhysRevE.109.064411，正文开头与估计量/方差推导部分。其 Eq. (2) 使用 Σ n_i(n_i−1)/[N(N−1)] 估计同类概率，并追溯 Simpson (1949)。因此本任务的不一致率是其补量，不能声称首次提出该估计量。

来源：https://link.aps.org/pdf/10.1103/PhysRevE.109.064411

注意该文的多项式抽样设定，与本报告条件于固定干净节点标签、独立翻转噪声的设定不同；其采样方差公式不能未经检查直接搬到图节点上。

检索还出现 “Unbiased variable importance for random forests” 等树模型工作，但本轮未成功核查方法全文，不把它写成已证实采用同一粒度目标的先例。后续联网请求多次返回 HTTP 429，故本轮**没有完成**“无偏不纯度在带噪决策树/图粗化中的直接使用先例”的穷尽检索，也没有得出没有先例的结论。

已有36篇文献复核中的鲁棒树、MRGC、SGBGC等仍是直接相关边界，见05与逐篇卡片。新贡献应落在问题与计算组织、粒度分配及其可验证作用，而非经典估计量本身。

## 5. 成本核算优先，但需要拆开架构与压缩收益

同意先用便宜的现成划分在 ogbn-arxiv 上做成本试验，暂不开发完整新方法。至少覆盖以下配对：

| 训练组织 | 原图/原节点 | 粗图/球 |
|---|---|---|
| 每轮传播 | 相同配置的 GCN | 对应粗图 GCN，显式说明传播定义 |
| 预计算关系特征 | SIGN 或相同多通道分类头 | 聚合同一批缓存特征，训练相同分类头 |

SIGN 对照必须按真实监督节点数 L 训练，不为比较方便每轮遍历 N 个节点。粗分类头对应 M_+ 个有标签球。只比较原图 GCN、SIGN、粗图 GCN，难以辨别收益来自压缩还是架构替换。

记录：预计算、构树、标签计数/选切面、聚合、训练、验证与推理；总墙钟与峰值显存；固定训练预算结果及达到可比精度所需时间。若粗图参数在原图评估，原图前向必须计入。粗边数也需记录，因为少节点不保证足够稀疏。

单次任务与摊销结果分别报告：无标签候选树和固定图特征可能复用；随训练划分或噪声种子变化的标签依赖切面、球软标签需要重算。仅初始化种子变化且标签/超参数不变时，可按实际情况复用切面。

不预设 ogbn-arxiv 必然超出 12GB；内存由具体模型、精度、实现和训练方式决定。“只有装不下或反复训练才有收益”也过强；即使能装下，训练迭代、密集监督或全节点鲁棒损失仍可能有压缩价值，需要实测。

若 L=.2N、M=.05N，则 L/M=4；这是所有球的平均标签量，并非每球或每个有标签球恰好4个。后者为 L/M_+，并且支持分布可能高度不均。实际比例应从所用数据/配置核对，不能把20%当所有 NoisyGL 设置的固定事实。

## 6. 更新后的实验顺序与最小方法

1. 成本核算：验证在可比精度下，粗化能否改善时间/显存；先解决是否值得开发的问题。5倍加速、2pp容忍可作为预注册目标，不能当所有数据集的普适科学阈值；同时看完整精度—成本曲线。
2. 缺口核查：SGBGC 作者默认流程与保持目标任务 train/val/test mask 的适配版分开报告。默认流程结果不能直接拿来与原协议基线排名。此前代码审计中，球级划分有重随机；原节点 split_test 的60/20/20是顺序划分，不能统称原节点重新随机划分。验证标签参与候选构造的代码事实应精确说明所在流程，不外推为对已发表全部实验的判断。
3. 固定候选树、表示、预算和骨干，比较 D、D+Gini、D+U；保留必要的最小支持/复杂度约束。clean-Gini oracle 与 clean-U oracle 都加，分别隔离目标定义和噪声影响，均仅作诊断，不进入方法或超参选择。
4. 如果 U 的收益随更强支持约束消失、或与 D 相当，不能把经典校正强写成核心创新；若稳定改善粒度配置并改善精度—成本曲线，再深入可靠性分析。

最小算法仍为：属性与关系通道 → 固定无标签候选树 → 按 D+U 及计算约束选择切面 → 构造 H、R、P_c=RPH 和训练标签软目标 → 球级训练 → 按预定部署方式在原图评估。

主线描述：在有限计算预算下，通过可解释的粒度分配，减少带噪标签诱发的过度细分，并保留有用的节点属性与关系差异。当前是待验证假设，尚未证明抗噪或加速有效。
