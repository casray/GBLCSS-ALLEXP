# 1080项实验后的路线裁决与候选重设计

日期：2026-10-20。性质：实验后分析与待评审设计，不是新算法已成功的报告。本轮没有启动新训练。

后续优先级修订：用户转来Claude算子分析后，实际GCN的前向/损失/梯度核验支持粗图训练与Pi P Pi节点训练的条件等价。LLP不再作为优先候选，本文72项草案不启动；先做算子与dropout分解、通用正则及GCE插件资格赛。修正和边界见`10_CLAUDE_OPERATOR_REVIEW_20261020.md`。本文保留历史推理，不改写成已实施计划。

## 1. 裁决

停止把当前“D+留一继承不纯度分配粒度、粗图训练、原图部署”的完整组合当作新论文主线继续优化；停止R3权重扫描、置信门控和交叉拟合救援；当前证据不支持高效这一主要卖点。

这个决策针对当前规格，不推出所有图粗化都无价值。保留无标签球级GCN在部分高噪声条件下的正则化线索，但不靠挑选这几个条件来延长现有方案。

建议只保留一个低成本、可证伪的转向候选：保留节点输入、传播与逐节点输出，让粒球只约束一组预测的总体分布，而不是让球内节点共享相同输入或相同软目标。它与标签比例学习直接相关，尚不足以独立立项；先验证机制，再决定是否继续。该候选也失败时，停止当前粗粒度监督路线，而不是立即再换编码器或堆模块。

## 2. 实验依据及解释边界

主证据：`experiments/budget_gb_coarsening_20261019/analysis_20261020/results/REPORT.md`及同目录配对表。1080/1080完成，三个种子；保存预测、配置、来源哈希与重算指标通过。下列是同seed差值，单位pp。

| 证据 | 观察 | 支持的判断 |
|---|---|---|
| 当前标签评分R3 | 八个图×噪声×骨干单元等权均差−0.033 | 当前标签项无一致分类增量，不继续校正评分救援 |
| 干净训练标签选切面O2 | 整体+0.281；Cora pair/GCN−3.184，CoraFull pair/GCN+1.828 | 评分代理与最终任务不一致；O2不是性能上界，不能否定所有任务感知划分 |
| CoraFull | 两骨干所有四标签条件，M/N=.3仍低于原节点A | 单靠增加球数没有修复当前压缩与训练迁移损失 |
| CS clean GCN | 冷成本19.66→31.65秒；完整显存0.672→0.719GiB | 当前完整流程没有优势；不能用单轮快代替总成本 |
| GCN CiteSeer u0.6 | C−B +5.813±1.960，C−LCSS +5.226±1.489 | 存在超出当前目标平滑的组合机制信号，不能唯一归因于输入共享 |
| GCN Cora u0.6、PubMed u0.6 | C−B分别+4.134±1.453、+4.024±3.009 | 高噪声条件值得研究，但不是跨图统一收益 |
| Photo/缓存MLP u0.6 | C−LCSS −7.588±2.694 | 共享机制也可能造成明显损害，不能泛称共享就抗噪 |

本批没有同协议正式重跑ERASE、ProCon、GD²、官方SIGN或SGBGC，因而不能据论文原表或历史异容量实验断言当前方法已被所有强方法超过；同样，也没有证据支撑与它们竞争。无需先补齐整个排行榜，才允许停止当前规格。

解释分层：

- 已支持：当前R3无一致收益，当前成本门槛未过，CoraFull压缩损失持续存在，部分高噪声GCN条件C优于B/LCSS。
- 合理解释：共享训练限制了逐点拟合自由度，同时抹掉部分真实差异；纯度评分不等于可学习任务风险。
- 尚未验证：上述收益究竟来自粗传播、输入共享、训练/部署分布变化还是它们的组合；新候选是否保留收益。
- 被负结果削弱：只需把球分纯、分多，便能统一解决当前问题。

补充支持量审计（seed0、GCN、clean、主预算；不是三seed平均）：CiteSeer L=665、M=333，其中66球无训练标签、88球只有1个训练标签；CoraFull L=3958、M=1979，其中516球无标签、569球单标签。主设定每球平均约2个训练标签。因此把所有叶球统计都称为稳定粗粒度证据并不成立。球内全部节点多，不等于球内可用监督多。

## 3. 三条路线的取舍

| 路线 | 与证据的关系 | 决策 |
|---|---|---|
| 继续现有高效粗化，换评分/调预算 | R3、O2与完整成本三方面都缺乏足够支持 | 停止当前主线；大图仍可能有价值，但本项目不为救主张立即下载大图重开大矩阵 |
| 学习投影、补节点残差、任务梯度匹配 | 可以针对压缩损失；ACE/GCond/MRGC已有直接方法依据，成本与噪声拟合也会增加 | 暂不选；不是因为有先例，而是当前没有证据证明新增复杂度有项目回报 |
| 节点预测不压缩，粒球监督从逐点复制改为总体约束 | 直接移除“同球所有人应相似”的约束，同时保留群体标签统计 | 推荐唯一小规模候选；先作为机制实验，不能直接宣布新论文方向成功 |

不选择强化学习生成球、自编码器换空间、新教师蒸馏或多门控融合。它们并未直接回答本轮暴露出的“共享监督是否误伤真实个体差异”问题。

## 4. 候选问题与粒球角色

问题：带噪节点分类中，怎样利用局部群体监督抑制对个别标签的依赖，同时保留同一区域内真实的类别混合与节点差异？

旧GB-LCSS组织别人给节点的投票，生成逐节点修正目标；当前粗图方案进一步共享输入和预测。候选改为：节点仍分别分类，粒球只限定一组预测合起来应是什么分布。

例子：球中有60% A、40% B，不要求每个成员都预测[.6,.4]，而允许一部分节点偏A、另一部分偏B，且平均分布合理。这里60/40只是说明约束差异；真实方法只能看到带噪训练标签统计，不能假装知道干净60/40。

粒球是监督统计与约束单元，不是硬伪标签、强制正样本或实际计算超节点。中心/半径用于组织局部群体；如果随机组或其他便宜分区同样有效，不能把收益特指为粒球机制。新路线不承诺减少原图GNN的主要前向/反向计算。

## 5. 最小公式与流程

仅用X/A构建或复用无标签候选树；标签值不参与切面选择。训练集合T，L=|T|。对球B，S_B=B∩T，n_B=|S_B|；无训练标签球不贡献监督项。

节点输出：p_i=softmax(f_theta(X,A)_i)，每个节点保留自己的输入和预测。

观测球分布与预测球分布：

`q_B = (1/n_B) sum_{i in S_B} onehot(z_i)`

`pbar_B = (1/n_B) sum_{i in S_B} p_i`

注意两者都在同一训练节点集合计算，不能拿少量训练标签分布直接对齐全球全部节点预测，却不声明代表性假设。验证/测试节点的标签不进入统计；原图特征和边按转导协议使用。

原节点损失：

`L_node = (1/L) sum_{i in T} CE(onehot(z_i), p_i)`

匹配的逐点平滑对照：

`L_point = sum_B (n_B/L) [(1/n_B) sum_{i in S_B} CE(q_B,p_i)]`

候选总体约束：

`L_group = sum_B (n_B/L) CE(q_B,pbar_B)`

第一轮只比较两个相同混合权重的目标：

`F_point = .5 L_node + .5 L_point`

`F_group = .5 L_node + .5 L_group`

0.5是固定机制筛查值，不声称最优；不做权重网格。两者使用完全相同骨干、分区、初始化、训练/验证协议与训练标签，区别仅为先算每个节点损失再平均，还是先平均预测再算损失。F_point等价于固定权重的标签混合，不等于旧论文完整LCSS。保留现有A、LCSS与C作为外部锚；若使用新的监督尺度，正式比较旧LCSS也必须在该尺度补跑，不能混称完全匹配。

流程：原图输入→无标签监督区域→仅训练标签计数→原图节点前向→汇总训练节点预测→节点损失与组损失共同更新→原图验证和推理。没有粗图训练到原图部署的迁移，没有新增教师或强制同球拉近。

监督尺度应区别于计算压缩率。预定主诊断预算M=max(2,floor(L/16))，只按训练位置数量设定，使平均每球约16个训练标签；这不是每球最低16、也不是最优球数。复用同一候选树D-only切面，报告实际支持量分布。原M/N=.1作为第二尺度，用来检查平均仅2票时该机制是否退化。不能根据测试成绩在两个尺度中选择主结果。

## 6. 数学上确实改变了什么

由负对数的凸性，对任意固定球与正概率预测：

`(1/n_B) sum_i CE(q_B,p_i) >= CE(q_B,(1/n_B)sum_i p_i)`。

左侧在自由概率空间中要求每个p_i趋向q_B；右侧只要求平均预测趋向q_B。它是更弱的约束，不代表更好的分类器。

已数值核验的二分类例子：q=[.5,.5]，p1=[.9,.1]，p2=[.1,.9]，逐点平滑损失1.2039728043，总体损失0.6931471806，差0.5108256238。两人都输出[.5,.5]时，总体损失也为0.6931471806。因此总体损失允许差异，但不会自动鼓励判别差异；节点骨干和节点监督仍然必要。

更严重的反例：若模型完全记住每个训练节点的观测标签，则球内平均预测恰好匹配观测q_B，组损失同样最优。因此该目标不从数学上禁止记忆噪声；若有效，来自共享模型、数据关系、有限训练等归纳偏好，而不是新损失保证已经去噪。

固定球、固定干净标签、节点噪声条件独立时，单一类别观测比例的方差为`sum_i Var(onehot(z_i)_c)/n_B^2 <= 1/(4n_B)`。这只说明聚合可降低人工翻转的随机波动。令T_noise[a,c]=P(z=c|y=a)，则`E[q_B]=q_B_clean T_noise`。对称噪声时为`gamma q_clean+(1-gamma)u`，gamma=1-C eta/(C-1)，u为均匀分布；pair等噪声没有这个统一缩放形式。聚合不消除系统偏差，不输入真实eta，不以此方差公式证明训练后分类风险下降。

## 7. 文献定位：已有方法提供工具，也指出失败边界

此前五领域36篇卡片继续有效，本轮不是重新声称精读全部36篇。以下做定向原始来源复核：

1. [ACE，UAI 2026正式页](https://proceedings.mlr.press/v337/li26j.html)：已研究粗化信息丢失，学习投影、结构正则及全图辅助任务。说明“补回残差”有具体依据，也意味着不能仅添加一个全图分支就声称解决新问题；未知噪声标签下的代价需另测。本轮核对正式摘要，完整机制沿用前轮卡片。
2. [MRGC作者全文](https://arxiv.org/html/2510.26451)：包含结构/特征/标签攻击下鲁棒凝缩，不能说标签噪声压缩无人研究。它是合成图凝缩与几何正则路线，不是当前真实节点群体约束。
3. [GNN-CFGD正式页](https://www.sciencedirect.com/science/article/pii/S0893608025002175)：其粗细划分指GMM区分干净/含噪节点、进一步按置信细分并重建连接，不能误读成把节点压成超节点的多尺度粗化。
4. [DnD-Net作者代码](https://github.com/kaize0409/DND-NET)：已把传播与可学习部分解耦处理图标签噪声。说明“加一个更便宜的MLP”不足以形成效率贡献；它与GD²是不同论文。
5. [EasyLLP，NeurIPS 2023](https://papers.neurips.cc/paper_files/paper/2023/hash/3085fd61063840fdb2e6eafac58589f8-Abstract-Conference.html)：组比例可用于实例级学习，但其去偏理论有特定袋采样假设，不能直接套到图上自适应几何球与噪声比例。本轮核对正式摘要，不声称重读完整证明。
6. [Learning from Label Proportions by Learning with Label Noise，NeurIPS 2022](https://papers.neurips.cc/paper_files/paper/2022/hash/ac56fb3fab015124b541f6299016a21c-Abstract-Conference.html)：把LLP化为带噪标签学习，采用forward correction；不是证明任意带噪球比例都可直接当干净监督。本轮核对正式摘要及作者HTML问题设定。
7. [LLP-PVC，ICLR 2026正式页](https://proceedings.iclr.cc/paper_files/paper/2026/hash/6fc46679a7ba2ec82183cf01b80e5133-Abstract-Conference.html)：直接指出均值比例匹配可能缺少实例判别力。其比例值分类是已有改进方向；本轮只读正式摘要，不能直接移植其理论。
8. [GLLP公开投稿PDF](https://openreview.net/pdf/f077cf4e358b91383dd00cb1dc395d89056f15af.pdf)：本轮读取摘要、引言和问题分解。已研究图上标签比例学习，提出同配感知OT伪标签；其中纯KL均值对齐较弱。读取的是标注ICLR 2026 under review的版本，未核正式录用状态，不把它称为正式ICLR录用论文。其无逐节点监督、给定袋比例的设定与我们有带噪训练节点标签不同。

因此，新贡献不能是“第一个图上球级比例损失”。潜在贡献只能是：分析逐节点共识与粗输入共享的偏差，设计适合带噪标签和混类区域的监督粒度，验证它确实比同权逐节点平滑、随机群体及强鲁棒方法更有效。若只是在旧方法上加普通组CE且无清晰增量，不值得扩为新论文。

## 8. 限量验证草案：最多先72项，不直接开跑

目的：判定从逐节点复制改为总体约束是否有真实增量，不是搜索最好分数。先用CiteSeer（现有正信号）和CoraFull（现有负信号），clean/u0.6/pair0.4，seed0/1/2，同一GCN。两监督尺度、F_point/F_group两个新臂，共2×3×3×2×2=72项。主要尺度固定L/16，原.1N尺度仅作敏感性分析，不能按test二选一。

原图划分、噪声映射、hidden、优化器、验证频率、早停保持v2；新版本独立目录，修复小数噪声缓存键后再执行。改变骨干、表示、噪声损失、划分和训练时长都不在首轮范围。所有预注册细节须在实施前冻结。

建议推进门槛（现在是供评审的筛查标准，不是已冻结且已执行的实验）：

- 主尺度u0.6，两图F_group−F_point均至少+1pp，且各至少2/3配对seed为正；同时CoraFull至少比当前A高1pp，不能只靠让F_point退化形成优势。
- clean相对A平均损失均不超过1pp；pair相对现有完整LCSS不能系统退化超过1pp；报告macro-F1和逐类召回，避免平均精度掩盖少数类损失。
- 若不满足，停止本候选，不加温度、门控、教师或更换GRACE救援。若仅一个局部条件成功，记为线索，不据此放宽门槛。

通过后才补：Photo压力测试、同训练支持量的随机分组、相同新分区的完整LCSS、简单鲁棒损失及至少一个直接相关强鲁棒方法；最后才动WikiCS确认图。随机分组在组损失中需匹配训练支持量；现有粗图D只能作为背景，不能替代该对照。用户此前暂缓kNN/k-means，对此不自动扩工作量；没有这些对照时不声称粒球不可替代。

主记录：配置、所有来源/分区/目标哈希、原始日志、逐节点预测、配对mean/std、全部准备/训练/验证/推理成本，以及新增实验方向历史。不把监督汇总的线性复杂度当作相对普通GCN的整体加速。

## 9. 项目资源决策

当前规格退出主线；一个小候选保留学习价值。不建议现在为了高效口号扩大到ogbn-arxiv，也不立即开启“异配+噪声+粗化+对比+蒸馏”的综合方法。

如果新候选通过有限筛查，再围绕“混类区域中的群体监督与节点判别”立项；如果失败，应另选有直接基线缺口与数据依据的问题，允许不再坚持粒球。此时需要新的问题诊断，不把已有负结果换一个名称重跑。
