# 对Claude算子解释与实验清单的独立审查

日期：2026-10-20。状态：已查实际代码并完成小型CPU float64前向/损失/梯度核验；未启动新的数据集训练。本文调整研究优先级，不是冻结后的实施PLAN。

## 1. 裁决

将后续优先级调整为：算子等价性→投影与dropout分解→便宜通用正则及GCE插件→通过门槛后才扩大强鲁棒方法比较。LLP总体分布监督从上一轮的优先候选降为备选，72项草案不启动。

原因是算子视角直接重写了已有正信号，而LLP没有项目内正信号。该判断不以“LLP在数学上不可能有效”为前提。继续停止R3评分与当前效率主张；只给原有C的训练视图机制一次有停止条件的验证，不恢复粒度调参。

## 2. 等价式在当前实现成立

代码：experiments/budget_gb_coarsening_20261019/v2/run_arm.py，GCN.forward。

实际模型为两层带偏置Linear，每次Linear之后左乘传播矩阵，第一层传播后ReLU与隐藏层dropout。没有BatchNorm、残差分支或粗图重新归一化。prepare.py构造对称度归一化的P；run_arm.py直接使用Pc=RPH。

令H为硬归属、R=(H^T H)^(-1)H^T、Pi=HR、S=Pi P Pi，则RH=I、Pi H=H、H1=1，且点式激活与H复制可交换。共享球级dropout时：

`H f_theta(RX,RPH) = f_theta(X,Pi P Pi)`。

偏置不破坏本实现的等价性，因为H复制仿射变换仍是相同节点仿射变换。Claude展示的无偏置表达式可以扩展到当前带偏置计算，不需要把模型改成bias=False。

CPU核验使用真实GCN类，N=15、M=4、输入5维、隐层7、3类，非等大球，非零偏置，显式相同的球级mask，seed47：

| 检查 | 最大绝对误差 |
|---|---:|
| 粗图logits提升与S节点实现 | 5.551115123125783e-17 |
| 粗图加权soft CE与节点B目标CE | 0 |
| 参数梯度 | 2.7755575615628914e-17 |
| S下自身观测标签A与B目标的CE | 0 |
| S下A/B目标的参数梯度 | 1.3877787807814457e-17 |

最后两项还说明：当最终logits球内恒定时，按合法训练节点自身标签计算CE，恰好等于按球计数计算soft CE。目标平均并不是此时额外加入的一项独立去噪操作。该事实不保证球目标正确，也不保证P部署时的节点预测正确。

以上只证明固定参数/相同mask下的实现等价。不同矩阵乘法顺序的浮点误差，在长程Adam、ReLU与离散检查点选择中可以放大。正式核验应比较logits、loss、gradient及少量配对更新，不要求数百轮训练的最终准确率逐数相同；更不能用同seed代替显式相同mask。

## 3. C−B仍未完成唯一归因：dropout不是旁注

现有B在N个节点上独立dropout；现有C在M个球上独立dropout，提升后同球共享mask。因此C与节点S+共享mask等价，但实际C/B比较仍同时改变了训练算子和dropout相关结构。

S的第一层输出在dropout前球内相同。如果改为逐节点独立mask，下一层S中的右侧Pi会将这些mask平均。球含s个原节点时，保留概率为1-d的缩放Bernoulli mask均值方差为d/[(1-d)s]，而共享mask方差为d/(1-d)。这与训练标签支持量不同：这里s是球内全部节点数。故两种dropout的随机正则强度不能默认相同。

最低限度补齐四个角：P/逐节点mask（已有B），P/球共享mask（新控制），S/逐节点mask（新控制），S/球共享mask（与C严格对应）。随后做单侧投影时统一mask方式，避免把投影效果与mask改变混在一起。

算子重写把当前变化统一表达为训练视图，是实质性澄清；它本身没有证明收益唯一来自“传播前输入平均”，也不证明任意数据上都抗噪。

## 4. 单侧投影和缓存MLP的准确解释

建议分解保留：P、P Pi、Pi P、Pi P Pi，统一用B目标、统一原图P验证与测试。每一层均使用选定算子。

- P Pi：每次消息传播之前投影，而不是仅对网络最初输入平均一次。
- Pi P：每次消息传播之后投影，而不是仅对最后logits投影一次。
- Pi P Pi：每层传播前后均投影；中间有非线性及dropout，不能随意挪动Pi。

缓存分支令F=[X,PX,P^2X]。其正确等价是`H MLP(RF)=MLP(Pi F)`（球共享mask），不是`Pi MLP(F)`。投影在预计算传播之后、可学习MLP之前，而且原始X通道本身也被平均。CPU使用同一CachedMLP类核验前者误差为0。

两骨干差异还包括拼接多跳特征与逐层传播的位置，不能仅据GCN强、缓存MLP弱，就唯一断定传播前平均是关键。单侧投影消融才回答这件事。

大图实现不显式生成N×N的Pi或S。使用Pi Z=H(RZ)、SZ=H[R P H(RZ)]的聚合/广播与稀疏P；粗图仍可作为S+共享mask的计算实现。

原图P与S双视图诊断应使用同一个主要checkpoint，不能把分别选出的primary与secondary检查点当成同参数的迁移差异。

## 5. LLP的优先级可以下降，但反对中的三个推论不成立

1. 训练节点总体匹配不阻止记住错标，这一点成立，09草案已明确给出反例。但CE组损失的最小值是H(q_B)，一般不为0；KL才以0为最小值。不影响“错标插值也可使组项最优”这个核心批评。

2. 平均概率匹配不等于固定比例的节点必须分类错误。反例：一个真实全A的三分类球，均匀翻转eta=.6，期望观测比例为[.4,.3,.3]。所有节点均输出[.4,.3,.3]，平均比例完全匹配，argmax却全部为A。因此不能说“强制60%预测为非多数类”。这不证明LLP一定有效，只是否定该不可能性论证。

3. F_group与F_point的最终准确率没有一般大小关系。Jensen只能比较同一组固定预测下的损失值；不能比较两种训练得到的分类准确率。F_point推向球多数类，仅在多数类对该节点正确时起去噪作用；对混类球中的真实少数类会引入偏差。

未知噪声转移使比例学习困难，这一点应保留。但并非必须显式乘T逆：forward correction使用T乘预测，backward correction才用T逆；特定对称噪声下还可保留类别排序。来源：Patrini等，CVPR2017，https://openaccess.thecvf.com/content_cvpr_2017/papers/Patrini_Making_Deep_Neural_CVPR_2017_paper.pdf 。不将这句话外推为未知T下必然可辨识。

此前多次监督区域实验负结果约束各个具体构造，不能作为所有群体监督方法无效的证明。当前不跑LLP的充分理由是证据优先级，而不是数学不可能性。

## 6. 实验清单的修正建议

### A0：已完成的代数核验，后续补小规模GPU/优化步核验即可

已验证当前带偏置模型、共享mask的前向/CE/梯度等价。不为了证明同一个恒等式重复训练整张数据矩阵。正式实现前补float32设备误差及数步Adam配对；定义绝对/相对误差，不把长期准确率相等设成必要条件。

### A1：先完成有限算子资格赛

保留四个正信号单元：Cora u.6、CiteSeer u.4/u.6、PubMed u.6；两个负信号单元：Photo u.4、CoraFull u.4。它们涉及五个图，clean应补五个图，合计11个条件，不能写“四图clean”。全部三seed，同协议、同主要验证checkpoint。

先用CiteSeer u.6、CoraFull u.4及对应clean做小范围核验/资格赛，再决定是否展开11条件全表。该小范围只是筛查，不替代完整结论。R3/O2和粒度搜索均不回归。

算子分解统一B目标、同一种mask；另以P/S×独立/共享mask检查随机正则。分区对照固定同M、同候选坐标与通道归一化，k-means固定初始化次数/seed，记录支持量、SSE、粗边和完整成本。随机D只能说明语义分区优于当前随机分组，不能替代k-means。

通用正则：统一标签平滑须写明epsilon（可预定.1）、GCE取q=.7；这两个值是固定文献参考配置，不是图任务通用最优值。GCE原文采用.7的依据已核：https://papers.neurips.cc/paper_files/paper/2018/file/f2925f97bc13ad2852a7a551802feea0-Paper.pdf 。Mixup还必须固定在哪一层混合、如何处理图关系、配对范围及标签混合；仅alpha=1没有定义完整图算法。图Mixup原文专门处理混合与消息传播干扰，不能拿错误的直接输入混合做弱对照：https://bhooi.github.io/papers/mixup_web21.pdf 。

### A2：GCE插件提前，使用匹配的二因素比较

至少比较P+CE、S+CE、P+GCE、S+GCE。CE与GCE都用训练节点同一自身观测标签，算子比较固定mask规则；S中CE自身标签与球soft目标等价。插件增量比较S+GCE减P+GCE，不能减P+CE。

如果粗图实现GCE，正确的球风险是sum_c q_Bc(1-p_Bc^q)/q，不是(1-(q_B^T p_B)^q)/q；两者不同。第一种是原始训练标签GCE的计数聚合。

这一步应提前，因为“单独不超过最强通用正则”不排除互补。只有单独无实际优势、且这个预选的廉价插件也无增量时，才停止当前算子候选。不继续找几十种组合救援。

### B：强方法与插件必须分阶段

ERASE/ProCon/GD²/TFR全量比较为4方法×5图×3噪声×3seed=180次，未包含任何插件。建议先重跑少量预选方法/条件，A1/A2有价值才展开完整表。

历史seed0不是当前强排名依据：不只参考GCN隐层64与当前256不同，旧TFR隐层16、ERASE隐层256且表示512；训练预算、骨干、预处理也不同，三seed均值与单seed不能计算正式胜负。历史时间3～9倍也不能当当前同成本结论。

S直接适配当前固定线性传播GCN；ERASE的GAT注意力、其他方法的边重构/视图/伪标签模块，不能不加说明地统一替换为S。按骨干兼容性在看新结果前选一个插件对象，写清替换位置和保持的原损失。必须比较该方法与该方法+插件，不只比较S与普通GCN。

## 7. 建议的裁决措辞

| 观察 | 合理决策 | 不能推出 |
|---|---|---|
| 单独不如通用正则，S+GCE也无增量 | 当前规格停止 | 不同正则的机制在数学上相同 |
| k-means与粒球数值接近 | 不主张粒球独有抗噪性；必要时定位簇投影训练 | 3seed无显著差异证明统计等价 |
| 机制配对成立且对预选强方法有可重复增量 | 有资格继续立项，补独立确认与更广比较 | 已经证明独立论文贡献或普适SOTA |
| 低于鲁棒方法且无插件增量 | 当前路线停止，不加新模块 | 所有任务或所有粒度永远无效 |

“至少一半带噪条件提升1pp”可作为实践推进门槛，但须在跑前固定分母，例如五图三噪声的15单元至少8个；提升指同方法插件配对mean，另报告各seed差值/std和clean损害。不能结果出来后改为只计高噪声或只计成功图。不将阈值当显著性检验，也不把通过资格赛直接命名为“主线成立”。

仅在资格赛通过后，才讨论哪些球该投影、哪些应保留细粒度；当前不提前设计门控或粒度评分。
