## 2. 2026-09-30 投稿版真正做了什么

题名：**Granular ball local consensus for graph-free node classification under label noise**。以本次 ZIP 中 `main.tex`、算法文件、表格文件及 `supplementary.tex` 为准，不以六月的 SoftDist [X‖H] 摘要代替最终稿。

完整流程：

1. 在全图 X、A 上做不使用类别标签的 GRACE 预训练。
2. 冻结编码器，取投影头之前的输出，L2 归一化后形成表示 G。
3. 在 G 中按平均半径下降进行递归 2-means 分裂；每个节点只属于一个球。默认最多 64 球、子球至少 32 节点、相对半径改善至少 0.05。
4. 对训练节点 i，只统计同球内其他训练节点的观测标签，得到留一分布 r_i；至少需要两张其他训练票。
5. 当最大票类唯一时，以 β=0.5 将 r_i 与多数类 one-hot 混合成 q_i；平票保留分布。
6. α_i=(C max r_i−1)/(C−1)，软目标 t_i=(1−α_i)e_ỹ_i+α_i q_i；缺票时保留原标签。
7. 独立的 X-only MLP 在 t_i 上训练。GRACE 编码器和粒球不参与这一步反向传播。
8. 扩展实验用同一软目标训练 GCN 教师，再将教师全节点预测蒸馏到属性 MLP。

这篇稿件的贡献主体是**局部共识软监督及无图部署**。它使用 GRACE，但没有提出新的 GRACE 对比损失。训练时可见测试节点属性与边，属于固定图传导学习；不等于对全新未见节点的归纳泛化。

协议为原 NoisyGL 20%/10%/70% 随机节点划分，仅训练标签受污染，干净验证选模，测试标签只最终评价。主表五个下游配对 seed，每个数据集主要复用一份冻结表示；另外有三个预训练 seed 的敏感性研究。新方案不得把仅换下游种子误报成独立预训练重复。

主文结果的范围：五数据集、五噪声设置，对七个同部署 MLP 的含噪学习基线，最高均值为 24/25；这不等价于超过所有鲁棒 GNN。主文表5自己已经显示：GB、kNN、k-means 在四个数据集上接近，CoraFull 的 kNN/GB 为 40.50±0.51 / 37.39±0.51，差约 3.11 个百分点。因此“粒球不可替代”没有被现稿证明。

## 3. 本轮发现的两处重要历史纠错

### 3.1 C1 正式实验不是 InfoNCE 预训练

本轮遍历 `gb_c1_ratio_success_20260609/results_ratio_formal_20260609/` 的全部 **40 份 config.json**，每份均记录：

```text
ssl_objective = negfree
variant = negfree_bn
phase2_supervised_loss = ce
lambda_inter = 1.0
```

因此不能把这批实验直接写成“GRACE/InfoNCE + noisy CE 联合失败”。老历史文件11及聊天中的“GRACE预训练+GB微调”是过宽简称，应优先采用运行配置。

现存源码 `gb_c1_ratio_success_20260609/src/gb_stage_b/train.py` 中：第一阶段优化 SSL；第二阶段在约第313行组合分类损失、intra 和 inter；第二阶段没有 InfoNCE。所有正式运行的配置签名与 Stage A CSV 重算保存在 `sources/local_evidence_audit.json`。

### 3.2 0.80 与 0.57 不是微调前后的一对表示指标

同一源码约第370行的 linear_eval 调用，在第二阶段结束后，对最终表示用 `y_true` 训练新的 logistic regression；`eval.py` 中 `clf.fit` 使用传入的干净训练标签。`classifier_test_acc` 则评价已经在含噪/修正监督上训练的原分类头。

这属于不同监督条件和分类器的比较。它说明最终表示仍可能包含可被干净监督读取的语义，而原训练头未充分利用；不能单凭该差值证明编码器“从0.80被毁到0.57”。需要同协议的阶段前后固定探针，才能隔离表示质量变化。

这也不意味着使用干净标签的探针结果可作为可部署抗噪分类成绩。探针应明确标为诊断。

**溯源边界：** 本轮检查的是现存源码快照与历史运行配置/指标。没有发现可将当前源码 SHA 与当时每次执行逐字节绑定的完整执行证明，故不声称重新复现了所有历史运行。

## 4. 一个具体、尚未被因果验证的缺陷候选

现存 `gb_c1_ratio_success_20260609/src/gb_stage_b/losses.py` 约第259行：

```python
def inter_ball_separation_loss(centers, reliable_balls):
    ...
    sel = F.normalize(centers[reliable_idx], dim=-1, eps=1e-8)
    ang = torch.acos((sel @ sel.t()).clamp(-1.0 + 1e-7, 1.0 - 1e-7))
    return -ang[off_diagonal].mean()
```

函数没有类别或语义关系输入。最小化它会鼓励所有可靠球中心互相分开；被拆成多个球的同一类别也受到排斥。

这为“球身份与类别语义混淆”提供了直接实现线索。它还不是旧失败的唯一原因证明：球分裂、噪声监督、分类头、学习率、缺票均可能共同作用。新实验若研究此点，应单独对照删除所有球间项、保留原项、仅放松不确定关系、完整新关系目标，且匹配负对数量和损失尺度。

## 6. 证据等级与研究方向

**已经支持：** 当前稿的局部软监督有明确适用域；简单球关系不是通用类别关系；公平 kNN/KM 是必要对照；原生表示学习还需防止压缩和细粒度信息丢失。

**合理解释：** 某些不加区分的排斥关系可能与分类目标不一致；图消息传递造成邻居信息重叠，可能让局部票数高估独立支持。两点都需要专门诊断，不能包装成已测因果。

**尚未验证：** 由图编码器在线更新、以软语义关系区分不同球、保留节点差异的新粒球关系目标，能否在匹配训练预算和分组对照下带来分类收益。

**被负结果削弱：** 冻结H后反复换形状、换票源权重、相似度过滤、小范围负例抑制、叠固定区域蒸馏；单独去负样本或只把球压紧。

本轮方向建议必须围绕一个具体机制接受或拒绝，不能将以上文献和所有新模块同时装入模型后用一张精度表归因。
