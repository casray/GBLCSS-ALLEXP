## 二、对新图对比学习/噪声节点分类最重要的结论

1. **“粒球用于图对比学习”不能单独作为创新点。** GBGCL 已用粒球划分异配图的多粒度局部区域，并明确同球节点作正对、异球节点作负对；MGCF-Net 已在空间转录组的多视图图表示中做跨视图球级对比。SAGHL 则在同构静态图上组合结构引导球分解、超边、对比采样和分类，并由官方摘要声称缓解标签噪声。新方案需具体化差异机制和问题设置。

2. **最强潜在差异是“关系置信度/弱结构先验”，不是再造一套硬正负球对。** MGBCC、GFSAF、GBGCL、MGCF-Net 都将球关联最终转成明确正负样本或关联掩码；关系误判会成为错误监督。项目偏好应保留球作为局部关系单元、置信度信号、soft structural constraint 或 weak view teacher，不能无证据改成硬标签或强拉近约束。

3. **“噪声”概念必须拆开。** CGBC、GBmooer、GBC-CNN 是有监督带标签噪声任务，但粒球标签/纯度本身依赖标签或监督信号。SAGHL 官方摘要宣称能缓解 label noise，但目前正文噪声注入协议仍未读到。GFSAF 的 NS 命名不能升级为真实噪声辨识：其 Eq. (4)–(6)是 Z/N 相似度惩罚；作者自己限定 LNS 不能严格视为噪声分离。MGCF-Net 的人工注释用于设定簇数及评测，不是噪声训练标签。

4. **不能只据题名判断图类型。** 更正：GBGCL 虽使用 heterogeneous 字样，用户补充的全文实际研究异配关系及 Cornell/Texas 等基准，并非多类型图任务；本卡此前按题名作出的相反判断撤回。异构（类型）与异配（类别连接关系）通用概念仍须区分。

5. **跨领域方法只提供待测假设。** MGBCC/GFSAF 是多视图聚类，MUGBP 是多模态监督意图识别，MGCF-Net 是空间转录组聚类，GBC-CNN 是图像分类，CGBC 是漏洞检测，GBmooer 是文本分类。它们不能替代图节点 noisy-label 协议上的直接证据。优先迁移局部结构单元如何参与表示，而非直接搬整套编码器、decoder、注意力或标签损失。

## 三、逐篇重叠与研究决策提示

- **GBGCL（最高直接重叠之一）：** 全文已核异配图、粒球硬正负关系、MLP 与联合训练。质量分裂式7依赖Y；可用标签范围和代码未核，不直接指控泄漏。未见独立标签噪声注入实验，不能称已验证噪声鲁棒性。
- **SAGHL（最高问题重叠）：** 已将结构驱动层级球、超边和对比采样用于有限监督节点分类，官方摘要明确说缓解标签噪声。新方案的研究问题、监督信号和结构推理形式必须与它逐项对照；当前证据仅是出版商长预览，尤其噪声设置未核。
- **MGCF-Net（图多视图球对比强先例）：** 跨视图成员重叠形成球关联，聚焦 false negatives 和空间组织；不等于噪声标签节点分类。其消融说明 GBCL 有用，但收益有限，PhCR 的结构保持也重要；运行开销较高。
- **MGBCC/GFSAF：** 支持多视图粒球对比的先例，但目标是聚类。GFSAF 不应被引用为完成“噪声识别/剥离”。
- **标签噪声监督类（CGBC/GBmooer/GBC-CNN）：** 其机制或任务依赖标签、纯度或有监督分类目标。能启发标签可信度实验，不能直接支持 label-free 图对比。
