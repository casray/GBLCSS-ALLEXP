# 文献核查、方法差异与证据边界

核查日期：2026-10-13。本文汇总本地全文、既有笔记以及官方论文/作者公开材料。逐篇阅读深度见 `reviews/`；覆盖一篇文献不代表已取得并精读其全部正文与附录。访问失败或只读摘要的工作不补写缺失公式和实验数字。

## 1. 核心判断

“粒球 + 对比学习”不是单一算法范式，至少包含三种不同因果路径：

1. **先对比、后粒球监督**：先获得较好的空间，再用局部标签统计或球级标签训练分类器。GBmooer、CGBC 及当前 GB-LCSS 属于这一大类，但分类目标与是否更新表示不同。
2. **粒球参与表示优化**：粒球中心或成员关系进入损失，梯度回到编码器。MGBCC、GFSAF、GBC-CNN 分别处理多视图关系或粗粒度分类；不能把它们简化成同一种多数投票。
3. **粒球重写图结构**：分球改变增强、超边或粗化结构，再训练图模型。GBGCL、SAGHL、GBC-GL 处于不同图任务和结构操作中，并不都以对比损失为核心。

用户新提议最值得检验的是第二条与图节点分类的结合。但已有工作对这一交叉已构成实质先例，不能因任务从聚类换成分类就直接宣称首次。

## 2. 必须纠正的文献理解

| 容易形成的结论 | 核查后应采用的表述 |
|---|---|
| LReMix 为旧失败提供了理论证明 | 名称为 PLReMix；其证据主要是特定图像含噪学习设置中的优化冲突实验。不能归因本项目所有历史失败 |
| CGBC 是早期图粗化算法 | 本项目引用的 CGBC 是 2026 年智能合约漏洞检测预印本；不要与图粗化缩写混淆 |
| CGBC 要推开所有不同球 | 其球间目标区分同类球和异类球；同类靠近、异类在 margin 内受分离约束 |
| GBC-CNN 让离散分球可微 | 它使用自定义反向传播规则；均值中心的标准梯度与其复制球梯度的做法不同；离散成员改变不是普通可微算子 |
| GFSAF 的 noise stripping 证明找到了真实噪声 | 这是作者对表示分离目标的命名；不能由此推断真实噪声具有可辨识性，更不能推断标签噪声已被识别 |
| 多视图聚类中的噪声等同于训练标签噪声 | AIRMVC、RAC-DMVC 等主要处理输入观测污染/缺失；与标签翻转不同 |
| 仅凭 GBGCL 题名就断定它研究多类型异构图 | 2026-10-13 补读用户全文后更正：本篇导言、定义和六个实验图实际针对 heterophily；通用术语应区分，但该论文不能只按题名判断 |
| SAGHL 只是超图分类，与本任务不直接相关 | 官方摘要已提到减轻标签噪声，且包含粒球、多尺度结构、对比增强训练；是必须面对的直接近邻 |
| soft relation / uncertain relation 本身就是创新 | RAC-DMVC、RGCL、PLReMix 等已有连续权重、半正关系或负关系放松机制 |
| 只要球更纯、更紧，就会提升分类 | 项目旧实验已经给出反例：更小半径可伴随更差语义；错标减少也不必带来最终准确率提升 |

部分旧二级目录的总结含模板化题录和任务误认，本轮保留原文件，用新卡记录核实结果，不沿用错误年代或错误任务。

## 3. 最接近用户问题的论文如何分工

### CGBC 与 GBmooer：两种监督载体

CGBC 通过对比预训练获得表示，再让球级表示、标签和结构约束参与鲁棒分类。其球间约束具有语义条件，而本项目现存 C1 的球间角距离项没有类别输入。这一差异值得单独做因果对照。[CGBC 原论文](https://arxiv.org/abs/2603.27734)

GBmooer 更接近“局部标签分布用于平滑监督”的路线，与当前 GB-LCSS 的研究血缘更直接。它是 SSRN 预印本，不因内容完整就写成已正式接收的期刊论文。[GBmooer 论文记录](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6022343)

两篇都不能为独立语义证据提供自动保证。须区分表示相关与标签翻转相关：给定 X、A、干净标签和固定无标签权重，消息传递共享信息不破坏独立人工翻转标签的条件假设；系统性相关错标则不在这一假设内。

### GBC-CNN：可学习的是球表示，不必是分球算子

它展示了深特征层的粗粒度分类和经验回放。对本项目最实用的借鉴是：固定成员后，用当前 H 计算中心，中心损失可以更新成员特征。普通均值池化已经能完成这条梯度路径，不需要先发明可微分裂。

自定义球梯度复制改变了不同球大小的训练权重，应与普通池化分开检验。经验回放用于该论文的训练环境；全图节点训练的成员组织和小批次图像训练不同，不应默认也要增加经验池。[GBC-CNN 原论文](https://arxiv.org/abs/2409.03254)

### MGBCC 与 GFSAF：从局部集合构造跨视图关系

MGBCC 的关键参考价值在于粒球级对应与对比，而不只是“在 H 里执行聚类”。GFSAF 将 H 的共同信息学习、视图特有表示与后续融合分阶段处理。它们为原生粒球表示学习提供了比冻结后投票更直接的路线。[MGBCC](https://ojs.aaai.org/index.php/AAAI/article/view/34274)、[GFSAF](https://doi.org/10.1609/aaai.v40i28.39556)

但多模态/多视图输入的互补信息不等于同一图两次随机增强产生的差异。图增强有时只是删除信息，不能假设差异都值得保留。迁移时应先用局部集合关系，避免直接复制整个重构、噪声分支和注意力系统。

### PLReMix、CR-GNN、RNCGLN、ProCon：最关键的非粒球参照

PLReMix 使用预测概率的 top-k 类集合关系构造可靠负集合；完整方法还包含样本选择和半监督训练。其价值是明确“对比关系要与语义兼容”，而非替粒球提供一个独有的创新点。[PLReMix](https://arxiv.org/abs/2402.17589)

CR-GNN 已把自监督对比、邻域关系和分类可信度用于含噪节点分类；RNCGLN 研究图结构和标签噪声。它们比纯聚类论文更接近任务验证。ProCon 的主要贡献是图上的同伴/原型一致性与可靠监督，不应因名字含 Con 就把它归为对比学习算法。[CR-GNN](https://www.sciencedirect.com/science/article/pii/S0893608024000273)、[RNCGLN](https://ojs.aaai.org/index.php/AAAI/article/view/29668)、[ProCon](https://www.ijcai.org/proceedings/2025/623)

### SAGHL 与 GBGCL：不能跳过的图结构先例

SAGHL 官方预览明确描述拓扑驱动的层次粒球超边；以结构枢纽引导分解，结合多尺度融合和对比增强目标。摘要还提到标签噪声鲁棒性。公开预览不足以复核全部噪声比例、训练协议和结果，但已足以否定“这几个模块组合起来没有先例”的说法。[SAGHL 出版社页面](https://www.sciencedirect.com/science/article/pii/S0952197626017124)

GBGCL 正式题名为 *Multi-Granularity Graph Contrastive Learning Framework via Granular-Ball on Heterogeneous Graphs*。用户补充 14 页全文后已核实：实际研究异配图；式7–8以类别标签定义球质量及分裂，Table III 将可用信息标为 X,A,Y。正文未充分说明标签可用范围，不能据此断定实际测试标签泄漏。GBA 在三个小型 WebKB 图有较大均值收益，但在 Chameleon 为负、Squirrel/Film 很小；没有独立标签噪声注入评测。此前据题名断定多类型图的意见撤回。详见 [GBGCL 全文卡](reviews/core/GBGCL.md)。

## 4. 相邻前沿提供哪些工具

| 文献群 | 可以学习的机制 | 本项目应避免的外推 |
|---|---|---|
| MFLVC、RAV、GFSAF | 将信息保留、共同语义、视图差异分层处理；关系对齐 | 分开投影头不等于共享编码器无冲突 |
| MANGO、Medusa、MCSF | 多尺度关系、扩散、高阶结构、谱约束 | 多模块整体胜出不说明其中的粒球机制有效 |
| RAC-DMVC、RGCL、STCMC-UR | 连续关系权重、半正关系、伪标签不确定性 | 相似度/置信度不自动等于经校准的正确概率 |
| AIRMVC | 异常观测检测与关系修正 | 假设干净参考视图的结果不能直接用于只有一张含噪标签图 |
| PROTOCOL、CAL | 类别失衡与不同类所需代表单元数量 | 当前噪声实验没有专门失衡证据时，先不要加入额外平衡模块 |
| CPMN、AF-UMC | 无对应/不完整视图的匹配 | 图的两个增强通常已知节点对应，不需要先解决全新匹配问题 |
| MGNR、GCFAggMVC、NGCE | 多粒度邻域、结构聚合、图与特征的协作 | 邻域分类/聚类有效不自动推出 CL 或标签抗噪有效 |
| SegGBC | 成员、非成员和边界不确定性 | 图像分割的空间先验与引用图不同 |
| GBS、VPGB、GBRAIN、G-GBC | 粗粒度采样、聚合、深表征与概率分配 | 对分球更复杂的改造不一定胜过更好的基础表示 |
| BNO-GB；AGPCS-OIC 另列待核线索 | BNO-GB 的球/样本证据分工与开放集判断；AGPCS 原始摘要/全文未核，暂不作为机制依据 | 分布外样本识别不等于封闭集标签翻转 |
| SupCon、SNSCL、SymNCE | 监督对比、噪声关系选择、鲁棒损失理论 | 观测标签作为正对依据在含噪图上可能出错；理论条件要单独核齐 |
| GBSVR、Rank-N-Contrast、GBC-GL | 连续目标、排序关系和图粗化 | 回归/压缩结果不能作为噪声节点分类效果证据 |

这张表是跨论文的研究归纳，不是文献计量排名，也不声称全部方法之间存在直接继承。

## 5. 从文献得到的设计约束

1. **一个类别可以包含多个球，一个球也可能混合多个类别。** 不将球 ID 直接当类别 ID。
2. **结构对应与语义同类是两种证据。** 同一批节点跨视图对应可靠，不代表把它们压成一个中心没有信息损失。
3. **标签无关与标签鲁棒不同。** 无监督预训练避免直接读取错标，但增强破坏、表示偏差和错误关系仍存在。
4. **置信度不能只靠命名。** 应测准确性、覆盖率、校准及错误关系的梯度贡献，不能仅报告 average confidence 上升。
5. **节点预测必须保留边界差异。** 不能把所有成员统一改成球级硬标签后，再用更纯的球解释分类提升。
6. **粒球必要性需要替代实验。** 相同容量和预算的 k-means、kNN、随机分组、仅节点预测关系，必须有明确位置。
7. **不把旧负结果抹掉。** 已失败的冻结表示后投票、简单过滤、固定区域蒸馏不能因换一篇参考文献就获得新证据。

## 6. 未解决的证据缺口

各组 `00_*_memory.md` 列出具体缺口，阅读层级以逐篇卡为准。SAGHL 仍只有官方预览；GBGCL 已补全文，尚未核实代码和构球所用标签范围。摘要/预览只支持重叠判断，不足以声称复现训练协议。

在全文缺口补齐之前，可以制定并检验候选机制；不能提交“首次提出”或“现有方法未考虑”的确定性表述。下一份文档 `03_算法重设计建议.md` 给出的 v0 是机制验证方案，不是已经可以直接写成贡献列表的最终算法。
