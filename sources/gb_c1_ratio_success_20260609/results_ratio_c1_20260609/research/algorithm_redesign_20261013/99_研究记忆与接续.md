## 当前稿件真正的身份

2026-09-30 稿件是 GB-LCSS，题名 Granular ball local consensus for graph-free node classification under label noise。

GRACE 无标签预训练 → 冻结预投影 H → 无标签递归分球 → 仅其他训练节点的观测标签留一投票 → 置信混合软目标 → X-only MLP。扩展为软目标训练 GCN 教师再蒸馏 MLP。

任务是固定图传导、仅训练标签受污染、干净验证选模、20/10/70 split。主结果五个下游配对 seed，并不等于五份独立 GRACE。论文不是新的图对比损失。主表24/25最高均值限于七个同部署 MLP 抗噪基线，不是强 GNN 全部领先。表5中 CoraFull 的 kNN40.50±0.51 vsGB37.39±0.51；粒球不可替代性未获支持。

## 三条必须继承的历史纠错

1. 40/40 份 C1 正式 config 为 negfree / negfree_bn / phase2 CE；现存第二阶段没有 InfoNCE。不能把它说成 GRACE 与含噪 CE 同时相加失败。
2. “linear probe约0.80、原分类头约0.57”不是表示微调前后的公平比较。现存代码在阶段二后用干净训练标签拟合新的 probe；原头在含噪/修正监督上训练。两个指标不可直接归因表示崩溃。
3. 现存 inter_ball_separation_loss 没有类别参数，鼓励所有可靠球两两分离。CGBC 原文区分同类球和异类球；当前实现与参考机制不同。它是值得测试的缺陷候选，尚不是历史失败的因果定论。

证据及源文件哈希见 `sources/local_evidence_audit.json`。现存源码未证明与每个历史运行逐字节一致，保留该限制。

## 不得忽略的负结果

- 固定 H 上简单过滤、换几何、投票再加工、强原型拉近多次未建立稳定粒球独立增量。
- 20261012 GB 统计增量诊断：强 kNN 信号后再加 GB，AUROC 平均增量约 −0.000935。
- 20261012 多尺度/增强稳定性诊断未过门，GB Full 修正精度比 kNN 低约2.75pp；未进行新分类器训练。
- 20261007 DIST+GB 区域KL仅+0.120901pp，未达当时+0.20pp门槛；不要再默认需要复杂粒球蒸馏。
- 20261012 E/F 监督恢复：18/18组错标减少，学生相对基线平均仍约−0.0391pp。关系/标签质量改善不保证最终准确率。

这些负结果限制特定实现与协议，不证明所有在线粒球表示学习都失败。C1相对自身no-ball曾有明显改善，也不能将历史概括为“全部无效”。

## 文献证据的关键界限

- PLReMix，不是 LReMix：经验冲突诊断与伪标签 top-k 负集合放松，外加双网络/二维GMM/半监督训练；不是所有 CL 与 CE 必冲突的定理。
- CGBC 是2026智能合约预印本，GBmooer 是SSRN预印本；不要沿用旧模板里的错误题录/图粗化任务。
- GBC-CNN 采用均值前向和自定义梯度复制；分球仍含离散步骤。ICONIP2024会议论文，Springer章节2025-06-24上线；方法阅读版本为arxiv2024v1。
- MGBCC 已有球级跨视图成员关联；将其改为软权重/图编码器不自动构成强创新。
- GFSAF 的“噪声剥离”不等于真实噪声辨识；VFS目标只有重构。多视图互补不等于图随机增强差异。
- GBGCL已由用户补充14页全文：虽题名为heterogeneous graphs，实际研究heterophily，旧有“不能写成heterophily”判断撤回。p5式7–8依赖Y分球；p9TableIII可用数据XAY，标签范围与代码未核，不能直接断言测试泄漏。GBA收益集中三张小WebKB图，Chameleon负、Squirrel/Film很小；无独立标签噪声注入评测。SAGHL官方预览已包含分类、对比与label-noise鲁棒性，是强重叠工作。
- CR-GNN、RNCGLN已有图标签噪声+对比先例；ProCon是图同伴/原型一致性去噪的直接参照。
- 2024 NR-GNN与2021 NRGNN不是同一方法。GBRAIN是正式缩写，文件名GB_RAIN保留别名；AGPCS-OIC与MOGB也不是同一论文。
- 47个具名条目以45份文献卡覆盖，基础SCE/Co-teaching/ELR合一。不能宣称47篇全部全文精读。
- SAGHL等全文缺口、AGPCS二手线索状态必须保留。GBGCL缺口现为代码/标签使用范围。core memory另记录GBNS-GCL的待核检索警报，不当正式证据；本轮检索也不是穷尽所有最新论文。
