## 3. 候选 A：跨视图粒度不一致时，只对齐由相同成员构成的区域表示

### 3.1 领域问题与已核实的切口

多视图聚类中，同一批对象在不同视图里有不同的局部密度和可分性。一个视图中的小区域可能对应另一个视图中较大区域的一部分。此时，“两个区域有关联”与“两个完整区域应被表示为同一个东西”并不等价。

[MGBCC，AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/view/34274) 用跨视图成员交集建立球间关系，并进行球中心对比学习。[作者实现](https://github.com/poensu/mgbcc_main) 中的关键位置为：

- `granular/base.py`：k-means 划分；中心是完整成员集合的均值。
- `granular/tools.py::relation_of_views_gblists_tensor`：交集大小除以较小集合大小，与阈值比较。
- `granular/granular_loss.py::MultiviewGCLoss`：从两个视图取得完整球中心后计算损失。

[HOARD，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/40136) 也采用交集相对较小球大小的跨视图关联构造。它已有共享/特有信息建模与其他对齐层次，因此不能把“增加层次对齐”当作本候选的差异。

### 3.2 一个可直接检查的反例

设视图一的小球 B 含 2 个对象；它们都在视图二大小为 10 的球 D 中：

\[
\frac{|B\cap D|}{\min(|B|,|D|)}=1.
\]

这个关联分数是最大值。但是 D 的中心还平均了另外 8 个对象。若这 8 个对象与 B 不同，拉近两个完整中心就包含了额外牵引。

令 I=B∩D，s=|I|，n=|D|，则同一视图中有精确分解：

\[
c_D=\frac{s}{n}c_I+\left(1-\frac{s}{n}\right)c_{D\setminus I},
\qquad
c_D-c_I=\left(1-\frac{s}{n}\right)(c_{D\setminus I}-c_I).
\]

这说明偏移由“非共同成员比例”与“非共同成员的表示差异”共同决定。**它只是代理关系存在缺口的数学例子，尚未证明真实数据上该现象频繁，也未证明改动一定提升聚类。**

### 3.3 最小方法

先保留原编码器、重建目标、分球规则和聚类输出。对每对视图 u、v：

1. 记录样本的球归属，得到非空交集 I_bd=B_b^(u)∩B_d^(v)。
2. 分别在两个视图里，用同一个 I_bd 中的对象求均值。
3. 对齐这两个同成员集合的表示，替代相应整球中心的正对齐项。
4. 以 |I_bd|/N 为候选权重；对于一对完整视图，各交集构成分区，每个对象的总质量只计算一次。
5. 保留节点/实例表示作为最终聚类输入，不广播球级预测。

\[
\mu_{bd}^{(u)}=\frac1{|I_{bd}|}\sum_{i\in I_{bd}}h_i^{(u)},\qquad
\mu_{bd}^{(v)}=\frac1{|I_{bd}|}\sum_{i\in I_{bd}}h_i^{(v)}.
\]

第一版只检验“对齐的成员集合是否一致”。多粒度自动生成、视图注意力、伪标签过滤、可学习温度均不加入。

需要防止一个新的混淆：若替换后同时改变负样本池、正样本总权重和损失尺度，不能把收益全部归因于共同成员对齐。应保留可比的负样本控制，另列权重/尺度对照。重建或其他防塌缩部分首先沿用基线，不能仅凭均值一致性保证非塌缩。

### 3.4 粒球作用、假设与边界

粒球是跨视图局部统计区域，用来发现“在哪里比较两个视图”及关系所覆盖的对象范围。它不提供类别标签，不要求同球成员同类，也不强制它们得到同一个表示。

假设：

- 两个视图的对象 ID 对应是正确的；第一轮不研究错误配对。
- 不同视图存在可以共享的语义。
- 区域平均在部分位置能降低扰动，而不会总是抹去有用差异。

主要风险：

- 若交集几乎都是单样本，该方法会接近实例级对比，失去区域统计的特殊价值。
- 共同成员集合也可能混类；“支持集合相同”不能证明“语义纯净”。
- 小集合均值方差可能很大。
- 两视图的语义本身不一致时，正确对象 ID 也不代表所有信息都应对齐。

### 3.5 最先做的实验，不直接铺开训练

先在 MGBCC 作者提供的数据与配置上复现 BBCSport、Caltech101-20、Scene15；具体数据版本、样本数、视图数以实际文件核验为准。

**第零步：固定表示诊断。**

- 非空交集大小分布，单样本交集覆盖率。
- 原规则判正的球对中，两个方向的覆盖率分布。
- c_D−c_I 的范数、方向；在表征尺度统一后比较。
- 干净类别仅用于事后诊断：共同与非共同成员的类别分布差异。
- 同一球同时被哪些异质区域牵引；必要时记录正项梯度之间的关系。

**有缺口再做五组控制，首轮 3 个种子：**

| 臂 | 改动 | 用途 |
|---|---|---|
| A0 | 作者原粒球损失 | 基准 |
| A1 | Jaccard 等简单重叠规则，匹配正对数量/总权重 | 检查是否只需更合理阈值 |
| A2 | 整球中心不变，仅按重叠程度软加权 | 区分加权与表示集合匹配 |
| A3 | 共同成员集合均值对齐 | 候选机制 |
| A4 | 实例级对比，匹配编码器与训练预算 | 检查是否仅退化到实例学习 |

报告 ACC/NMI/ARI、运行时间、峰值显存、实际比较单元数及种子逐项结果。三种子用于筛查，不宣称小差异具有统计显著性。最终论文需增加数据集、种子及合理统计检验。

注意作者 `main.py` 同时保存最后一轮与根据真实 ACC 选择的最佳轮次。后续必须明确区分作者复现口径和统一固定轮次/无标签选模口径；不能用真实聚类标签为新方法反复挑超参或检查点，再称为无监督模型选择。已检查的构球/损失路径里标签被携带，但上述分球和关系计算依赖特征与样本索引，不能仅因函数接收 `y` 就指控标签泄漏。

继续条件：真实数据中缺口可观；A3 的收益超出简单改权重和实例对比解释；改进在至少两个不同数据特征的任务上复现，并能与诊断量变化对应。

停止或降级条件：缺口少见；A1/A2 即解决；A3 几乎全部单样本化且与 A4 等价；只有单个种子/单个数据集优势；改进来自不同选模口径。

成功后再把同一模块移植到 HOARD 等第二个框架，不提前把“改进两个方法”写成已成立贡献。

## 4. 候选 B：错误配对条件下，按需要细化区域对应关系

### 4.1 是什么问题

这与候选 A 不同：A 假设 ID 正确，只是区域大小与组成不一致；B 研究对象配对本身含错。直接把观测配对全部当正样本，会把错误关系写进表示。

这个问题已被直接研究：

- [RMCNC，TKDE 2024](https://xlearning-lab.com/assets/2024-TKDE-Robust-Multi-View-Clustering-with-Noisy-Correspondence.pdf)：噪声对应下的多视图聚类。
- [CANDY，NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/dbe81b08f7dc4dd8b43bc62dedfd9662-Paper-Conference.pdf)：双重对应噪声。
- [CorreGen，ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/8c1d92835eb4e601f396c97ec60439fe-Abstract-Conference.html)：隐对应建模、EM 式更新及对不可匹配情形的处理。
- [OPTION，ICML 2026](https://proceedings.mlr.press/v306/zhou26l.html)：不完整或未对齐多视图学习。其公开摘要描述的是不同条件下的评估，不据此断言同时解决所有缺失与错配的组合。

因此“加入最优传输”“允许拒绝匹配”“用置信度选正样本”本身不足以形成与这些方法的区别。

### 4.2 可能的具体增量

只考虑一个问题：**在对应关系计算预算有限时，哪些区域值得展开到实例层，哪些可以保留区域层的多对多关系？**

候选流程：

1. 各视图独立预热编码器，建立可比较的表示；不能直接比较未对齐模态的原始欧氏距离。
2. 建立区域级候选对应，允许多对多和未匹配质量。
3. 根据对应分散程度或区域内部的代价变化，识别区域级近似最可能失真的位置。
4. 仅将这些区域细化为实例或子区域，再更新对应。
5. 对实例保持独立表示；区域负责降低对应关系求解的分辨率，而不是给成员强制分配共同类别。

这里的“自适应”必须对应一个可测量的近似误差或计算分配问题，不能重新变成任意加权评分。

假设：存在可恢复的共享结构、部分可靠联系或其他可识别条件。任意打乱且不存在跨视图共享信息时，正确对应一般不可恢复。

### 4.3 最关键的反证控制

CorreGen 的作者说明使用 512/1024 的小批量，不能把它描述成必须存储全数据 N×N 对应矩阵。先做实际剖析，再决定计算压缩有没有空间。

必须比较：

- 原 CorreGen；
- 相同预算的简单原型/固定 k-means 块近似；
- 随机细化和均匀细化；
- 候选的按误差细化。

先仅做对应噪声，沿用原文数据与噪声协议，不同时加入缺失视图、类别不平衡、图异配和标签噪声。若不能在相同时间/内存预算下改善对应恢复与最终聚类，就不推进。

本候选的文献竞争更强、实现更重，因此作为 A 的后续延伸或独立备选，暂不与 A 同时开跑。

## 5. 候选 C：用粒球压缩消息参考值，用采样残差保留节点差异

### 5.1 领域问题及最接近的先例

大图小批量训练需要处理批次外邻居：少采样可能增加估计误差；缓存每个节点的历史表示会占用内存且可能陈旧。这里可以问：是否能用少量区域参考值替代部分历史缓存，再用少量残差补偿，获得更好的预算—误差折中？

这不是全新问题：

- [VQ-GNN](https://arxiv.org/abs/2110.14363) 已用向量量化压缩批次外特征，并处理近似前向与反向传播。
- [VR-GCN](https://arxiv.org/abs/1710.10568) 已用控制变量降低采样方差。
- [GAS](https://arxiv.org/abs/2106.05609)、[LMC](https://arxiv.org/abs/2302.00924) 分别涉及历史嵌入和局部消息补偿。
- [LABOR，NeurIPS 2023](https://proceedings.neurips.cc/paper_files/paper/2023/hash/51f9036d5e7ae822da8f6d4adda1fb39-Abstract-Conference.html) 是采样预算的重要对照。
- [GB-CGNN，2026 预印本](https://arxiv.org/abs/2603.29148) 使用粒球组织子图训练，不宜误写成只在中心粗图上做分类。

所以候选增量不能是“把 VQ 的码字改名为球心”。要落在：**如何根据区域残差与传播权重分配有限中心、残差采样或刷新预算，以及这是否真正降低实际误差。**

### 5.2 一个明确的数学起点

先限制为固定传播权重的 GCN 单层，避免一开始推广到注意力模型。

\[
m_i=\sum_jP_{ij}h_j.
\]

选择区域参考值 c_b，记 a_ib=Σ_{j∈B_b}P_ij，有恒等分解：

\[
m_i=\sum_ba_{ib}c_b+\sum_jP_{ij}(h_j-c_{b(j)}).
\]

前项由少量区域参考值计算；后项是不能被区域平均解释的节点差异。对邻居按 q_i 采样 s 次：

\[
\widehat m_i=
\sum_ba_{ib}c_b+
\frac1s\sum_{t=1}^{s}
\frac{P_{ij_t}}{q_i(j_t)}(h_{j_t}-c_{b(j_t)}).
\]

在给定 P、真实当前 h、参考值和采样分布的条件下，且 q 对所有非零贡献有正概率、独立有放回采样时，该单层激活前消息估计无偏，其均方误差满足：

\[
\mathbb E\|\widehat m_i-m_i\|^2
\leq
\frac1s\sum_j\frac{P_{ij}^2}{q_i(j)}
\|h_j-c_{b(j)}\|^2.
\]

这是从期望与独立样本方差直接推得的候选分析，不是从已有实验得到的性能结论。它也不是宣称控制变量为新发明。

### 5.3 粒球为什么可能有用

球心提供共享参考值；半径/残差统计提供近似难度信息。残差较大的区域需要更多样本、更多中心或更频繁刷新。几何紧致度此时直接关联消息估计误差，而不是间接猜测类别纯度。

同一球内节点保留各自的特征、残差、监督和预测。因此与之前 ΠPΠ 强投影不同：不是把球内差异直接删除，而是对这些差异采用可控制的估计。

但必须承认：

- 固定 k-means 码本同样可以做上述分解；粒球层次的额外价值待验证。
- 上式不自动保证整个多层非线性网络或训练梯度无偏。
- 若 h 使用陈旧近似而非真实当前值，必须另计偏差；旧球心本身不破坏上述条件无偏性，但可能使方差增加。
- 若用半径给出最坏误差界，应使用真实最大半径或有效上界，平均半径不够。
- 总内存还包含成员映射、图、输入特征、采样结构和 PH 的非零项，不能只报 M×d。
- 刷新、分球及重建区域连接统计可能比省下的计算更贵。

### 5.4 首轮只做消息估计诊断

在可取得的固定模型状态上，比较相同缓存字节和邻居访问预算下的消息均方误差、梯度近似误差和实测时间。候选对照包括均匀采样、历史缓存控制变量、VQ 参考值、固定 k-means＋残差、候选的区域预算分配。

先检查本地数据与实现兼容性；若需大图，优先考虑官方划分的 ogbn-arxiv，但本报告没有下载数据或安装依赖。

只有出现明确预算—误差优势后才做完整分类训练。第一轮采用干净标签，不重新叠加旧的标签噪声目标。失败条件：中心更新成本吞没收益；消息误差不优于简单固定码本；降低消息误差不转化为可用训练行为。

## 6. 为什么暂不推荐另外几种“大方向”

| 方向 | 本轮判断 |
|---|---|
| 再加局部可靠性、粒球纯度或多粒度标签修正 | 与项目已有失败重叠，缺少新的可观测信息来源 |
| 粒球＋对比损失＋分类损失 | 组合本身不是问题；需先定位具体错误约束 |
| 统一处理异配、标签噪声、缺失视图和不平衡 | 同时引入太多变量，难以判断失败来自哪里 |
| 样本级视图质量加权 | 有 [RML，ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/papers/Xu_Robust_Multi-View_Learning_via_Representation_Fusion_of_Sample-Level_Attention_and_ICCV_2025_paper.pdf) 等直接先例；需进一步找具体不足 |
| 类别不平衡的多视图最优传输 | [PROTOCOL 预印本](https://arxiv.org/abs/2506.12408) 已研究部分传输与不平衡；仅把均匀边际改掉不够具体 |
| 把流数据当成尚未研究的空白 | 尚需更完整核查，不能因为换任务就假定粒球具有独占优势 |

这些不是永久否定，而是当前不值得先付实验成本。

## 8. 下一步决策

本报告建议先执行 A 的固定表示诊断，确认具体缺口再训练；不同时启动三个方向。若用户明确希望保留图分类，则优先执行 C 的预算—误差诊断。

这次候选与旧路线的区别在于，粒球的质量有了更直接的检验对象：A 检查对齐双方是否代表同一批对象；C 检查近似消息误差。它们仍可能失败，但失败原因更容易定位，不需要通过增加模块来解释。
