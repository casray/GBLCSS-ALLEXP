# GraphECL honest pilot implementation plan

日期：2026-10-29；用户已授权设计并实验。执行方式为当前任务逐阶段实现、测试与复核。旧实验来源只读，新结果单独保存。

**Goal:** 用已有缓存收尾 ContextECL、筛查集合关系蒸馏，并用两 seed 检验交叉拟合目标生成是否产生带噪净收益。

**Architecture:** 复用原 GraphECL、数据桥、SUPPORT32 生成器和固定线性分类头；新机制独立实现。固定 H0 读出，先分离目标收益。训练源与输入保存 SHA256 收据。

**Tech Stack:** Python / PyTorch ROCm / NumPy / SciPy / scikit-learn，固定现有虚拟环境。

## 科学规格

假设H1：图/属性分支对粒球集合的关系差异，包含超出现有几何和票集中度的目标质量信息。

假设H2：仅由另一折标签学习的粒球对比空间，能够提高本折投票的真实类别票差，从而弥补样本拆分损失。

粒球角色：H1中为局部集合关系载体；H2中为软监督正对候选单元及目标生成区域。沿用已冻结下游分裂/支持裁剪配置。无新结构扰动、无clean否决、无正式kNN/KMeans方法训练。

### S1 反事实与缓存筛查

CS/Photo×seed0/1×U.4/U.6/Pair.4：新增12个 H0+GB100目标头；另复现12个 H0+原目标头，与旧概率逐位比较。旧 H1+q0、H1+q1 从完成文件引用。

记录每训练节点新旧票源Jaccard、支持数、净增/净失真同类票、真实类别margin、Brier变化及分类翻转；保存逐节点表。Photo详细，CS同口径聚合。

H1使用现有全票SUPPORT32分区和同K的KMeans(n_init=3，固定seed)缓存对照。图分支g与属性H分别按自身空间计算组均值、余弦softmax，τ=.5；查询参与中心时显式留一。新增KL(Q||P)、H(Q)/logK、Q在对应组质量。基础特征为球内训练支持余弦、log(1+support)、LOO票max及top2差。所有比较采用相同原GB组的GroupKFold(5)，标准化参数仅在诊断训练折拟合。LogisticRegression(C=1,max_iter=1000)预测共识argmax正确；Ridge(alpha=1)预测实际软目标Brier。人工真值只用于诊断响应。

H1推进门：12单元宏增量AUROC≥.01，两个seed宏增量均正，宏增量优于匹配KMeans，Brier回归MSE下降。失败则停止该KL定义的新增编码器训练。通过时先记录信号，另按本方案的单变量原则登记短训配置再执行。

### S2 交叉拟合最小训练

CS/Photo×seed0/1，只用Uniform .4。节点ID用seed+29001随机均分A/B，划分与标签独立。

共享终点为已有无标签ECL模型，重置Adam，学习率原值×.1，训练20轮，原weight_decay保持。每(d,s)训练一次20轮无标签ECL，分别在A/B裁剪SUPPORT32；真实及打乱分别训练两个折模型，共4×(1+2+2)=20条，400次全图更新。

用H0和A掩码单独构球、用A观测标签生成原LCSS完整软目标t_A，冻结这份目标。训练E_A时仅传入A节点ID、A目标、A分区。其他节点仅作为无标签X/图输入。B标签及其派生目标无输入路径。随机打乱在A内置换完整目标行，保留目标多重集；两分支共享候选和初始化。

辅助损失为属性投影输出上的软监督对比：

    w_ij = 1[same_ball(i,j)] max(t_i dot t_j - 1/C, 0), i!=j
    a_ij = w_ij / sum_j w_ij
    L_aux = mean_active_i -sum_j a_ij log softmax_{k!=i}(sim(z_i,z_k)/.5)

key包含本折全部训练节点；每轮最多512个固定随机查询，同球关系只提供候选，软目标决定权重。无有效正对的查询不进入该辅助均值。记录有效查询比例、权重分布和目标熵。

在初始模型上测全参数梯度：λ=min(1, .1||g_ECL||/||g_aux_real||)，逐折校准，20轮内固定，打乱分支使用真实分支同λ。只读取本折目标，按A/B分别校准。原GraphECL正边、分母、索引与自环保持。辅助项使用同次前向输出并保留计算图；梯度与原目标相加。

训练E_A后在其H里以B的节点掩码重建SUPPORT32，B内留一投票；E_B对称。单向执行，不将生成目标反馈编码器。将两折目标按原训练ID拼接，固定H0、同初值分类头拟合。

报告5组：原全票a0、原空间折内票b0、20轮无标签续训折内票b20、真实交叉拟合c、打乱d。a0与CE旧结果先复现；完整20轮无标签空间的全票目标a20另记以解释续训效应，仍固定H0读出。

主门（验证集，不以测试选臂）：c−b20宏≥1pp，两个seed宏为正；c−d宏>0；c−a0宏≥0；训练目标Brier宏下降且两图方向不反。通过才考虑扩噪声或普通软监督对比。未通过停止当前规格，不扩网格。报告全部测试差值和逐图/seed负结果。固定H0的CE不变，交互量与LCSS增量相同，不作为额外独立证据。

理论诊断：s、真实类别Δ、sΔ²、Δ≤0比例，Uniform.4对应γ。折内目标自身标签突变时q/alpha不变；B标签突变时A监督包、权重和一次更新不变。旧公式条件保留。
