# 节点路由与全局融合并列诊断

## 授权与假设
2026-10-23 用户明确要求在全局融合收益有限时直接检验节点路由。本实验独立于
channel_routing_variance_20261023，原实验 L1 停止决定保持原样。
假设：A300 与 C_head 的自身概率信号能预测分歧节点上应选择哪一个学生，
从而比全局概率融合获得更多净纠错。粒球仅作为通过首阶段后可研究的局部统计单元。

## 固定协议
- 5 图、clean / uniform0.4 / uniform0.6 / pair0.4；协议与学生 seed0。
- 复用 sc_support_channel_pilot_20261023 的全部概率及划分。
- A300 是 SUPPORT-LCSS 教师的软 CE 蒸馏学生；C_head 是 R2 冻结头学生。
- 神经网络新增拟合次数为零；仅拟合 CPU 逻辑回归路由器。
- 8 个特征：A/C 各自最大概率、归一化熵、第一第二概率差、两者 JS 散度、预测一致指示。
- 标准化 + L2 逻辑回归，C=1，lbfgs，max_iter=2000，class_weight=None。
- 拟合样本为验证节点中恰有一个学生正确的节点，标签 1 表示 C 正确；
  两者都错仍参加阈值选择与所有整体指标。两者预测相同时保持 A。
- 某拟合子集仅含一种路由标签时退回恒定 0 或 1 概率；无可用样本退回 0。
  全部回退记录，相关单元仍计入汇总和门槛。

## 验证选模与并列对照
外层 KFold(5,shuffle=True,random_state=42)，只使用验证节点。
每个外层训练折：内层 4 折产生路由 OOF 分数，选阈值后在整个外层训练折重拟合，
对外层留出折预测；全局融合权重也只在同一个外层训练折选择。
这样 ROUTER_NESTED 和 GLOBAL_NESTED 可直接比较。
阈值与权重网格均为 0,.05,...,1；路由额外含永不切换。
阈值按准确率、少切换、高阈值依次平票；融合权重平票偏向 A。
最终部署规则：在全部验证集用 5 折 OOF 选阈值，再拟合全部验证集；
全局权重在全部验证集选。20 个单元的规则全部落盘后才读取测试标签评分。
固定 0.5 路由、直接概率平均、A、C、教师置信度阈值均作为描述性对照。
已有学生检查点用过同一验证集，故本轮属于探索性验证集再使用；嵌套路由
控制新增路由拟合的偏差，独立确认需另行冻结规则与使用新数据划分。

## 门槛与阶段决策
主门槛只用外层验证预测：ROUTER 相对 GLOBAL 的带噪均值在
Cora/CiteSeer/CoraFull 至少 2 图达到 +0.5pp，且五图 clean 均不低于 GLOBAL 1pp。
通过后再设计图统计和 SUPPORT 统计的独立增量对照；本轮自动执行范围为学生自身信号。
失败则停止新增路由复杂度。测试结果仅报告，所有阈值、特征及阶段门槛保持固定。
另报告测试相对最强单通道 +1.5pp 的原始研究目标是否满足，不用于自动扩展。

## 输出与审计
保存配置、源码/输入 SHA256、原始日志、每折标准化与模型参数、全节点路由概率、
外层预测、最终规则、准确率、macro-F1、救回数、误伤数、覆盖率、AUROC、并集空间兑现比例。
AUROC 在分歧且恰有一个正确的节点上计算，主准确率计入全部节点。
单 seed 不提供 seed 标准差；三噪声条件标准差单独标记。
最终报告逐数据集说明结果、机制解释、失败记录及继续/暂缓决定。
