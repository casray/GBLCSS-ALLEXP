# 带噪监督下预算约束粒球图粗化：实验计划（预注册草案）

日期：2026-10-19。状态：设计完成，未实现、未训练。整合来源：`research/literature_reassessment_20261019/05_DESIGN_REASSESSMENT.md`（Codex 设计）、`07_LOO_IMPURITY_REVIEW.md`（Codex 留一不纯度复核）与本轮 Claude 补充。门槛在实现前冻结；结果出来后不改门槛、不换主对照。

## 0. 研究问题与可证伪假设

问题：计算预算有限、训练标签含噪时，怎样分配粗化粒度，使模型少拟合随机错标，同时保留需要区分的属性与关系差异？

| 编号 | 假设 | 对应实验 | 否定后的含义 |
|---|---|---|---|
| H0 | 粒球粗化相对其原图对应模型存在可测的时间或显存收益，且精度损失可控 | E0 | 不能以"高效"为主卖点 |
| H1 | 已有纯度驱动粒球粗化（SGBGC）在保持训练掩码后，于强噪声下出现可重复的退化或球数膨胀 | E1 | 缺口叙事需改写，不能写"已有方法在噪声下失效" |
| H2 | 同一无标签候选树、同一预算下，用含噪标签的留一不纯度分配粒度，优于纯无标签切面和普通 Gini | E2 | 标签项不是贡献；方法退化为无标签粗化 |
| H3 | 完整方法在精度—完整成本曲线上不被已有鲁棒图方法支配 | E3 | 无法投稿主张 |

执行顺序 E0 → E1 → E2 → E3；E4（异配适用性）仅在 E2 通过后进行。

## 1. 整合后的设计决定

1. **粒度评分采用带证据继承的留一不纯度 Û_inh。** 对含 n_B≥2 个训练标签的球，Û_B = n_B/(n_B−1)·Gini_B = 1 − Σ_c c_c(c_c−1)/[n_B(n_B−1)]，等于 GB-LCSS 留一一致率的补。训练标签不足 2 个的叶球不用先验 1−1/C，而**继承最近的、含 ≥2 个训练标签的祖先球的 Û**。
   - 修复 Codex 反例 1：两标签混合球拆成两个单标签球，先验约定下目标从 2 降到 4/3；继承约定下保持 2（`theory/check_inherited_loo.py`）。即"拆到证据不足以下"不再降低标签代价。
   - 固定分区下对称噪声恒等式在继承约定下仍精确成立：E[Σ n_B Û_inh] = γ²·U_clean,inh + (1−γ²)(1−1/C)L；η=0/0.3/2/3 三档数值核验误差为 0（同一脚本）。条件：分区不依据当前噪声标签选择；独立同分布对称翻转；右侧也用继承约定计算。
   - **不解决选择噪声**（Codex 四节点例，2.2716 < 2.6667）。高噪声下标签项期望变平但方差不变，实际选择可能被噪声驱动。本计划不为此新增机制，而用 D-only 对照、切面稳定性诊断和一条预注册后续分支处理（§4 E2）。
   - 联合目标中标签项的有效权重为 βγ²，随噪声变化；"不需要知道 η 即可计算"不等于"目标不受 η 影响"。
   - 严格比例关系只对对称噪声成立；3 类循环 pair 有系数 κ=1−3η+3η²，4 类以上循环 pair 一般不成立。因此 pair 噪声必须在多类数据（CoraFull，70 类）上检验，不能只靠小例。
2. **候选树不读标签与训练位置。** 坐标 F=[U, PU, P²U]，U = TruncatedSVD(行 L2 归一化 X, 128 维)（arxiv 原特征已为 128 维，直接用）；P 为加自环对称归一化邻接；三通道各自行归一化后乘 1/√3 拼接。逐层顺序计算 P(PU)，不显式形成 P²。
3. **切面目标**：J(P) = Σ_B [D(B) + β·(n_B/L)·Û_inh(B)/(1−1/C)] + λ|P|。D(B) = Σ_通道 SSE_通道(B)/SSE_通道(根)。β 主设定固定为 1（不调）；λ 用二分搜索使实际叶数落在目标 M 的 ±1% 内，各臂按实际 M 配对。剪枝递推 F(B)=min(a(B)+λ, F(左)+F(右))。
4. **粗图算子**：H 为 N×M 硬归属，R=(HᵀH)⁻¹Hᵀ，X_c=RX，P_c=RPH（稀疏），不再交给 GCN 默认归一化。另设 Ac=HᵀAH 重新归一化作对照（仅 E0）。
5. **训练与评估**：球级 soft CE，按 n_B 加权，只有含训练标签的球贡献损失；验证用提升预测 H·Z_c 在验证节点上逐轮计算（不做每轮原图前向，避免吃掉节省）；最终用同一 θ 在原图前向一次作为主测试结果，提升预测的测试精度作为迁移诊断同时报告。

## 2. 共同协议

- 划分：NoisyGL 百分比划分 20/10/70（`percent_split_indices`），ogbn-arxiv 用官方划分（另注明）。
- 噪声：只污染训练标签（`inject_train_label_noise`，scope=train）；验证、测试干净；干净验证选模。带噪验证作为后续第二协议，不混表。
- 噪声类型：uniform 0.2/0.4/0.6；pair 0.4（NoisyGL 循环映射）；instance 0.4 仅作压力测试。
- 种子：筛查 0/1/2；确认 3/4 加一个此前未用于开发的数据集（Physics 或 WikiCS，筛查前锁定）。每个种子同时决定划分、噪声与初始化。
- 骨干：两层，hidden 256，dropout 0.5，Adam 0.01，weight decay 5e-4，最多 300 轮，验证 patience 50。原图臂与粗图臂共用超参，不对任何一方单独调参。
- 环境：`D:/codex_temp/noisygl-rocm721/Scripts/python.exe`，RX 7700 XT，torch 2.9.1+rocm7.2.1，PyG 2.7.0。
- 计时：每阶段前后 `torch.cuda.synchronize()` + `perf_counter`；每配置 1 次预热不计，3 次重复取中位数；`torch.cuda.reset_peak_memory_stats()` 分阶段记录显存峰值，另记主机 RSS 峰值。
- 防泄漏：测试标签只在最终评估读取；验证标签只用于选模；干净训练标签只用于事后诊断与标注为 oracle 的臂。每个协议记录 split/noise 哈希。

## 3. 记录的指标

精度：test accuracy、macro-F1、最差类召回；原图前向与提升预测两种测试结果。
结构：N、E、M、E_c、有标签球数 M₊、单标签叶球比例、继承发生比例、球大小分布。
监督（诊断，用干净训练标签）：球级软目标对干净分布的 Brier、超节点多数类错误率。
选择稳定性：同一划分下两次独立注噪所得切面的 ARI（选择噪声诊断）。
成本：特征预处理、建树、切面选择（含 λ 搜索）、粗算子构造、每轮训练、选模验证、最终推理，分项与总和；显存峰值；同一 λ/β 网格的重复训练次数计入总成本。另报告"换噪声种子或训练划分时必须重算"的部分（标签依赖切面、软目标）与可复用部分（无标签候选树）。

## 4. 实验

### E0 成本与压缩空间（最先做，1–2 天）

不使用标签决定切面（R0：D-only），只回答"压缩能省什么、损失什么"。

| 配对 | 原图版本 | 粒球版本 |
|---|---|---|
| 每轮传播 | 全图 GCN | 粗图 GCN（P_c=RPH；另一行 Ac 重归一化） |
| 预计算后训练 | SIGN：[X, PX, P²X] 缓存后训练 MLP 头（L 行） | 同一缓存经 R 聚合为 M 行，头只训练 M₊ 个有标签球 |

- 数据：Coauthor-CS、Physics、CoraFull（本地）；ogbn-arxiv（需安装 ogb 并下载数据，待批准）。若 arxiv 结果仍不能判断，再申请 ogbn-products——全图 GCN 显存压力真正出现在这一量级，arxiv 上全图 GCN 每轮只需约数十毫秒，绝对时间收益可能很小，这一点提前写明。
- 预算 M/N ∈ {0.05, 0.1, 0.3}；标签条件 clean 与 uniform 0.4；种子 0/1/2。
- **门槛 G0（冻结）**：在至少一个数据集（必须包含最大的那个）、至少一个 M/N 上，粒球版本相对**其自身原图对应版本**，干净标签精度下降 ≤1.0pp，且总流程时间 ≤0.5× 或显存峰值 ≤0.5×。GCN 配对与 SIGN 配对分别判定。
- 分支：
  - 两个配对都通过 → 论文可主打效率。
  - 只有 GCN 配对通过 → 只能写"相对逐轮消息传递的节省"，必须同时披露 SIGN 对比结果，效率作为次要主张。
  - 都不通过 → 效率不能作卖点；能否继续取决于 E2/E3 在精度上的证据（见 E3 分支）。
- 附带观察（不设门槛）：u0.4 下 D-only 粗图 GCN 是否已高于全图 GCN-CE。若是，说明粗粒度共享本身有正则化作用，这是 E2 的前提背景。

### E1 已有方法缺口（2–3 天，可与 E0 并行）

- 对象：SGBGC 作者代码（GitHub mxjun17/GBNC；Codex 曾读取 raw 文件，本地未缓存，克隆需批准）。
- 两条流程分别报告：(a) 作者默认流程，原样记录；(b) 掩码修正版：只用训练掩码内标签，保持 20/10/70，不重新随机划分球级 train/val。论文中只做事实陈述，不作指控。
- 数据：Cora、CiteSeer、CS、Photo、PubMed；uniform 0/0.2/0.4/0.6、pair 0.4；种子 0/1/2。
- 指标：球数、M₊、单节点球比例、超节点标签错误率、E_c、精度、总时间；同时与 E0 的 D-only 粗图在匹配 M 下对比。
- **门槛 G1（冻结）**：掩码修正版在 u0.4 下比全图 GCN-CE 低 ≥3pp 的数据集 ≥3/5，或球数从 clean 到 u0.4 增长 ≥2×，或 D-only 粗图在匹配 M 下高于它 ≥2pp 的数据集 ≥3/5。三项满足其一即"缺口成立"。
- 不通过：引言不能写"纯度驱动在噪声下失效"，改写为"给出标签项的抗噪分析与预算化分配"，E2 仍可进行。GBGC 原任务为图分类，不进入 E1 主表。

### E2 粒度规则（核心，约 1 周）

固定同一候选树、同一实际 M（主设定 M/N=0.1，0.05/0.3 作敏感性）、同一 P_c 与骨干（采用 E0 中表现更好的配对；若无差别，用粗图 GCN）、同一训练流程。只改切面评分：

| 臂 | 切面评分 | 性质 |
|---|---|---|
| R0 | D | 无标签 |
| R1 | D + 普通 Gini（含噪） | 基线 |
| R2 | D + Û，<2 标签叶取先验 1−1/C（Codex 版本） | 候选 |
| R3 | D + Û_inh（证据继承） | 主候选 |
| O1 | D + 干净 Gini | oracle，仅诊断 |
| O2 | D + 干净 Û_inh | oracle，仅诊断 |
| X1 | SGBGC 掩码修正版，匹配 M | 外部对照 |
| F1/F2 | 全图 GCN-CE / 全图 SIGN-CE | 参照 |

- 数据：Cora、CiteSeer、CoraFull、CS、Photo、PubMed（arxiv 视 E0 结果加入）。
- 噪声：u0.2/u0.4/u0.6、pair0.4、instance0.4（压力测试，不进门槛）；种子 0/1/2。约 6×5×3×8 ≈ 720 次粗图训练，每次秒级到分钟级。
- **门槛（冻结；在 u0.4、u0.6、pair0.4 三类带噪单元上判定）**：
  - G2d 上限：O2 − R0 ≥ +1.0pp（单元均值）。不通过 → 即使用干净标签，标签感知粒度也没有空间，**停止标签项路线**。
  - G2a 标签规则有用：R3 − R0 ≥ +1.0pp，且 ≥2/3 的数据集×噪声单元为正。
  - G2b 留一有必要：R3 − R1 ≥ +0.5pp，且 ≥60% 单元为正。不通过 → 普通 Gini 已足够，留一不写入贡献。
  - G2e 优于纯度驱动：u0.4 下 R3 ≥ X1 的数据集 ≥3/5。
  - R3 对 R2 只报告，不设门槛（机制细节）。
- 预期模式（用来解释结果，不作门槛）：R3−R0 的优势应随噪声率升高而缩小（βγ² 收缩、方差不收缩）。若 u0.6 下 R3 < R0，与选择噪声解释一致。
- **唯一允许的后续分支**：G2d 通过而 G2a 不通过时，可加一臂交叉拟合（训练标签分两折，一折选切面、另一折算软目标，再交换平均）。若该臂仍不过 G2a，停止，不再追加收缩、门控或调 β。

### E3 与鲁棒图方法定位（E0 或 E2 通过后）

- 对照：ERASE、ProCon、GD²、RTGNN、NRGNN（NoisyGL 中已有适配器）、GCN-CE、SIGN-CE。
- 同协议、同划分噪声；报告精度、macro-F1、完整时间、显存，绘制精度—时间帕累托图。
- 参考：已有 seed0 筛查（`robust_graph_seed0_20261006`）中，ERASE 教师在 CoraFull 上约 124s，GCN-CE 约 14s。
- 门槛按 E0 分支，事先冻结：
  - E0 通过：在 u0.4 下与最强鲁棒方法的精度差 ≤2pp，且总时间 ≤其 1/3，满足的数据集 ≥3/5（工程筛查阈值，不是理论标准）。
  - E0 不通过：u0.4 与 u0.6 下精度不低于最强鲁棒方法的单元 ≥50%。达不到则暂停，不改题目维持主线。

### E4 异配适用性（仅在 E2 通过后）

Roman-empire、Amazon-ratings（官方划分）；骨干同时用 GCN 和一个通道分离骨干（原图与粗图同骨干）；仅作适用性诊断，不作主要主张。ACE 代码若可运行则作对照。

## 5. 停止规则汇总

- G2d 不通过 → 停止标签项路线。
- G0 不通过且 E3 精度门槛不通过 → 暂停主线，回到选题讨论。
- 改善代理量（Brier、D、不纯度）但不改善精度或成本曲线 → 不作为贡献。
- 不在看到测试结果后改门槛、换主对照、逐图挑 M 或 β。
