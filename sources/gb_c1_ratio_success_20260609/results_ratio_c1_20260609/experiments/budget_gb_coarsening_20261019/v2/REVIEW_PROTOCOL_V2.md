## 3. 目标公式与实现锁

以下 n_B 均指球内**训练节点数**；|B| 指所有节点数；L 为训练节点总数。所有目标计数只用训练掩码内带噪标签。

| 臂 | 训练输入与目标 | 必须检查 |
|---|---|---|
| A | 原节点输入；原带噪 onehot | 原图/原缓存、L 行训练损失 |
| B | 原节点输入；q_B=counts_B/n_B，包含自身 | 同球训练节点共享目标，损失按节点均值 |
| Bprime | 原节点输入；(counts_B−onehot(y_i))/(n_B−1)；n_B=1 回退自身标签 | 纯 LOO 平均，无 alpha、无多数类拉近；不是完整 GB-LCSS |
| LCSS | 原节点输入；原 targets.py 完整公式，使用与 B/C 相同新球 | 是“旧目标在新球上的对照”，不是完整旧方法复现 |
| C | RX 或 R[X,PX,P²X]；q_B；球级 soft CE | 以 n_B/L 加权，n_B=0 无损失；不能按 M+ 均匀平均 |
| D | 按 C 的完整 |B| 多重集合随机分组；后续同 C | 精确相同全节点组大小；n_B 与 M+ 允许不同，必须记录 |

LCSS 原公式核读结论：

1. `min_train_per_ball=2` 指移除当前节点之后至少还有两票，故只有 **n_B≥3** 的球才有资格改变目标；n_B=1/2 保留自身 noisy onehot。
2. LOO 经验分布 p_i 使用其他训练节点。alpha_i=clip[(max(p_i)−1/C)/(1−1/C),0,1]。
3. 无并列时 local_i=(1−beta_target)p_i+beta_target onehot(argmax p_i)，原默认 beta_target=.5；并列时 local_i=p_i，禁止由类别编号破并列。
4. 最终 t_i=(1−alpha_i)onehot(y_i)+alpha_i local_i。alpha=0 时保持原标签。
5. `beta_target=.5` 与 `beta_cut=1` 是不同参数，manifest、日志和函数参数必须区分。若用户此前采用其他旧目标参数，应显式记录来源，不能靠本报告默认值暗中替换。

LCSS helper 当前会对传入的整个标签数组先 onehot，再只修改训练节点。为满足防泄漏设计，调用前最好创建仅训练位置填 noisy 标签、其余位置填固定合法哑值的标签向量；不要将整图 clean 标签传入目标构造器。类别总数是数据集任务元数据，不应靠查看测试标签动态推断。目标与训练输入不得保存验证/测试标签值。

B 与 C 在“同球内预测完全一致”时加权 soft CE 相同，但实际模型输入、dropout、图算子、参数更新均可不同，因此**这不是 B 与 C 等价的证明**。Bprime 对 n_B≥2 的球平均目标等于 q_B，但逐节点目标与预测的配对关系仍不同，损失和梯度一般不相同。

## 4. E2：只改变切面评分的标签来源

无标签树构造不得读取标签或训练位置；树可使用全图 X/A，这是转导协议，需照实命名。训练位置只在切面评分中用于 n_B。R3 使用 noisy train labels；O2 使用 clean train labels；之后两者都用同一份 noisy train labels 构造 q_B 并训练。O2 命名为“干净标签切面诊断”，不是分类精度上界。

树应保留完整父子关系。D 必须与计划一致，使用各通道 SSE/根通道 SSE；零方差通道需预定义为零贡献，不能除零。不要把通道行归一化后的等权拼接 SSE 默认为相同的 D。

继承规则：n_B≥2 用自身 LOO 不纯度；n_B=1 用最近支持数≥2的祖先；n_B=0 的加权标签代价为零；根也无足够支持时须有明确异常/默认约定。继承源由固定树与训练位置决定，不由类别值决定。固定分区下对称噪声恒等式不保证标签驱动选切面后无选择偏差；pair 多类噪声不能套用对称噪声缩放解释。

精确 M 不能靠“lambda 二分已接近”代替。lambda 剪枝存在离散跳跃；若使用确定性补切/合并实现 exact M，必须记录规则、顺序和 tie-break，并称为该启发式的 exact-size 输出。除非实际实现与验证了固定预算动态规划，否则不能称求得 exact-M 全局最优切面。补切依据也必须保留 R0/R3/O2 原评分差异，不能临时统一成 D 排序抹掉标签项。

必要不变量：同 dataset/tree_seed 的树哈希相同；同单元 R0/R3/O2 的 split/noise/source X/P 哈希相同；实际 M 相同；R0 不随 noisy label 的类别值变化；R3/O2 之外下游数据与超参不变。若噪声标签改动导致无标签树改变，应中止。

## 5. 图与缓存：易被忽略的比较混淆

- H 为 N×M onehot，R=diag(|B|)^−1 Hᵀ，P 是原图一次加自环并对称归一化的算子。P_c=RPH 一般**不对称且不是再次标准 GCN 归一化后的邻接**。custom GCN 必须直接使用给定 P/P_c，不再自动加环或归一化；记录边去重、自环与零度处理。
- cached C 必须先算原图 F=[X,PX,P²X]，再算 RF。若改成 [RX,P_cRX,P_c²RX]，则额外改变缓存传播，不能作为当前 C 的实现。
- 两个骨干训练粗输入，主部署均在原节点对应输入上前向。GCN 的 C>B 混有粗图训练及粗细图迁移；cached 的 C>B 更集中反映输入共享/压缩训练效应，仍不能把性能差直接归因于唯一机制。
- D 与 C 的所有节点组大小向量排序后逐项相等，D assignment 仅由独立随机种子与这些大小决定。不能拿“随机训练节点分组后随意塞无标签节点”冒充匹配随机全节点分组。D 的训练支持、空球、类混合不同属于真实结果，应记录而非强行调成相同。
- 球大小匹配不能排除所有随机分组质量差异；D 只检验所选随机控制下局部组织的价值，不足以证明粒球相对所有聚类方法必要。

## 6. 主选模与次要提升读数

主部署为原图/原节点前向；每 5 epoch 在干净验证集评估一次。patience=10 次验证检查意味着最多 50 epoch 无改进；max_epoch=300。记录严格/非严格改进判定、tie-break、epoch 5/10/…/300、模型 eval/no_grad 与 checkpoint clone，防止 state_dict 浅拷贝指向末轮权重。

所有臂的主 checkpoint 按同一种原节点验证指标选择。C/D 的提升预测 HZ_c 若单独选 checkpoint，必须独立保存验证最佳 epoch 和权重；不能把两种测试精度取最大。主训练的停止条件按主验证决定；次要提升读数只在这个共同训练轨迹内选模，不能声称覆盖额外训练后的最优值。若次要指标改变训练停止，则必须作为额外流程单独计费并说明。

最终主测试与次要测试都只在配置冻结与训练完成后计算；测试值不得驱动 checkpoint、预算、骨干或提前停止。每臂保存主/次 checkpoint 身份、原始预测与测试索引，避免汇总表误读字段。

## 7. 成本：独立进程是必要条件，不是完整答案

每臂独立 subprocess；准备缓存先在 CPU 完成并落盘，训练子进程只加载必要对象。GCN 不加载 concat 缓存。原图部署阶段确实需要原图对象，因此不能把该阶段峰值排除出完整峰值。父进程 RSS、准备峰值和训练子进程 RSS 不相加冒充峰值；需要记录阶段定义与是否并发。

至少保存以下分项：data load、common feature/propagation preparation、coordinate/SVD、tree、cut（含 exact M 修复）、target、coarse operator/cache、serialization/load/transfer、GPU 初始化/模型构造、train、validation、checkpoint 操作、main inference、secondary inference、诊断与审计。明确哪些诊断是科研额外成本，不能既从方法成本剔除又计入对照成本。同步 GPU 计时；进程墙钟另记启动/导入等冷启动开销，不与内部阶段简单相加造成双计。

必须区分：

1. **单任务冷启动完整时间**：该臂从空方法缓存开始，到主部署完成的所需成本；同样允许原节点臂做合理公共缓存。
2. **共享准备 + 任务增量**：T(K)=T_shared+sum(T_incremental,k)，给定事先锁定的复用范围和 K。缓存文件存在不能让其原始构造时间在单任务口径中消失。
3. **每轮训练成本与实际总训练时间**：早停轮数不同是端到端流程的组成，但不能把总训练速度比称为每轮加速。
4. **阶段峰值与完整峰值**：torch allocated/reserved 分开；CPU RSS 与 GPU allocator 不是同一量，不能相互替代。GCN 原图验证和推理可能决定整个任务峰值。

树缓存键必须含图/特征/坐标/建树参数/tree_seed/实现哈希。切面键还含训练位置、标签源、噪声标签哈希、beta_cut、M；目标键含 assignment、noisy label、训练位置与目标参数；不依赖标签的 R0 不应被不必要的标签源污染。若 tree_seed 随实验 seed 变化，不能跨这几个 seed 宣称同一棵树复用。cached 基线与 C/D 同等复用 [X,PX,P²X]；不能只给粗模型摊销。

禁止同机其他实验占用 GPU 后仍将结果当可靠成本比较。独立子进程串行运行与资源记录优先于过度重复计时；若只做一次冷启动，应直说单次读数，不能伪造 3 次计时中位数。

## 8. 训练前最低验证清单

这些是小规模 CPU 张量/工件检查，不要求增加训练变体：

- split 不交叠且覆盖预定节点，noise 只改 train，实际翻转率与 uniform/pair 映射记录；每配对 split/noise 哈希相同。
- A/B/Bprime/LCSS 目标每行有限、非负、和为 1；空球不计损失；n_B=1/2/3、全一致、并列、多类小例逐项核对。LCSS 与原 helper 对相同合法输入数值一致。
- 在任意 logits 小例下，C 的 n_B 加权损失与把同球 logits 复制给每个训练节点后的 CE 一致；不只是比较 q_B 是否一致。
- H 每行一个 1，无空输出球；R 行和为 1；RX、RPH 与小例稠密算式一致；所有预算实际 M 精确达标。
- D 全节点组大小多重集合与 C 严格相等；训练支持差异日志保留。
- E2 只替换 cut label source；训练目标确实仍来自同一 noisy 标签；R0 的输出不随标签类别变化。
- checkpoint 主/次分开；主验证每 5 epoch，10 次无改进退出；主测试读取主 checkpoint。所有阶段计时、峰值和训练 epoch 字段都有值且含义明确。
- 对计划 manifest 做预期行数审计；失败行保留错误/状态，不丢弃、不用旧 E0 补齐。恢复运行按配置哈希和完整工件校验，不能只看 CSV 有行就跳过。

## 9. 结果解释的天花板

三 seed 的配对差、均值、样本标准差、正向 seed 数和全部数据×噪声单元都应报告。0.5pp 是预设实用差距带，只作描述；落在该带内不证明统计等价、非劣或机制等价。不得以 C≈B 证明粗化完全可被标签平滑替代。

C 比 A 好而未超过 B/LCSS，不自动否定粗化：若相对可靠的完整基线有清楚的计算收益与可接受精度代价，仍支持预算化方法故事。反之，压缩训练更快但完整流程更慢，应据实区分局部节省与总成本。D 低于 C、O2 低于 R0 等负结果同样保留。

O2 未改善，只支持“该树、预算、beta_cut 和骨干下，干净标签评分未产生足够增量”；不能否定所有标签感知粗化。R3 只在个别格子提升也不能写成稳定抗噪。先完成已锁定最小矩阵，再依据整体证据决定继续、修改、暂缓或放弃；本轮不要新增交叉拟合、门控、收缩或调 beta 来挽救局部结果。
