# SimMLP 共同骨干适配实验

日期：2026-10-09。范围：五个主数据集、uniform 0.4、seed 0，GPU。
这是单 seed 筛查，不是五 seed 论文结果；没有修改论文，也没有覆盖旧实验。

## 1. 固定实验设置

- 使用主实验原始属性、20%/10%/70%划分、同一份 seed 0 噪声训练标签。
  所有划分和噪声 SHA-256 均与主实验历史记录一致；验证/测试标签未污染。
- 部署结构直接拆分现有共同 MLP：d→64→C，两次 Linear；第一层后
  ReLU、BatchNorm、dropout 0.5。没有残差、PReLU 或输出 L2 归一化。
  作者辅助预测器、聚合器和解码器保留其原有结构，但不参与部署。
- 200 轮无标签自监督预训练，再冻结编码器并训练 200 轮分类头。
  两阶段均用 Adam、学习率 0.01、权重衰减 0.0005，不使用调度器。
- 保留作者图对齐、停止梯度、图增强、属性重构和冻结后线性分类机制。
  自监督训练函数只收到属性和边，收不到标签与评估划分。
- 预训练固定取最后一轮；分类头取干净验证集准确率首次最优检查点。
  冻结阶段编码器参数、BatchNorm 统计量不变，关闭编码器 dropout。
- 与旧版相比，分类头在共同 MLP 初始化时一起初始化，而不是预训练后初始化。
- 方法特有设置保留预先确定的作者数据集预设；CoraFull 继续使用 Cora
  预设作为缺省适配。没有根据本轮测试结果修改参数。

## 3. 核验与成本

四项快速单元测试通过：文件存在、共同骨干训练/推理逐元素输出一致、
固定协议配置、自监督可训练且分类头阶段冻结编码器不变。
Cora 的 2+2 轮 GPU 冒烟运行通过。五个正式运行每个均有 200+200 轮日志。

五个检查点在 CPU 重载后均复现相同验证/测试精度；最大概率逐元素误差
约 1.49e-6。所有代码哈希、主实验协议哈希、首次验证最大值轮次、冻结

## 4. 结论及证据边界

已支持：相同划分与噪声下，这组共同协议适配版在五个数据集均低于旧版；
差值范围为下降 0.37 至 9.15 个百分点。CoraFull 变化最大，Photo 最小。
这说明旧版结果依赖其整体实现设置，不能直接作为共同两层骨干比较。

不能推出：多一层单独贡献了这些增益。本轮同时改变部署结构、激活与
归一化、优化器、调度器、分类头初始化时点以及验证并列规则，不是单因素消融。
也不能从一个 seed 判断稳定优劣或统计显著性。

共同骨干不等于相同训练流程：SimMLP 自监督预训练后冻结编码器，
GB-LCSS 则用软目标训练 MLP。这是方法机制差异，必须保留，不能为了
表面一致将 SimMLP 改为普通 CE。结果应标为 SimMLP (matched backbone)，
而不是声称完全复现作者原始结构的 SimMLP。

最终决策：本次单 seed 运行完成并保留。没有额外搜索、增加 seed、
重跑旧实验或修改论文。正式加入论文表格仍需完整同协议多 seed 结果。

- matched_adapter.py：共同骨干模型和训练实现。
- run_matched.py：单 seed GPU 调度及原始记录保存。
- test_matched.py：四项快速测试。

- results.csv、artifact_audit.json：机器可读汇总和核验。
- runs/<dataset>/simmlp_matched/：配置、协议、环境、源码哈希、日志、
  检查点、概率及结果。smoke/ 为单独存放的冒烟实验。
