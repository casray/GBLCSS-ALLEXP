# 根据数量诊断重新设计粒球：构造树与选择监督粒度分开

2026-10-15。本文给出可检验的候选设计，**不是已经训练验证的新算法成绩**。最终分类曲线见综合结论与接续及实验结论。本轮已实现并测试的是固定支持约束的嵌套树生成器；下面的训练内剪枝尚未实现或声称优于原方法。

## 1. 诊断改变了什么判断

1. 统一的5%平均半径门槛不适合所有表示；这已由旧GREET的单球与新树的可行分裂证实。但取消门槛并不能保证每次细分都改善监督。
2. 用冻结后的干净标签事后检查，GREET在各图/噪声条件平均约17%–36%的正SSE分裂会使目标Brier变差。相对SSE收益与监督收益的Spearman排序相关很弱，不能直接把几何收益当作去噪置信度。
3. 请求球数、实际球数和有效投票量必须分别记录。小图在支持16约束下很早达到平台；继续把请求64改成256没有改变区域。
4. 同一个区域是否值得细分，可能随噪声类型、类别混合和证据支持而改变；全局统一B无法表达这种差异。
5. 好目标不一定能被X-only MLP利用。数量/剪枝方法不能自动解决编码空间或学生输入的信息限制。

因此，下一版不宜继续搜一个“更聪明的统一B公式”，也不宜把Cora用细球、CS用粗球这种事后结果写成算法。

## 2. 已交付的工程生成器

`granular_ball_trajectory.py::build_ball_trajectory`只输入H、训练节点位置和固定约束。它产生同一棵树及各预算快照，支持前缀不变、正SSE、训练支持下限、退化停止和完整trace。它是研究新停止规则的基础设施；本身还不是监督语义自适应算法。

普通验证集选B也是可运行的工程参照：对预定义预算分别训练，依据validation_accuracy选模型，并列优先较少的实际球数。本目录`validation_budget_diagnostic.py`只以验证分数选择，再读取test报告。这属于事后补充诊断与普通超参数选择，不构成新的粒球方法贡献，而且比固定B消耗更多验证选择预算。

## 3. 推荐的研究候选：无标签树＋训练内剪枝选择

核心是让树负责提供候选区域，让独立训练证据决定这些区域何时被采用。不要用噪声标签直接计算纯度后递归硬分裂，也不要把同球身份当作硬正样本。

### 输入和输出

输入：冻结无标签表示H、训练集合T、观测训练标签Z_T、固定的树容量与支持约束。验证/测试标签不进入区域选择。

输出：每个训练节点的可用监督区域及软目标；不同折可以采用不同剪枝，允许最终证据为多粒度组合。应区分“几何树的叶球数”和“实际参与监督的区域数”，而不是只报告一个B。

### 第一步：几何候选树

沿用本轮SSE优先、固定最小子球与支持下限构建树，保存父子关系和全节点归属。树生成不接收任何类别。预算是计算上限和候选覆盖范围，不能当作必须达到的数量。

### 第二步：分离被监督节点、选择证据与投票证据

把训练节点按与类别无关的固定随机划分分成三组。对每个查询折Q，另两折分别承担选择S和投票V，再交换S/V做第二次估计。Q节点的观测标签只能出现在自己的最终标签锚中，不能参与它的区域选择或投票。

将S再分为拟合A和评分D。A在每个候选区域形成观测标签多数类预测，D仅用于评分；空区域或缺乏支持的区域回退到有证据的祖先。分折不能使用真实污染标记。

这一设计的目的不是增加网络，而是防止同一批噪声标签既决定“这个球很可靠”，又为自己背书。

### 第三步：对整棵树做剪枝，不贪心检查单次分裂

对每个节点B，用A_B的多数类预测D_B，得到观测分类错误数L_D(B)。一个具体、但尚未验证的保守评分是：

`cost(B) = L_D(B) + sqrt(|D_B| * log(2M/delta) / 2)`

其中M是预先确定的候选树节点数，delta是预先固定的置信参数；不能从本轮test峰值拟合它。该式是用于观测0–1风险的保守候选，不是软标签Brier的无偏估计。

首个候选若实施，固定delta=0.1，V内最低16个投票节点，S内A/D各半；不再做一串置信参数或支持阈值网格。以上是下一轮待验证的具体版本，不是本轮已使用的设置。

自底向上比较“保留B”的cost与两个子树的最优cost之和，取较小者；完全并列保留父球。没有评分证据、没有原型证据，或投票V不足预定支持的子树不可采用。计算完整子树代价，避免上层分裂暂时不改善而把后续有用细分全部截断。

最终球数由局部保留/剪枝决定，不手工指定每个数据集的test最佳B。

### 第四步：独立投票与原LCSS目标

对n属于Q，使用选中区域内V的观测标签计算原来的留一投票、q和alpha。V与Q不相交；若证据不足则沿祖先回退，仍不足时回退观测标签。交换S/V得到另一份目标，平均两份有效概率目标。

保持X-only学生和原训练协议，使收益可归因于区域选择。先不同时改编码器、对比损失、alpha公式或分类器。

### 伪代码

```text
tree = build_label_free_tree(H, T, fixed_support, computation_cap)
folds = split_training_indices_without_using_labels(T, seed)
for query_fold Q:
    estimates = []
    for (S, V) in the two orders of the other folds:
        A, D = split_indices_without_using_labels(S)
        prediction[B] = majority_label(Z[A intersect B]), with ancestor fallback
        cost[B] = heldout_disagreement(prediction[B], Z[D intersect B])
                  + predefined_uncertainty_penalty
        regions = bottom_up_prune(tree, cost, support_from_indices_of_V)
        estimates.append(original_LCSS(Q, voters=V, regions=regions))
    target[Q] = average(estimates)
student = train_original_X_only_MLP(target)
```

## 4. 为什么不使用“最小噪声Brier”直接选区域

对不依赖评分节点自身噪声标签的固定类别预测，在独立对称翻转下，观测0–1风险满足：

`R_noisy = eta + (1 - C*eta/(C-1)) * R_clean`。

当系数为正时，期望风险排序保留。这只解释了为何可把训练内分类分歧作为候选信号；不证明有限样本下正确选树。

对概率预测的Brier，噪声期望还含预测概率平方范数项，不能直接声称排序相同。Pair噪声也不满足上述简单标量关系，必须单独验证，不能把对称噪声结论外推。

## 5. 该候选的明显代价和理论边界

- 三组角色会显著减少每次投票和评分的样本。低标注量、70类CoraFull、小图都可能因此退化；这不是可忽略的实现细节。必须把“选择质量”与“数据利用率损失”分开消融。
- 几何树仍无标签，但最终监督区域依赖观测训练标签。论文不能继续把整个过程称为完全无标签构球。
- 因Q的标签未进入S或V，仍可争取保持对自身标签锚的留一独立性。条件于选择折S，V的独立人工翻转可用于重新推导投票边界；仍需要正的干净投票边际，不能自动保证正确多数。
- 区域选择、两次角色交换、置信惩罚和随机分折都需要完整的新分析。原Proposition不能直接改符号后照搬；Pair情况尤其没有现成保证。
- 评分只考查H中的区域标签预测，未必体现X-only学生可学习性。若Roman仍“目标改善、分类不动”，必须转向表示/学生信息诊断，而不是继续堆剪枝模块。
- 这是一种待检验的研究设计，不声称已构成独立论文创新；树剪枝与交叉拟合都是通用工具，贡献必须来自图噪声监督问题的具体机制和实验证据。

## 6. 先验证什么，何时应该放弃

先冻结一个具体参数版本，比较同一H/同一协议下的原64、同树64、细树终点、仅验证集选B，以及候选剪枝。用户本轮暂缓的独立kNN/k-means保持在未来单独阶段，不用缺少它们的实验宣称粒球必要性。

必要消融：不剪枝；仅几何/支持停止；选择后使用全部训练票（经验变体，不保留S/V条件独立保证）；严格独立V票。所有新目标先冻结，再诊断Brier/边际和分类，保留clean损害及Pair负结果。

若严格分折因证据稀疏而退化，不通过改test最佳阈值掩盖。若同树的干净标签oracle剪枝相对最佳固定前缀的Brier空间已经很小，也不应预期实际无真值剪枝能带来巨大目标收益。该oracle仅是“当前树＋全训练投票＋原LCSS”的目标质量参考，不是新分折方法的形式上界，更不是分类准确率上界。

当前最应避免的重设计是：按test逐图指定球数、增加一串几何阈值、重新包装已失败的ESS×JS乘法门控、或同时修改所有模块后无法归因。
