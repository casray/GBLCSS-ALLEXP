# 图噪声鲁棒教师与蒸馏：seed 0 筛查

已完成 40/40 组，失败 0 组。

## 1. 实验回答什么

比较近期鲁棒图方法作为教师时的精度，以及这些教师接相同属性 MLP 后的效果。参考线为 GCN+CE 和 GB-LCSS 目标训练的 GCN。粒球只用于参考线，未加入 TFR、ERASE。

五个数据集，训练标签 uniform 0.4/0.6，seed 0，20%/10%/70% 划分；验证和测试标签均未污染，检查点仅由验证精度选择。所有模型和逻辑回归探针在 RX 7700 XT 上训练。

## 4. 配对差值与方向判断

- TFR：教师在 2/10 个设定高于 GB-LCSS GCN，平均差值 -17.78 pp；学生在 2/10 个设定更高，平均差值 -17.07 pp。
  uniform 0.4：学生 0/5 个设定更高，平均差值 -19.06 pp。
  uniform 0.6：学生 2/5 个设定更高，平均差值 -15.07 pp。
- ERASE：教师在 6/10 个设定高于 GB-LCSS GCN，平均差值 +2.11 pp；学生在 8/10 个设定更高，平均差值 +3.36 pp。
  uniform 0.4：学生 3/5 个设定更高，平均差值 +0.91 pp。
  uniform 0.6：学生 5/5 个设定更高，平均差值 +5.81 pp。

本轮证据：ERASE 在 uniform 0.6 下的学生在 5/5 个数据集上高于 GB-LCSS；较低噪声下并非全面占优。ERASE 学生低于 GB-LCSS 的设定为：CiteSeer u0.4 (-1.07 pp), Coauthor-CS u0.4 (-0.19 pp)。
GB-LCSS 学生高于普通 GCN+CE 学生的设定为 7/10；CoraFull 等负结果同时保留，不能只报告优势数据集。
解释边界：本轮支持筛选更强的教师路线，但尚不能确定差距来自鲁棒机制、模型容量、预设参数、输出置信度还是这些因素的组合。

## 5. 可比性与限制

- TFR 使用作者 DBLP 预设；作者未提供本轮五数据集的预设。ERASE 使用作者 Cora、CiteSeer、CoraFull 预设，Coauthor-CS 与 Amazon-Photo 固定迁移 Cora 预设。本轮没有调参，不代表各方法最优效果。
- TFR 核心 GCN/解码器、ERASE GAT/损失类直接来自作者代码。稀疏传播、散射和原型计算做了 ROCm GPU 适配。ERASE 使用作者已有的等价多类压缩公式避免平方规模的成员矩阵；逻辑回归保持 C=1 多项式目标，GPU LBFGS 与 sklearn 合成测试通过。
- TFR 按作者训练循环保留解码器在第一次验证后保持 eval 的行为。未擅自修正作者代码而改变方法。
- TFR 第一批 8 次尝试提前添加了图级自环，与作者 DBLP 数据配置不符，已归档为 superseded_tfr_selfloops，不参与最终统计。修正后使用原始图，由 GCN 和解码器各自在内部添加自环，其他超参数未调整。
- ERASE 作者对 Cora/CiteSeer 默认做特征行归一化；本轮为匹配主实验，统一使用原始特征。因此输入预处理也属于本轮协议适配，不能把本轮结果当作作者原协议的直接复现。
- 参考教师使用主实验原始特征和已核验的粒球成员缓存。学生训练前对每个教师统一重置 RNG，因此本轮 GB-LCSS 学生不是论文原始 seed-0 学生的逐数值重现。历史值单独记录，未与本轮混算。
- 教师预算按公开方法保留：TFR 500、ERASE 400（patience 150）、参考 GCN 200；学生均为 200。这里只统一评估及学生训练协议，尚未统一教师计算预算。
- 教师架构和容量也按方法保留：参考 GCN 隐层 64，TFR 公开预设隐层 16，ERASE 隐层 256、表示维数 512。本轮比较完整路线，不是只替换损失的机制消融。
- 记录的 GB-LCSS 运行时间不含已完成的 GRACE 预训练和粒球划分；不能与其他方法直接做端到端训练成本排名。
- 单 seed 无法给出稳定排名、标准差或统计显著性。差值只是下一轮实验的筛选依据。

## 7. 决策

继续：优先为 ERASE 与两条 GCN 对照补足 seeds 1-4，检验强噪声优势能否重复。TFR 优先跟进 CiteSeer uniform 0.6 的优势，其余数据集先核查迁移预设，不直接扩大调参。修改：增加与 ERASE 同容量的 GAT+CE 对照，隔离鲁棒机制与架构容量的贡献；随后再检查输出置信度和蒸馏损失。暂缓：不能用本轮迁移预设下的负结果否定某个已发表方法。
