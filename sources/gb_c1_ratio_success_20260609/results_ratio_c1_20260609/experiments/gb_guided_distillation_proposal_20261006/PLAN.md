# 强鲁棒教师下的粒球引导蒸馏：首轮实验方案

日期：2026-10-06。状态：待用户确认；尚未修改训练代码或启动实验。

## 1. 研究问题与假设

固定一个已训练的 ERASE 图教师及同一个属性 MLP，粒球局部监督能否比普通蒸馏带来额外收益，同时保留教师的分类精度？

研究假设：教师对部分节点给出的概率较分散，而这些节点所在粒球的其他训练标签具有较集中意见。把这种局部证据以保守权重加入学生目标，可能减少错误知识迁移。

这是假设，不是已支持结论。投票集中程度不是正确概率，教师最大概率低也不意味着教师错误。强教师已正确而粒球共识错误时，候选方法可能降低精度。

粒球角色：训练阶段的软监督参照及投票集中程度信号。不改变图教师，不把同球成员当作硬标签，不增加学生输入，不在推理时查询粒球或图。

## 2. 为什么选择这条路线

可选路线包括：固定教师并辅助修正学生目标；保留教师目标但按粒球信号重加权蒸馏样本；把粒球加入教师训练后重新训练教师。

本轮选择第一条。它可以复用已有教师，并通过同位置、同权重的对照区分局部目标内容的作用。第二条会改变样本贡献，机制归因稍复杂；第三条同时改变教师质量和迁移，暂不采用。

历史约束：不在鲁棒教师隐层重新构球。MLP-53 已出现分类隐层粒球退化为单球的负结果；本轮沿用原 GRACE 空间及核验后的粒球成员。也不增加多分区、跨分区票数池化或新表征模块。

## 3. 固定设置

| 项目 | 本轮设置 |
|---|---|
| 数据集 | Cora、CiteSeer、CoraFull、Coauthor-CS、Amazon-Photo，全保留 |
| 噪声 | 训练标签 uniform 0.4 和 0.6 |
| 种子 | 0，作为探索性筛查；没有标准差或显著性结论 |
| 划分 | 与已完成实验完全相同的有序 20%/10%/70% 划分和噪声指纹 |
| 教师 | 每个设定对应的已保存 ERASE 教师及其全节点概率；固定、不重训 |
| 粒球 | 主实验 GRACE 粒球缓存，默认设置不变 |
| 粒球目标 | 原 GB-LCSS 留一、平局安全目标，beta=0.5，s_min=2 |
| 学生 | 只输入原始属性的两层 MLP，hidden=64，BN，dropout=0.5 |
| 优化 | Adam，lr=0.01，weight_decay=0.0005，200 epochs |
| 蒸馏 | 温度 1，全节点软交叉熵；各方法训练前同样重置学生 RNG |
| 模型选择 | 只用干净验证精度，与已有实验相同的严格提升检查点规则 |
| GPU | RX 7700 XT；既有 noisygl-rocm721 Python 环境，不允许 CPU 训练回退 |

本轮固定 ERASE，避免按测试精度逐数据集选择教师。TFR 的 CiteSeer 强噪声优势单独作为参考，不把两条教师路线事后拼接成一个方法。后续需要检验第二种教师及更广的强图方法。

## 4. 候选方法

对节点 v，记教师概率为 P_v，原 GB-LCSS 软目标为 t_v，其投票集中程度权重为 alpha_v。只在有足够其他训练节点投票的训练节点上启用辅助目标。

候选权重和目标为：

\[
w_v=\lambda\alpha_v\left(1-\max_i P_{v,i}\right),\qquad \lambda=0.5
\]

\[
\widetilde P_v=(1-w_v)P_v+w_vt_v
\]

验证节点、测试节点、未分配节点和不满足投票条件的训练节点取 w_v=0，因此目标保持 P_v。训练仍然是在全节点上最小化相同的软交叉熵，没有新增损失项或损失归一化变化。

直观含义：教师概率越集中，辅助修改越小；局部投票越分散，辅助修改也越小。lambda=0.5 使教师在每个目标中至少占一半。lambda 是本轮待检验的固定设计，不是已经调出的最优参数；不按数据集或噪声率调整。

注意：这混合的是原 GB-LCSS 最终目标，并非单独的多数类标签。它仍包含原观测标签的贡献，所以需要下面的观测标签对照。

## 5. 对照设计

| 编号 | 目标构造 | 回答的问题 |
|---|---|---|
| D0 | 原教师概率 P_v | 普通蒸馏基线 |
| D1 | 同 D3 的修改节点及 w_v，辅助目标换成观测标签的 one-hot | 收益是否只是加入训练标签，而非局部共识内容？ |
| D2 | 真实 GB-LCSS 目标，但所有合格训练节点使用相同的平均权重 | 自适应分配权重是否优于同等总修改量？ |
| D3 | 上述候选方法 | 真实局部目标和自适应权重的联合效果 |
| D4 | 同 D3 的修改节点及 w_v，辅助目标来自随机大小匹配分组 | 在固定修改强度下，真实局部成员是否有贡献？ |

D1、D4 为机制对照：它们继承真实粒球产生的 w_v，因此不是完全不使用粒球信息的独立方法。D1 隔离目标内容，D4 隔离局部目标的成员来源，不能把它们称作完整 no-ball baseline。

D2 的平均权重在合格训练节点上计算，使该臂与 D3 的权重总和一致；其余节点均不修改。这样避免把候选较好简单归因于“修改更少”。

D4 只对合格训练节点的球编号做固定种子 137 的置乱，其余节点编号保持不变。保留每球总节点数及训练节点数，仍排除自身投票，并使用相同 GB-LCSS 目标规则。D4 使用 D3 的权重，不使用随机球自己计算的 alpha 来决定修改强度。这能保留修改位置和权重，但不保证每个节点的实际概率位移相同，后者另行记录。

已有 GB-LCSS 教师蒸馏结果与 ERASE 图教师作为外部参照，不计入上述学生侧机制消融。

总共 10 个数据集—噪声设定，每个设定 5 个学生臂，共 50 行结果。D0 已有 10 行；先对一个设定做原路径回放，确认缓存和 RNG 可逐数值对应，再复用 D0。因此主要新增 40 次学生训练，不新增教师训练。

## 6. 两阶段执行与诊断

第一阶段固定并保存全部目标及其配置指纹，检查概率有限、非负、行和为 1，以及非训练节点目标不变。lambda=0 必须还原 D0；没有有效投票、alpha=0 或教师最大概率为 1 时也必须还原教师目标。

记录覆盖率、权重均值和分位数、修改前后概率的 L1 距离，以及实际改变最大概率类别的比例，判断候选是否真实激活。

第二阶段按相同初始化、dropout RNG、epoch 预算和验证选择规则训练全部学生。所有变体和配置在读取新增测试结果前固定，不因某个单元结果不好而中途改参数或丢弃数据集。

以下机制指标只作运行后的诊断，不参与目标构造、调参、选教师或选检查点：

- 在训练节点上，用原始干净标签核算教师目标、粒球目标及混合目标的 Brier 分数。
- 在教师与粒球类别不一致的训练节点上，统计“教师错、粒球对”和“教师对、粒球错”。
- 统计目标实际纠正及损坏多少个训练节点的最大概率类别。
- 在完整测试集报告学生纠正教师错误、学生破坏教师正确预测的数量，以及净精度差。

原始训练干净标签只能在目标和配置固定后用于这组分析，不得反推权重或筛选节点。没有独立性证据时，不把 GB-LCSS 与 ERASE 的错误称作独立。

## 7. 主指标与预先约定的判断标准

主指标是 D3 相对 D0 的测试精度配对差值，十个设定等权汇总，并逐格完整展示。

次指标为 D3-D1、D3-D2、D3-D4，以及每个学生相对同一 ERASE 图教师的差值。还记录学生训练耗时、训练峰值显存和预计算目标成本；推理代码保持属性 MLP，不比较不完整的端到端教师训练成本。

进入五种子阶段的探索性门槛暂定为同时满足：

1. D3 相对 D0 在至少 6/10 个设定为正，平均增益至少 0.5 个百分点，没有单格下降超过 1.0 点。
2. D3 相对 D4 在至少 7/10 个设定为正，平均增益至少 0.3 点。
3. D3 相对 D1 的平均差值为正；否则无法证明局部目标比同权重训练标签更有价值。
4. D3 的十格平均值高于 D2；否则先保留更简单的等权设计，不声称自适应权重有效。
5. D3 相对 ERASE 图教师每格损失不超过 2.0 点。这是工程门槛，不是统计非劣证明，也不是超过全部强图方法。

上述 0.3、0.5、1.0、2.0 点都是待用户确认的资源分配标准，不是从统计显著性推导的阈值。单 seed 通过也不能写成稳定提升。

## 8. 失败标准与最终决策

- D3 不优于 D0：本轮没有支持粒球辅助强教师蒸馏，停止该固定变体，不通过加大混合强度追测试精度。
- D3 与 D4 接近：局部成员来源没有得到足够支持，不把结果归功于真实粒球几何。
- D1 与 D3 接近或更好：优先研究简单监督锚定，不能声称粒球共识提供额外收益。
- D2 与 D3 接近或更好：自适应权重缺少证据，优先选择简单方案。
- Brier 改善但学生精度不改善：只支持目标概率误差变化，不支持分类收益。
- 权重及实际概率位移几乎为零：记录为机制激活不足、筛查未决，不把无变化解释成可靠性已被验证，也不宣告所有粒球蒸馏方向失败。
- 通过门槛：获得用户授权后补 seeds 1-4，随后检验其他噪声类型、第二种教师、普通可靠性蒸馏和同空间 kNN；不跳过这些比较直接升级论文 claim。
