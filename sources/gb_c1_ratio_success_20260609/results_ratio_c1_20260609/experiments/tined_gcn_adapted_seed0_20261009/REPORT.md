# TINED 共同 GCN 教师适配实验

日期：2026-10-09。五个主数据集，uniform 0.4，seed 0，GPU。
本轮完成全部五图，不覆盖旧实验，不修改论文，不追加搜索或其他 seed。

## 1. 实验设置

主实验原始属性、20%/10%/70%划分、仅训练标签加噪均保持不变。
五图的划分和噪声 SHA-256 与主实验历史记录完全一致。训练模块只接收
噪声训练标签和单独的干净验证标签，不接收测试标签。

教师改为现有共同 PyG GCN：两层、隐藏64、dropout0.5、原始 X 和 A。
使用 Table 8 CE 路线相同的原始稀疏邻接方向、重复边合并、归一化及
自环处理；初始化按共同 MLP 后共同 GCN 的随机数消耗顺序。
Adam，lr0.01，wd0.0005，200轮；教师验证并列保留末次，和现有 CE 教师路线一致。
本轮重新训练共同 GCN，并不声称已经重载 Table 8 的原始同一教师检查点。

学生保留官方 MLP_from_sequence_of_layers 定义与前向：四个 FC，分别
模仿两层教师的 FT 和 GP，复制教师 FT 权重和偏置，GP 模仿层按预设初始化。
GCN 的 FT/GP 能量目标从对称归一化传播提取，不能沿用 SAGE-gcn 的邻居均值。
学生只用原始属性推理，不需要图；这是 TINED 而不是 TINED+。

学生200轮，Adam，基础lr0.01、wd0.0005，无调度；保留方法的注入层
学习率倍率、独立 CE/KL/DE 优化步骤及全节点 KL 蒸馏。即使 CE 权重为0，
仍按官方流程执行对应 Adam step。学生由干净验证集首次最优轮次选择。

作者 best_records JSON 没有完整 GCN 最佳预设，只有 SAGE 预设。
机制参数延用此前预先确定的 SAGE-transductive 记录，不伪称 GCN 官方最佳配置。
本轮恢复该记录的学生 dropout，而不是所有学生强制设为0.5：

| 数据集 | 学生 dropout | 机制参数预设 | 是否缺省适配 |
|---|---:|---|---|
| Cora | 0 | Cora | 否 |
| CiteSeer | 0 | CiteSeer | 否 |
| CoraFull | 0 | Cora | 是 |
| Coauthor-CS | 0 | Cora | 是 |
| Amazon-Photo | 0.5 | Amazon-Photo | 否 |

lr/wd和训练预算仍采用共同协议，不采用作者各数据集的最佳lr/wd。
CoraFull70类大于隐藏64，官方层序为FT-GP-GP-FT；其余为FT-GP-FT-GP。
不强行压学生为两层，否则无法保留此方法的完整机制。

## 3. 训练轨迹与未解决问题

| 数据集 | 学生最优轮次 | 最优验证 (%) | 最后轮验证 (%) | 最优模型全图预测类别数 |
|---|---:|---:|---:|---:|
| Cora | 6 | 80.0000 | 28.1481 | 7/7 |
| CiteSeer | 118 | 69.2771 | 63.8554 | 6/6 |
| CoraFull | 181 | 53.2592 | 51.0864 | 46/70 |
| Coauthor-CS | 61 | 93.5079 | 92.6896 | 15/15 |
| Amazon-Photo | 10 | 75.6863 | 27.3203 | 6/8 |

已支持：四图相比旧适配提高，Photo下降。CoraFull从19.19%恢复至51.75%，
且其第200轮验证51.09%，不再表现为此前极早退化的情况；但仍低于本轮
GCN教师61.67%，且最优模型全图只预测46/70类，不能称为完全解决。

Cora和Photo仍存在明显后期退化。记录中的测试结果均来自验证选中的
最佳模型，未导出错误的最后一轮。因此最佳检查点有效和训练过程稳定
是两个不同结论：产物一致性通过，不等于方法配置已足够稳健。

Photo的教师89.36%，学生74.81%，说明这次弱结果不能简单归咎于教师
精度低。Photo学生dropout仍为0.5，不能把它的下降说成采用dropout0的效果。
Cora即使dropout0仍后期退化，也说明dropout修正不是所有不稳定性的完整解答。

合理但未验证的解释：共同lr/wd与TINED的分阶段优化及DE约束可能不够
兼容，尤其原作者Photo学习率为0.001，而此处基础学习率为0.01。
这不是单因素因果结论；没有增加学习率、DE权重等试验。

本轮同时更改教师、学生dropout和学生验证并列规则，不能将增益单独
归因于GCN或dropout。只有一个seed，没有mean/std或显著性证据。
完整官方DGL训练与此PyTorch移植的端到端等价性仍未验证。

最终决策：共同GCN适配单seed实验完成，保留所有正负结果，不立即
据此声称正式基线已定稿。若继续正式多seed，需先由用户决定是否保留
严格共同lr/wd，还是允许预先声明的方法特定优化器参数并仅用验证集选择。
没有用测试结果追调参数或自动替换旧分数。

## 4. 核验、成本与产物

五项快速单元测试通过：共同GCN前向及FT/GP目标、学生注入与层序、
预设与并列选择规则、DE值与detach-normalization梯度，以及适配文件存在。
Cora GPU 2+2轮冒烟通过。五图均完成200轮教师加200轮学生日志。

五组教师和学生检查点均在CPU重载复现同样验证/测试精度。源码哈希、
主实验划分/噪声指纹、教师末次/学生首次验证最大值轮次、学生保存的
能量目标一致性全部通过。最大重载概率误差约1.43e-6。
PyG COO转CSR及CSR beta提示是警告，未造成运行失败。
