## Hypothesis and granular-ball role

For a fixed proposed replacement class and fixed correction coverage, stability of leave-one-out
votes across granularities and graph perturbations reduces incorrect corrections beyond the averaged
vote margin and unique observed-training-node support. GB organizes scopes, not hard positives.
Frozen encoder is label-agnostic; no supervised encoder/student/teacher updates in this screen.

Distinct questions:
1. Are corrections proposed by vote averaging more accurate? (descriptive, not stability evidence)
2. For the SAME proposed corrections, does stability improve selection? (primary mechanism test)
3. Does GB outperform equivalent multiscale BKM/KM/kNN controls? (GB-specific test)

## Groupings and correlation controls

GB: one label-free recursive split tree per representation, original mean-radius reduction >= .05,
minimum child size 32, max balls 64, k-means++ n_init10 with seed=iteration+position.
Save leaf cuts at 16/32/64 requested budgets; if splitting stops early, report actual counts and
reuse final cut. Do not pretend a 64-cut exists if only 50 balls are possible.

BKM: bisecting k-means biggest_inertia; same actual region counts per corresponding GB cut,
k-means++ n_init10 random_state0 max_iter300 tol1e-4. KM: independent Lloyd fits at these counts.
These comparisons match region count, not GB minimum-size/stop constraints. Record cut nesting.

kNN: for EACH target/view/scale, exactly match that GB scope's number of OTHER TRAINING nodes,
using closest observed training nodes in normalized representation. No unlabeled node supplies a vote.

Exclude the current node from every scope. Distributions are empirical, without parent smoothing.
Parent smoothing is deliberately deferred: it would increase cross-scale agreement by construction.
No global-prior fallback counts as evidence. Scopes with fewer than two other training nodes are inactive.
Deduplicate identical voter sets for each target; different overlapping sets are still correlated.
The union size is called unique support, NEVER number of independent votes.

## Fixed statistics and ranking rules

For active distinct scopes, mean vote p_bar uses equal weights. S = 1 - mean(JS(p_scope,p_bar))/log(2),
where JS is the two-distribution Jensen-Shannon divergence with natural logs. S in [0,1].
Margin = largest minus second largest component of p_bar. U = number of unique voters in active scopes.
Support factor = U/(U+2). No fitting on true correction quality.

For every grouping's full six-scope ensemble, define ONE candidate set: at least one active scope,
unique leading class of p_bar, and leading class != observed label. Proposed class is fixed for all
ranking rules on that ensemble:
- Margin: margin alone.
- NoStability: margin * support factor.
- Full: S * margin * support factor.
- StabilityOnly: S alone (secondary analysis).

Separate descriptive ablations: canonical fine scope only; canonical three-scale ensemble;
two augmented fine scopes. These may change candidate classes; their gains do not isolate ranking.
Within fixed-margin quartiles (defined from unlabeled margin values), report correctness vs stability.
These are descriptive strata, not adjustable selection thresholds or causal evidence.

## Outcomes and gates

Coverage curve retains 10/20/40/60/100% of each fixed candidate set. Primary fraction: 20% candidates.
Also report actual fraction of all training nodes corrected, since candidate sets differ across methods.
If a score has a tie at the boundary, use fractional expected selection, independent of clean labels.

Correction precision: correct proposed replacements / selected corrections.
Correction recall: originally wrong labels fixed / all originally wrong training labels.
Clean corruption rate: originally correct labels changed to wrong / all originally correct training labels.
Net label accuracy change: (wrong labels fixed - clean labels harmed) / all training labels.
Report ranking AUROC for whether a candidate replacement is correct, number of scopes, supports,
ARI and same-fine-scope voter Jaccard across views. Stability is not a calibrated probability.

Each dataset/noise unit averages its three paired seeds; overall macro averages four units.
Mean/std use three seeds per unit. No independent-node significance claims; datasets are previously used.

G1 stability mechanism: Full minus NoStability precision at primary coverage >= .03 macro,
positive on >=3/4 dataset/noise units, and macro clean-corruption rate does not increase.
These use EXACT same candidates and proposed labels, so averaging benefits cancel.

G2 GB-specific evidence: among all training nodes, fixed correction coverage .05 (5%) for each method,
Full GB precision exceeds Full BKM and Full kNN by >= .02 each; each difference positive on >=3/4 units.
If any method has insufficient candidates in a cell, record missing coverage and do not silently
lower the coverage or claim G2 passed. KM comparison reported as an additional strong control.

- G1 fails: stop this frozen multiscale/perturbation-stability selective-correction implementation.
  Do not adjust rates, kappa, scales, clipping, thresholds, or weights on these outcomes.
- G1 passes/G2 fails: only generic neighborhood stability signal; no GB-specific upgrade claim.
- G1+G2 pass: design external confirmation and an observed-label-only training rule; no automatic
  classifier training from this screen's clean-label evaluation.

Thresholds are investment decisions, not significance/equivalence tests. All negative results retained.
