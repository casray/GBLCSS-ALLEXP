# 粒球与图对比学习结合实验总结报告

## 一、整体背景

本轮实验主要研究：粒球计算能不能帮助图对比学习。

图对比学习可以简单理解为：对同一张图做两次不同扰动，得到两个“视图”，然后让同一个节点在两个视图中的表示更接近，让不同节点的表示更区分。这里面最关键的部分有三类：

1. 怎么生成两个视图，也就是怎么扰动图的边和特征；
2. 怎么定义正样本和负样本，也就是哪些节点应该拉近、哪些节点应该推远；
3. 怎么设计额外约束，让模型学到更稳定的局部结构。

粒球的直觉是：先把图中的节点按局部相似性分成一些“小组”，再把这些小组关系作为结构先验加入对比学习。我们尝试过多种结合方式，但总体结果说明：粒球不能直接当成可靠的语义标签，也不适合强行主导对比学习流程；它更适合作为温和的辅助先验或诊断工具。

## 二、实验方向总结

### 实验1：用粒球控制图对比学习的视图生成

**粒球担任的角色：**  
粒球被用来决定哪些边应该保留、哪些边可以扰动。例如，同一个粒球内部的边可能被认为更重要，跨粒球的边可能被认为更容易被删除。

**修改的是对比学习中的哪一部分：**  
修改的是“视图生成”部分，也就是原本 GRACE 中随机删边、随机遮蔽特征的增强过程。

**结果怎么样：**  
这个方向在多个项目中反复失败。粒球确实能被构造出来，也能参与视图扰动，但在正式训练和长轮次训练中，结果多次低于原始 GRACE。

**为什么失败：**  
图对比学习中的随机增强并不是随便加噪声，它本身维持了一种比较有效的训练分布。粒球强行控制视图后，虽然看起来更“有结构”，但可能破坏了原来的增强多样性，使两个视图之间的差异变得不合适，最后影响表示学习。

**经验：**  
粒球不适合直接当视图生成器。以后除非有非常明确的噪声图场景和视图诊断证据，否则不应继续在这个方向上调 schedule、freeze、anchor/explore 等参数。

### 实验2：用粒球修正对比学习中的负样本

**粒球担任的角色：**  
粒球用来判断一些“表面上是负样本、实际上可能相似”的节点。比如两个节点在同一个粒球里，就可能不应该被模型强行推远。

**修改的是对比学习中的哪一部分：**  
修改的是对比损失中的负样本部分。具体做法是：不删除负样本，而是对少量同球、高相似的负样本降低权重。

**结果怎么样：**  
这是目前最稳的粒球主线。GB-FN-GRACE v2 topk-soft 在 Cora、CiteSeer 上有很小的正向结果，PubMed 基本持平。但是提升非常小，例如 Cora 约 +0.0014，CiteSeer 约 +0.0010，而且和 baseline 的标准差重叠。

**为什么没有形成强结果：**  
第一，真正被修正的负样本比例很小，对整体训练影响有限。第二，不使用粒球、只用相似度选 top-k 的 no-ball topk 对照也能得到非常接近的结果，说明粒球本身提供的额外信息还不够明确。

**经验：**  
这个方向不是失败透顶，但也不能说已经成功。它可以保留为“低侵入的结构先验”，但不能写成显著优于 GRACE。下一步重点不是继续发明新公式，而是证明粒球相对 no-ball topk 是否真的有独立贡献。

### 实验3：把同粒球节点直接当正样本或原型约束

**粒球担任的角色：**  
粒球被当成语义分组。同一个粒球里的节点被认为更相似，因此尝试把它们直接拉近，或者让节点靠近粒球中心、原型。

**修改的是对比学习中的哪一部分：**  
修改的是正样本构造和额外正则项。也就是在原本“同一个节点的两个增强视图互为正样本”之外，额外加入“同粒球节点也应该接近”的约束。

**结果怎么样：**  
整体结果不理想。prototype、same-ball positive、direct relation regularization 等方向没有稳定提升，部分实验中还降低了 Cora 的测试结果。GB-PCL 在一个项目里有 Cora 单 seed 的正结果，但证据太少，不能推广。

**为什么失败：**  
同一个粒球不等于同一个语义类别。粒球只是局部结构或特征相似的分组，其中可能包含很多不应该被强行拉近的节点。直接把同球关系当成正样本，会干扰对比学习原本的区分能力。

**经验：**  
不能把 same-ball membership 当成硬语义标签。以后如果还想用同球关系，只能用 soft、top-k、confidence-gated 的形式，而且必须有 no-ball、random 或 shuffled 对照。

### 实验4：用粒球做边去噪或边权重调整

**粒球担任的角色：**  
粒球被用来判断图中的边是否可靠。例如，同球边可能被认为更可信，跨球边可能被认为更像噪声边。

**修改的是对比学习中的哪一部分：**  
修改的是图结构输入或训练时的边权重。也就是不只是改 loss，而是直接改变图中边对模型的影响。

**结果怎么样：**  
纯粒球 membership 的边去噪效果较弱。实验中能看到跨球边有一点噪声富集倾向，但 precision 和 recall 不够强，也容易误伤干净图中的有用边。相比之下，直接用节点特征相似度做 x-space percentile edge denoise，在噪声图上效果更强，但这不是粒球贡献。

**为什么失败：**  
边是否是噪声，不能只靠“同球/跨球”判断。跨球边中也可能有重要连接，同球边也可能不是可靠边。粒球 membership 太粗，作为边规则会误伤正常结构。

**经验：**  
粒球不适合作为边去噪的硬规则。后续如果继续探索，只能把粒球作为 edge scorer 的一个辅助特征，并且必须证明它比 x-space 相似度单独使用有额外增益。

### 实验5：把粒球视图迁移到 BGRL / GBT 等其他自监督目标

**粒球担任的角色：**  
粒球仍然主要参与视图生成，然后把这些粒球视图接入 BGRL、GBT 等非 InfoNCE 的自监督目标。

**修改的是对比学习中的哪一部分：**  
修改的是训练目标函数。也就是尝试不再使用原 GRACE 的对比损失，而改用其他自监督学习目标来吸收粒球视图。

**结果怎么样：**  
这个方向也失败。GB-BGRL 明显不稳定，GB-GBT 虽然相对稳定，但仍低于 GRACE。

**为什么失败：**  
问题不只是 InfoNCE 损失本身，而是粒球视图和训练目标之间存在整体错配。换一个目标函数并没有解决粒球视图破坏训练分布的问题，反而引入了更多变量。

**经验：**  
不要用“换目标函数”来修复粒球视图生成失败。除非先证明没有粒球的 BGRL/GBT baseline 本身健康，再证明接入粒球后有稳定增益，否则不应继续投入。

### 实验6：RDCL 局部关系一致性

**粒球担任的角色：**  
粒球或 kmeans 分组被用来构造局部关系约束，让模型在局部小组内部保持一定的一致性。

**修改的是对比学习中的哪一部分：**  
修改的是额外的局部关系正则项。它不是直接改视图，也不是简单增删正负样本，而是在原训练目标之外加入局部关系约束。

**结果怎么样：**  
这是当前比较值得保留的正向信号。PubMed 上 RDCL 有 3-seed 正结果，例如 kmeans 约 +0.0030，gb_v2 约 +0.0025。

**为什么还不能直接说成功：**  
机制对照削弱了“高纯度语义粒球带来收益”的解释。random、shuffle 等控制组在 PubMed 上也能接近主方法，说明收益可能来自“局部关系正则”这种形式，而不一定来自真正语义正确的粒球分组。

**经验：**  
这个方向值得继续，但下一步必须做 fixed partition、size-matched random partition、shuffled partition 等机制隔离。只有真实分组稳定超过这些控制组，才能说粒球分组本身有贡献。

### 实验7：诊断实验

**粒球担任的角色：**  
粒球在这里不是主方法，而是分析工具，用来观察分组质量、候选负样本质量、边可靠性、分组是否塌缩等。

**修改的是对比学习中的哪一部分：**  
不直接修改训练流程，主要用于解释实验结果。

**结果怎么样：**  
诊断实验非常有价值。它帮助发现：高 protected_precision 不一定带来下游提升；ball-topk 不一定优于 no-ball topk；构球数量健康也不代表最终表示更好。

**为什么重要：**  
没有这些诊断，很容易把“粒球能构出来”“候选看起来更纯”“某个 seed 有提升”误写成方法成功。

**经验：**  
后续每个新方向都应该先有诊断指标，再进入正式训练。诊断不能替代下游结果，但可以有效阻止低价值实验继续扩大。

## 三、粒球和对比学习不太能结合的方向

1. **粒球直接控制视图生成。**  
   这条路反复低于 GRACE。原因是对比学习很依赖视图扰动分布，粒球强行控制视图容易破坏原本有效的随机增强。

2. **把同粒球关系当作硬语义标签。**  
   同球节点不一定语义相同。直接做 hard positive、hard negative deletion、prototype pulling 或 full-ball suppression，容易把不该拉近的节点拉近，或者把有效负样本误伤。

3. **用粒球 membership 直接做边去噪规则。**  
   同球/跨球关系太粗，不能可靠判断一条边是不是噪声。纯粒球边去噪容易同时误删噪声边和干净边。

4. **用 BGRL/GBT 等目标函数修复粒球视图失败。**  
   实验说明失败不只是损失函数问题，而是粒球视图和训练过程整体不匹配。

5. **继续堆复杂公式。**  
   GB-FN 的 adaptive、mass-preserve、cross-view 等变体没有超过简单 fixed topk。复杂度增加了，但证据没有增加。

## 四、粒球和对比学习还可以结合的方向

1. **作为低侵入的负样本修正先验。**  
   也就是 GB-FN topk-soft：只对少量高置信候选负样本降低权重，不改变视图、不硬删除样本。这个方向可以保留，但 claim 要弱。

2. **作为局部关系正则的分组来源。**  
   RDCL 的结果说明，局部关系一致性可能有价值。粒球可以作为一种分组方式继续验证，但必须和 fixed/random/shuffled 分组严格对比。

3. **作为诊断工具。**  
   粒球可以帮助分析局部结构、候选负样本、边可靠性和分组稳定性。即使不作为主方法，它也能帮助解释为什么某些方法失败。

4. **作为边风险估计的辅助特征。**  
   在噪声图场景下，粒球不能单独做边去噪规则，但可以尝试作为 edge scorer 的一个弱特征。前提是必须证明加入粒球后比 x-space 相似度单独使用更好。

## 五、后续实验保留的经验和决不能走的弯路

### 必须保留的经验

1. **先做机制诊断，再跑正式训练。**  
   每个新方向至少要有 candidate overlap、no-ball 对照、loss scale、ball size、max group size、assignment change 等诊断之一。

2. **所有 GB-FN 实验必须带 no-ball topk。**  
   如果 no-ball topk 和 GB-topk 接近，就不能说收益来自粒球。

3. **所有分组正则实验必须带 random / shuffled / fixed 控制。**  
   如果随机或打乱分组也能得到类似收益，就不能说是语义粒球贡献。

4. **小于标准差的提升不能当成功。**  
   Cora、CiteSeer 上 0.001 量级的提升，只能说有弱信号，不能写成显著提升。

5. **粒球只能作为弱先验，而不是强标签。**  
   后续所有设计都要避免把 same-ball 当成绝对正确的语义关系。

### 决不能继续走的弯路

1. 不再继续调 GB view generation 的 schedule、freeze、anchor/explore。
2. 不再用 GB-BGRL / GB-GBT 修复视图生成失败。
3. 不再尝试 hard same-ball positive、prototype pulling、整球 suppression、ratio-wide suppression。
4. 不再继续做 GB-FN 的公式购物。
5. 不再把纯 same/cross-ball membership 当边去噪规则。
6. 不再用 Cora single-seed 结果支撑主结论。
7. 不再把 protected_precision、candidate precision、ball activation 直接等同于下游有效。

## 六、建议的下一步最小实验

### 优先实验1：RDCL 的机制隔离

固定现有 RDCL 配置，不调 alpha/tau，只新增 fixed partition、size-matched random partition、shuffled partition 控制。

目标是回答：RDCL 的收益到底来自有意义的分组，还是任何局部小组正则都能带来类似效果。

如果真实分组稳定超过控制组，这条线可以继续推进；如果控制组接近主方法，就必须把 claim 降级为“局部正则形式可能有效”，不能说语义粒球有效。

### 优先实验2：GB-FN 的独立贡献证明

固定 GB-FN v2 topk-soft，不再改公式。补 GRACE、no-ball topk、random topk 对照，并分析 candidate overlap、masked ratio、per-seed paired delta 和 loss contribution。

目标是回答：粒球到底有没有提供 no-ball 相似度之外的独立信息。

如果没有，这个方向只能作为弱 ablation 或 appendix；如果有，再补 PubMed 多 seed。

### 优先实验3：粒球作为 edge scorer 辅助特征

在噪声图场景下比较 GB-only、x-space-only、x-space + GB 三种边风险估计。

目标是回答：粒球能不能在强相似度边去噪方法之外提供额外信息。

如果 x-space + GB 没有超过 x-space-only，就停止粒球边去噪方向。

| 4a | `codex-code_2_无粒球抗噪` | x/z percentile edge denoise、GNNGuard-lite、shuffled-score control | 从 `codex-code_2` 分出，重点验证“不用粒球也能抗噪”。 |
| 4b | `contrast learning` | S2、degree-protect、clean-safe、risk-aware augmentation、CLSA、更多数据集 | 从 `codex-code_2` 继续扩展出的最终综合分支；与 `codex-code_2` 项目文件高度重复，但新增实验最多。 |

## 七、最终结论

目前的实验结论不是“粒球完全不能和图对比学习结合”，而是：

粒球不适合以强方式介入图对比学习，例如直接控制视图、直接定义正样本、硬删除负样本、直接改边权或替换训练目标。这些方向已经多次表现出机制不匹配。

更可行的结合方式是弱方式：把粒球作为低侵入的候选范围、局部关系正则的分组来源、或者机制诊断工具。下一步实验应该围绕“粒球是否提供了普通相似度、随机分组、打乱分组之外的独立信息”来设计，而不是继续发明更复杂的公式。

因此，后续最优先保留 RDCL 机制隔离和 GB-FN 独立贡献证明；其他强粒球路线应停止继续投入。
