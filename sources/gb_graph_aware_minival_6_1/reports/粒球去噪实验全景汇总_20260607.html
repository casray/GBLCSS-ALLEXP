一句话主线（读这一段就够）： 课题方向从「图感知粒球」转向「对比表示上的 reliable 粒球去噪」。随后用一连串严格的预注册实验逐一证明： 在「保持 GRACE 表示稳定」的前提下，粒球结构相对最朴素的 kNN 共识没有任何可证的独立增量—— 图感知球、reliable 互惠-kNN 球、density 球、最小弱 encoder-coupling 全部无首信号。 唯一稳健的是「局部一致性可靠性信号 + commit-style 样本选择」，但这与「球」本身无关。 保留粒球作主角只剩「球损失主导的强耦合训练」（CGBC/GBmooer 路线，工程大、与项目 frozen 稳定经验相悖）。

§12.1
DCGB 诊断		 导师 idea：图感知粒球（特征+拓扑）是否比纯特征球更好？验证拓扑增量。 Cora/CiteSeer × noise 0.2/0.4 × 5 seed；比较 dcgb（特征+拓扑）vs dcgb_emb_only（纯特征互惠-kNN）的球质量。 拓扑增量 dcgb − emb_only：purity ±0.002、AUROC ±0.001（全 8 条件 ≈0）。 图感知球不作主创新

§12.1
raw-vs-GRACE		 互惠-kNN 构球本身是不是稳定正信号（与表示无关）？ raw 特征 vs GRACE 上对比 ordinary GB vs 互惠-kNN 球的 purity/AUROC。 raw 上 ordinary GB purity 崩塌（Cora 0.303 / CiteSeer 0.210）；互惠-kNN 恢复到 0.78–0.84；GRACE 上 dcgb purity 0.89 / AUROC 0.79。 互惠-kNN 构球=稳定正信号
可靠性来自构球方式，与表示空间/拓扑无关。
§12.3-4
S1 (NoisyGL)		 在监督 GCN hidden 上构 reliable 球 + 保守重加权，能否去噪？ NoisyGL GCN 宿主，Cora uniform 0.4 seed3000 单 seed smoke；含 no-ball/random 对照（修了 config 覆盖 bug）。 reliable-GB test 0.705 = GCN 0.705，best_phase=warmup；gated precision 0.50 = 有效 no-ball 0.50。 S1 no-go
工作假设：GCN epoch6 见顶记忆噪声→瓶颈在监督表示，转 label-free 对比表示。
§12.4
S2a Phase1 + headroom		 把同一套 reliable 球搬到 frozen GRACE + 软目标/重加权，能否涨点？先测有没有油水。 Cora symm 0.4 seed0；ce/gb/dcgb_emb_only/qsafe/topk/shuffled；clean-oracle 测 headroom。 headroom = oracle 0.8221 − noisy-CE 0.7878 = 3.43pp（有油水）。但 dcgb 0.7941 = shuffled 0.7941，< gb 0.7962；NCR 多为 0。 软目标链路未过
有 headroom 但「球→下游」转化失败；soft-target 不提交决策。
§12.5
S2-redesign-v1		 换「提交式」机制：commit-style 样本选择（small-loss × 球可靠性），替换软目标。 seed0；每 epoch 选 top-k 信任节点，固定 schedule；方法+6 对照同 schedule，仅 rel 来源不同。 seed0 上 sel_dcgb 0.779 碾压 no-ball/shuffled/random（0.66–0.68）；但 sel_gb 0.809 > sel_dcgb > gb_soft。 预注册门未过
commit 机制让球信号转化了（机制对）；但 seed0 出现「gb>dcgb」倒挂，记为待验证假设。
§12.6
S3 Phase1		 seed0 的「sel_gb > sel_dcgb」倒挂是真的吗？先多 seed 证伪再投入机制解释。 Cora symm 0.4 × 5 seed；预注册 A/B/C 机械判定。 A（gb>dcgb）1/5、mean −3.00pp；B（gb>gb_soft）2/5；C（dcgb>对照）5/5/5。均值 dcgb 0.8002 > topk 0.7969 > gb 0.7702。 seed0 倒挂被证伪
C 成立
reliable 球才是稳的；commit-selection+球稳健。
§12.7
S3 Q2（主线生死）		 球结构相对纯 kNN 共识到底多提供了什么？（审稿人会问：粒球=kNN consensus 包装？） 复用 5-seed 数据，paired 比较 dcgb vs topk（k 匹配球大小、同覆盖 0.6）。 dcgb−topk test +0.327pp、std 1.03pp、t≈0.71 不显著；sel-precision 0/5 输、noise-recall 0/5 输。 命中降级档
显式建球相对 kNN 共识无可证独立增量。
§12.8
S3 Phase1c（density）		 借 GBmooer：球级密度结构（kNN 共识表达不了）能否拉开 kNN 共识？（先验证角距离=恒等，避免无效实验） 新 density 信号 = density(B)×compactness(i,B)×noisy_consensus(B)；5 seed；配 shuffled/random matched。 density 0.7714 < topk 0.7969 < dcgb 0.8002；density>topk 1/5、mean −2.56pp；sel-prec/recall 全面更差。density 赢自身 shuffled/random（+5.97/+3.02pp）。 预注册否定
球级密度结构被 kNN 共识覆盖且更差；frozen-space「改球」穷尽=没救。
§12.9
S3 Phase2（encoder coupling）		 读 CGBC/GBmooer 原文→根因是「表示为球而生+球反馈进 encoder」。最小弱耦合：让表示被球塑造。 GRACE init 全 encoder 小 lr 微调 L=L_sup+λ_cl·L_GRACE+λ_gb·L_ball（λ 固定不调）；中间诊断早停门：球质量是否变好。 coupled-dcgb purity 0.8856 / AUROC 0.8885 vs frozen 0.8893/0.8920（−0.37/−0.35pp）；coupled = baseline purity ±0.00。log：L_GRACE≈6.84 ≫ intra 0.02/inter 0.2。 早停（球质量未改善）
球损失被对比损失淹没；最小弱耦合无效（不否定强耦合）。

三、贯穿全程的机制结论（为什么粒球在 frozen 表示上不转化）

主题结论证据
表示 vs 球frozen GRACE 不是「为球而生」的表示；球的几何与分类器学的是同一套，信息冗余 → 任何球结构退化成局部 kNN 共识。§12.7 dcgb≈topk；§12.8 density<topk
转化环节瓶颈不在球质量/去噪公式/时机，而在「转化」：软目标不提交决策（NCR≈0），commit-style 选择能转化但转化的是「局部一致性」不是「球」。§12.4 headroom 3.43pp 但 dcgb=shuffled；§12.5 commit 机制生效
group-purity 的误导group 级 clean-purity 分不出 gb 与 dcgb（0.892 vs 0.893），但 node 级 selection precision 区分得出 → 球质量指标会骗人。§12.7
弱耦合不足最小弱耦合中球损失被 L_GRACE 量级淹没（0.02 vs 6.84），球质量零改善；coupled=baseline。§12.9
CGBC/GBmooer 为何有效它们球损失是一等主导损失（CGBC L=L_clustering+L_SCE、GBmooer 超球对比专为球可分），表示被球塑造，代价是放弃 frozen 稳定性、接近从头训。任务也非图节点（合约/文本，i.i.d. 样本）。原文核对 2603.27734v1 / ssrn-6022343

四、全程严守的科研护栏（这也是结论可信的原因）

① clean label 只用于评估/诊断，绝不进构球/可疑度/门控/权重/教师/目标/损失（已单测）。
② 不做 hard same-ball positive、不做 GB view generation、不做 prototype/center pulling。
③ 每个 claim 必须带 no-ball + random/shuffled size-matched 对照，且同覆盖、同 schedule。
④ 不 threshold/formula-shopping（不为过线调 alpha/gate/top_ratio/λ/schedule）。
⑤ 不从单 seed、不从 within-std 判成功；倒挂/涨点先多 seed 证伪再投入机制解释（§12.5→§12.6 即活例）。
⑥ 两条 protocol 不混报：minival（ratio-split / symmetric / seed 0–4）≠ NoisyGL（uniform+pair / seed 3000–3004）。
⑦ 每步先 seed0 冒烟/中间诊断早停，通过才扩 5 seed。

五、当前位置与两条可选方向（待你决策）

方向内容风险 / 评估
方向 1
高风险		 强耦合 / 球损失主导训练：真正复刻 CGBC/GBmooer，让球的 intra/inter/聚类损失成为主导项，允许表示大幅偏离 GRACE。粒球翻身唯一剩下的技术机会。 工程量最大、最不稳；放弃项目最稳的 frozen 基础；图节点同配性可能仍是额外阻力。先验不乐观。需严格预注册 + 硬止损。
方向 2
证据支持		 诚实主线：「局部一致性可靠性信号 + commit-style 选择」为方法主体（Phase1 的 C 满分本身站得住），粒球为一种实现；外加一条「为何 frozen 表示下球结构不转化 / 弱耦合不足 / 需球损失主导」的负结果机制分析。 所有证据支持；对「研究粒球」的课题组而言是诚实且可发表的机制贡献；不是放弃粒球，是把它放到证据支持的位置。

Claude 的诚实建议：倾向方向 2——「frozen + 改球/弱耦合」这条路已被 8–9 个严格实验走到头；方向 1 是孤注一掷。但若导师坚持粒球为头号卖点，方向 1 也可做，会带硬止损。
