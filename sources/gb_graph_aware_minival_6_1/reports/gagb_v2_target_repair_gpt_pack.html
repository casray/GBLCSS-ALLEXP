1. Context And Objective

本项目研究的是图标签噪声任务中的 Graph-aware Granular Ball（GAGB）是否能作为局部可信区域，辅助 frozen GRACE embedding 上的 noisy-label robust node classification。

上一轮 v2 target-only minival 表面结果是 gagb_qb_conflict_gate 的 NCR=0，看起来没有真正纠错。但随后 gated-node diagnostic 发现：

  • conflict gate 明显富集 noisy train nodes；
  • q_mix 在 gated noisy nodes 上大多已经指向 clean label；
  • teacher 在 gated noisy nodes 上有较高 clean accuracy；
  • 真正阻断 NCR 的是旧 target update 中 alpha=0.3 的 convex mixing 过弱，target argmax 仍停在 noisy label。

本轮实验的目标很窄：不改 GRACE、不改 GAGB 构球、不改 teacher，只修 gated nodes 的 target update 形式，验证 pre-alpha correction signal 是否能转化成 post-target correction signal。

2. Prior Experiment Chain

阶段核心发现对本轮的约束

本轮 target update repair只改变 gated nodes 的 target update，观察 NCR/CDR/accuracy。仍然只是 minival；未恢复全部 fair-control suite。

3. Method / Algorithm

3.1 输入与固定组件

  • 输入图：Cora / CiteSeer attributed graph。
  • Embedding：frozen GRACE 表示，不在本轮更新。
  • Grouping：沿用现有 GAGB 构球，不调 lambda_h/lambda_t/tau_add。
  • Teacher：只用 noisy train labels 在 frozen embedding 上训练 linear teacher，输出 all-node teacher_probs。
  • Clean labels：只用于 diagnostics 和 validation/test evaluation，不进入训练目标构造。

3.2 q_mix 构造

对一个 graph-aware ball B：

q_label_B = ball 内 train noisy label distribution
q_pred_B  = ball 内 all-node teacher probability mean
q_mix     = (1 - beta) * q_label_B + beta * q_pred_B
beta      = 0.5

3.3 Conflict gate

对 train node i，只有满足以下条件才改 target：

q_mix[noisy_y_i] <= 0.35
max(q_mix) >= 0.55

直观含义：当前 noisy label 在局部 soft distribution 中支持度很低，同时 q_mix 有较明确 top class。

3.4 本轮 target update variants

方法更新形式目的
gagb_qb_conflict_gate_alpha03旧版本：几何置信度缩放后的 alpha 最大约 0.3。作为 baseline，复现 NCR=0。
alpha06gated nodes 使用固定 alpha=0.6。测试较强 soft mixing 是否足够翻转 target argmax。
alpha07gated nodes 使用固定 alpha=0.7。prompt 中最小 repair 候选。
alpha09gated nodes 使用固定 alpha=0.9。测试接近 replace 的强 soft update。
replace_qmixgated nodes 直接使用 q_mix 作为 target。彻底移除 noisy one-hot 的 argmax 阻断。
sharpen_qmix_T05gated nodes 使用 sharpen(q_mix, T=0.5)。测试更尖锐 target 是否更有效。
margin_replace在 conflict gate 基础上，若 argmax(q_mix) != noisy_y_i 且 q_mix[top1] - q_mix[noisy_y_i] >= 0.2，则 replace。希望比直接 replace 更保守，降低 clean damage。
实现细节：最初 smoke run 发现 alpha06/07/09 如果继续被原来的球半径/节点距离几何置信度缩放，实际 alpha_max_actual 仍低于 0.5，无法测试“固定 alpha repair”的假设。因此最终 alpha06/07/09 在 gated nodes 上使用固定 alpha。alpha03 保留旧版本作为对照。

4. Clean-Label And Data-Leakage Boundary

  • Clean labels 没有用于 GAGB 构球。
  • Clean labels 没有用于 teacher training。
  • Clean labels 没有用于 target construction。
  • Clean labels 没有用于 classifier training targets。
  • Clean labels 仅用于 validation/test evaluation 和 diagnostics，如 NCR、CDR、gated noisy ratio、qmix argmax 是否等于 clean label。

7. Metrics And Definitions

  • Test Acc Mean/Std: 5 seeds 的 test accuracy at best validation mean/std。
  • NCR / noise_correction_rate: 在 noisy train nodes 上，target argmax 是否从 noisy label 指向 clean label。
  • CDR / clean_damage_rate: 在 clean train nodes 上，target argmax 是否被错误改离 clean label。
  • Possible Before Alpha: gated noisy nodes 中，q_mix argmax 是否等于 clean label。它表示 pre-alpha correction signal。
  • Lost By Alpha: q_mix 本来能指向 clean label，但最终 target argmax 没有指向 clean label 的比例。
  • Target Argmax Eq Clean Rate: gated noisy nodes 上最终 target argmax 等于 clean label 的比例。
  • Gated Noisy Ratio: gated train nodes 中真实 noisy nodes 的比例。只用于诊断，不能用于训练。

9. Diagnostic Results

机制打通：alpha07/alpha09/replace_qmix/margin_replace 在四个 dataset-noise settings 上都让 NCR 从 0 变成正数，并且 CDR 最大为 0.0255，低于本轮 0.05 硬阈值。
仍需谨慎：accuracy 提升幅度普遍小于或接近 seed std。例如 Cora 0.4 上 replace_qmix 比 gb 低约 0.0013；CiteSeer 0.2 上 replace_qmix 低于 alpha03 约 0.0006。
  • alpha03: NCR 仍为 0，lost-by-alpha 等于 possible correction，复现旧 failure mode。
  • alpha07: 可以部分翻转 target argmax，但在 Cora 0.2 上 accuracy 下降，说明更强纠错不必然提升分类。
  • alpha09: 几乎消除 lost-by-alpha，四个 setting 都超过 alpha03，但个别 setting 的 paired seed 一致性不强。
  • replace_qmix / margin_replace: NCR/CDR 相同；说明 margin threshold=0.2 在当前 gated samples 上几乎没有产生额外过滤，需后续诊断。
  • sharpen_qmix_T05: 机制上纠错，但 downstream accuracy 不支持继续。

10. Supported Conclusions

  1. 上一轮 NCR=0 不能解释为 GAGB 完全没有纠错信号；更准确地说，旧 target update 形式阻断了纠错信号进入 target argmax。
  2. 只修 target update 就能让 post-target NCR 变成正数，且本轮 CDR 低于 0.03。
  3. alpha09、replace_qmix、margin_replace 是本轮最值得保留的候选；sharpen_qmix_T05 应丢弃。
  4. 本轮是 mechanism-positive 和 method-promising，但不是 paper-ready main method。

11. Unsupported Or Still-Hypothetical Claims

不能写成论文结论：“GAGB 已经证明有独立价值”还不成立，因为本轮没有恢复 gagb_shuffled_alpha_matched、kmeans_gagb_matched、topk_gagb_train_matched 等公平控制。
  • 不能说 target repair 已经稳定提升 accuracy；多个 setting 的提升小于 std，paired positive count 也不是全满。
  • 不能说 margin gate 有独立价值；当前 margin_replace 与 replace_qmix 完全一致。
  • 不能据此改 GRACE 预训练、图增强、GAGB 构球或 teacher 架构。
  • 不能重新走 hard same-ball positive / prototype pulling 路线。

12. Missing Information / Residual Risk

  • 缺少 shuffled matched repair controls：需要 gagb_shuffled_alpha09_matched、gagb_shuffled_replace_matched，否则无法判断收益是否来自真实 GAGB grouping。
  • 缺少 kmeans/topk matched repair controls：本轮只能说明 target update repair 有效，不能说明 graph-aware ball grouping 是必要的。
  • 缺少 margin distribution diagnostics：无法解释为什么 margin_replace 与 replace_qmix 完全相同。
  • accuracy gain 小：很多 delta 小于 std，不应过度解释。
  • 数据集范围窄：仅 Cora/CiteSeer，且只有 symmetric noise 0.2/0.4。

实验背景：
我在做 GAGB / GB-GCL noisy-label robust node classification。上一轮 v2 target-only 实验中，gagb_qb_conflict_gate 的 NCR=0。但 gated-node diagnostic 发现，gate 明显富集 noisy nodes，q_mix 和 noisy-label-only teacher 在 gated noisy nodes 上多数指向 clean label。问题主要是 target_i = (1-alpha_i)*one_hot(noisy_y_i) + alpha_i*q_mix 中 alpha=0.3 太弱，使 target argmax 仍停在 noisy label。

本轮目标：
只修 gated nodes 的 target update，不改 GRACE、不改 GAGB 构球、不改 teacher、不改数据划分、不改噪声生成。验证 pre-alpha correction signal 能否变成 post-target NCR，同时观察 clean damage 和 accuracy。

方法：
q_label_B = ball 内 train noisy label distribution。
q_pred_B = ball 内 all-node teacher probability mean。
q_mix = 0.5*q_label_B + 0.5*q_pred_B。
Conflict gate: q_mix[noisy_y_i] <= 0.35 且 max(q_mix) >= 0.55。
Clean labels 只用于 diagnostics/evaluation，不用于构球、teacher、target construction、classifier training。

Variants：
- alpha03: 旧版本，作为 baseline，几何置信度缩放后的 alpha 最大约 0.3。
- alpha06/alpha07/alpha09: gated nodes 使用固定 alpha=0.6/0.7/0.9。
- replace_qmix: gated nodes 直接用 q_mix 作为 target。
- sharpen_qmix_T05: gated nodes 用 sharpen(q_mix, T=0.5)。
- margin_replace: 在 conflict gate 基础上，若 argmax(q_mix) != noisy_y_i 且 q_mix[top1]-q_mix[noisy_y_i] >= 0.2，则 replace。

Noise: symmetric 0.2, 0.4。
Seeds: 0,1,2,3,4。

指标：
NCR = noisy train nodes 上 target argmax 是否从 noisy label 指向 clean label。
