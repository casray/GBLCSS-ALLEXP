GAGB v2 Gated Diagnostic Review Pack

给 GPT / 同行审查用：完整串联 v1 失败、v2 target-only 设计、gated diagnostic 结果、代码边界和下一步判断。

核心结论： gagb_qb_conflict_gate 的 NCR 为 0 不是因为 gate 没选中 noisy nodes， 也不是因为 q_mix 没有纠错方向，更不是 NCR 统计不一致。 诊断显示 gate 明显富集 noisy nodes，q_mix 和 teacher 多数能指向 clean label； 失败主因是 alpha=0.3 的 convex mixing 太弱，混合后 target argmax 仍停留在 noisy label。

1. 审查前必须知道的背景

本项目研究 Granular Ball Computing 与节点级 Graph Contrastive Learning 的结合。 当前任务族是 带噪标签属性图节点分类，实验在 frozen GRACE embedding 上进行。

已有跨方向复盘显示：GB 直接做 view generation、hard same-ball positive、prototype pulling、 broad negative filtering 等方向反复不稳。因此本轮没有改 GRACE、不改视图增强、不接入 RTGNN/NoisyGL， 只研究 GAGB 在 noisy-label target construction 中是否有价值。

3. v2 Target-Only 算法

Input:
  frozen GRACE embedding H
  GAGB grouping B
  noisy train labels y_noisy
  train / val / test masks

Teacher:
  Train LinearClassifier(H -> class) only on noisy train labels.
  No clean labels, val labels, or test labels enter teacher training.
  Output teacher_probs for all nodes.

For each GAGB ball B:
  q_label_B = noisy label distribution among train nodes in B
  q_pred_B  = mean teacher_probs among all nodes in B

gagb_qb_pred_mix:
  q_B = (1 - beta) * q_label_B + beta * q_pred_B

gagb_qb_teacher_prior:
  q_B = (count_label_B + gamma * q_pred_B) / (n_train_B + gamma)

gagb_qb_conflict_gate:
  q_mix = (1 - beta) * q_label_B + beta * q_pred_B
  gate node i only if:
    q_mix[noisy_y_i] <= 0.35
    max(q_mix) >= 0.55

Target update:
  target_i = (1 - alpha_i) * one_hot(noisy_y_i) + alpha_i * q_mix
  if gate rejects i:
    target_i = one_hot(noisy_y_i)

6. Minimal Diagnostic Patch 计划

目标是解释 gagb_qb_conflict_gate 的 NCR 为什么仍为 0。约束如下：

  • 不修改 GAGB 构球算法。
  • 不修改 GRACE embedding。
  • 不加入 prediction consistency 或 Q(B)。
  • 不接入 RTGNN / NoisyGL。
  • 不调参，不扩数据集。
  • clean labels 只用于 diagnostics。

新增诊断回答四个可能原因：

  1. A. gate 选中的大多是 clean nodes。
  2. B. gate 选中了 noisy nodes，但 q_mix 不指向 clean label。
  3. C. q_mix 指向 clean label，但 alpha 混合后 target argmax 没改变。
  4. D. target argmax 已经改对，但 NCR 实现没有反映。

7. Diagnostic 算法

For each dataset, noise_rate, seed:
  1. Load frozen embedding artifact H.pt.
  2. Rebuild the same GAGB grouping with v2 parameters.
  3. Recreate noisy labels for the same split/noise seed.
  4. Train the same noisy-label-only teacher.
  5. Recompute q_mix and the conflict gate mask.
  6. Recompute target_i after alpha mixing.
  7. Use clean labels only to diagnose:
       - whether gated nodes are actually noisy
       - whether q_mix argmax equals clean label
       - whether target argmax changes after alpha
       - whether NCR computation agrees with target argmax
       - whether gated balls are high-purity
  8. Write per-seed CSV, aggregate summary CSV, and markdown report.

9. 关键解释

当前 gate 其实选得很准：它明显富集 noisy nodes，并且这些节点所在的 ball clean purity 较高。 teacher 也不是完全复现 noisy labels；在 gated noisy nodes 上，它多数能预测 clean label。

真正的问题出在 target update 的几何上。即使 q_mix 的 argmax 是 clean label， 当前 target 仍然是： 

target_i = (1 - alpha_i) * one_hot(noisy_y_i) + alpha_i * q_mix

当 alpha_i <= 0.3 时，noisy one-hot 仍保留至少 0.7 的质量。 除非 q_mix 对 clean label 的置信度极端高，否则 target argmax 很难从 noisy label 翻到 clean label。 因此 NCR 为 0 是符合公式预期的，不是 gate 或 teacher 没有信号。

10. 容易误读的地方

  • 不能说“GAGB 没有纠错信号”。诊断显示 q_mix 在 gated noisy nodes 上经常指向 clean label。
  • 不能说“teacher 没有用”。teacher 在 gated noisy nodes 上的 clean accuracy 很高。
  • 不能说“gate 选错了”。gate 对 noisy nodes 有明显 lift。
  • 不能说“NCR 指标坏了”。重算 NCR 与当前报告一致。
  • 也不能直接说“只要调大 alpha 就成功”。这需要下一轮实验验证 accuracy/CDR 是否仍可控。
