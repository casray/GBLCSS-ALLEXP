1. Context And Objective

本实验属于 GAGB / GB-GCL 研究线：在 frozen GRACE 图对比表示空间中构造 Graph-aware Granular Balls，并把粒球作为带噪标签节点分类中的保守 soft-label generator。

本轮 v2.1 的核心问题不是再设计新公式，而是做公平控制：上一轮 v2 target repair 发现 alpha09 与 replace_qmix 可以产生正的 noise correction rate，但还不能判断收益来自 GAGB grouping，还是来自任意局部扰动、kmeans、topk、khop-only 或随机分组。

2. Prior Experiment Chain

  • v1 GAGB 使用 graph-aware grouping + local soft label，但常出现 NCR=0 或精度收益不稳定。
  • v2 target-only repair 引入 noisy-train teacher 与 conflict gate，发现 alpha09 / replace_qmix 有机制信号。
  • v2.1 的目标是补齐 fair controls，不改 GRACE、不改构球、不做 view generation。

3. Method / Algorithm

Graph-aware Ball Construction

  • 输入：normalized embedding H 与 edge_index。
  • 中心选择：未分配节点中 degree 最大者，随机数只用于 tie-break。
  • 候选集合：默认 candidate_scope=khop，max_hops=2。
  • membership score: 0.7 * cosine(h_i, h_c) + 0.3 * (1 / hop_distance)。
  • 阈值：tau_add=0.55；min_ball_size=5；max_ball_size=128。

Teacher-Aware Conflict-Gated Target Repair

For each ball B:
  q_label_B = noisy label distribution over train nodes in B
  q_pred_B  = mean teacher probability over all nodes in B
  q_mix     = 0.5 * q_label_B + 0.5 * q_pred_B

For each train node i in B:
  gate_i = (q_mix[noisy_y_i] <= 0.35) and (max(q_mix) >= 0.55)

alpha09:
  if gate_i: target_i = 0.1 * one_hot(noisy_y_i) + 0.9 * q_mix

replace_qmix:
  if gate_i: target_i = q_mix

本轮不修改 GRACE pretraining、不修改 graph augmentations、不做 prototype pulling，不把 same-ball membership 当 hard positive label。

4. Clean-Label And Data-Leakage Boundary

Teacher 只使用 noisy train labels 训练；clean labels 不参与构球、teacher、target 构造或 classifier training。

Clean labels 只用于：最终 validation/test evaluation，以及 NCR、CDR、AUROC 等 diagnostics。也就是说，NCR/CDR 可以用来理解机制，但不能被误解为训练时可用信号。

5. Experimental Protocol

  • Datasets: Cora, CiteSeer
  • Split: ratio_train0p2_val0p1_split0
  • Noise: symmetric label noise, rates 0.2 and 0.4
  • Seeds: 0,1,2,3,4
  • Mode: frozen GRACE embedding
  • Classifier: epochs 200, patience 30
  • Teacher: linear teacher on frozen embedding, noisy train labels only, epochs 100, lr 0.01, weight decay 5e-4, temperature 1.0

6. Baselines And Fair Controls

  • gb: ordinary embedding GB smoothing.
  • gagb: v1 graph-aware GB target smoothing.
  • khop_only: topology-only grouping.
  • alpha03: weak conflict-gated repair baseline.
  • shuffled_*_matched: randomized grouping controls. Important caveat: after repair, these often change almost no nodes, so they are sanity controls but not fully intervention-strength matched.
  • kmeans_gagb_matched_*: kmeans grouping with GAGB-matched group count.
  • topk_gagb_train_matched_*: train-node effective group size matched topk neighborhood control; not a strict partition.
  • khop_only_*: same target repair formula on khop-only topology grouping.

10. Supported Conclusions

  • Target repair 不再是 inert 模块：alpha09 和 replace_qmix 在 4/4 settings 都有 NCR > 0。
  • Clean damage 可控：主方法 CDR 均低于 0.03。
  • replace_qmix 通过 hard gate 中的 alpha03 比较：3/4 settings wins。
  • 修复路由后，主方法 vs shuffled matched 是 3/4 wins，不再是旧汇总中的完全相同结果。

11. Unsupported Or Still-Hypothetical Claims

  • 不能强 claim “GAGB grouping 稳定优于所有公平 matched controls”。
  • Cora 0.4 是失败 setting：主方法输给 alpha03、GB 或 shuffled control。
  • 许多 accuracy gain 小于或接近 std，不能包装成显著提升。
  • shuffled controls 不是完全 intervention-strength matched，因为 target changed count 经常接近 0。

12. Missing Information / Residual Risk

  • 未实现 correction-by-class bias 诊断。
  • 未分析 Cora 0.4 的 gated nodes 是否集中在特定类别或低质量 balls。
  • 未做 threshold sweep，因此 conflict gate 的 0.35/0.55 是否过严尚未确认。
  • topk control 是 neighborhood pseudo-group，不是严格 partition，对照解释需要谨慎。
  • 当前只覆盖 Cora/CiteSeer 和 symmetric noise，尚未覆盖 PubMed/OGBN 或 asymmetric/instance-dependent noise。

【实验背景】
研究方向是 GAGB / GB-GCL：在 frozen GRACE 图对比表示上构造 Graph-aware Granular Balls，用作带噪标签节点分类中的保守 soft-label generator。上一轮 v2 target repair 显示 alpha09 / replace_qmix 可以带来正 NCR，但缺少公平 matched controls。本轮 v2.1 检验这些收益是否真的依赖 GAGB grouping。

【有效性说明】
旧汇总 reports/gagb_v2_1_fair_repair_20260602 不作为结论依据，因为发现 repair controls 被错误路由到 GAGB grouping。修复后新增测试并重跑 20 个 frozen classifier runs，生成有效目录 reports/gagb_v2_1_fair_repair_fixed_20260602。

【方法】
GAGB 构球：输入 normalized embedding H 与 edge_index。中心为未分配节点中 degree 最高者；候选节点默认为 max_hops=2 的 k-hop 节点；membership score = 0.7*cosine_similarity + 0.3*(1/hop_distance)，tau_add=0.55，min_ball_size=5，max_ball_size=128。v2.1 不改 GRACE、不改构球、不做 view generation。

Target repair：每个球 B 内 q_label_B 来自球内 train noisy labels；q_pred_B 来自 noisy-train linear teacher 在球内 all nodes 的预测均值；q_mix = 0.5*q_label_B + 0.5*q_pred_B。Conflict gate 条件是 q_mix[noisy_y_i] <= 0.35 且 max(q_mix) >= 0.55。alpha09 用 fixed alpha=0.9 混合 noisy one-hot 与 q_mix；replace_qmix 对 gated nodes 直接用 q_mix 替换 target。

【clean-label 边界】
Teacher 只使用 noisy train labels 训练。Clean labels 不用于构造 ball、teacher、target 或训练；只用于 NCR/CDR/AUROC 和最终 test/val 评估诊断。

【协议】
Datasets: Cora, CiteSeer；split=ratio_train0p2_val0p1_split0；noise=symmetric；noise rates=0.2,0.4；seeds=0..4；mode=frozen GRACE embedding；classifier epochs=200；patience=30；base alpha=0.3；teacher epochs=100, lr=0.01, weight_decay=5e-4, temperature=1.0。

【方法与控制组】
主方法：gagb_qb_conflict_gate_alpha09, gagb_qb_conflict_gate_replace_qmix。
对照：gb, gagb, khop_only, alpha03, shuffled matched, kmeans GAGB-matched, topk train-node matched, khop-only repair。topk 是 train-node effective group size matched 的 neighborhood control，不是严格 partition。

【成功标准】
Hard gate: 主方法 NCR>0 且 CDR<0.03；至少 3/4 setting 超过 alpha03；至少 2/4 超过 shuffled matched；至少 2/4 超过 kmeans/topk matched。Strong gate 还要求 3/4 超过 shuffled/kmeans/topk，且至少 2 个 setting 有约 0.3 std 以上 accuracy gain，并且无 correction-by-class bias。但 correction-by-class 尚未实现。
