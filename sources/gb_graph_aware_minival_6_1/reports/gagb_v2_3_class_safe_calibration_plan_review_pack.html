1. Context And Objective

当前项目研究 GAGB / GB-GCL 在带噪标签属性图节点分类中的作用。v2.2 已经把 Cora 0.4 的失败定位到更具体的层面：GAGB target repair 能产生正 NCR，且平均 CDR 很低，但最终 accuracy 尤其 class 1 和 class 6 不稳定或下降。v2.3 的目标不是加新大模块，而是做 class-safe target calibration：让低误伤纠错不要破坏类别边界。

2. Prior Experiment Chain

v1 的 graph-aware GB 没有稳定证明 GAGB-specific value。v2 target-only 不改 GRACE、不改构球，只用 GAGB 生成 teacher-aware ball-level qmix target。v2.1 fair-control 修复后，alpha09 / replace_qmix 在四个 Cora/CiteSeer setting 中都有正 NCR 且 CDR < 0.03，但 Cora 0.4 失败，且 GAGB 相比 khop repair 的优势不足。v2.2 进一步做 correction-by-class 诊断，发现 Cora 0.4 失败更像少量强 target update 引起间接 decision-boundary movement，而不是大量 clean damage。

3. Method / Algorithm

既有 qmix 构造：q_label_B 来自球内 train noisy label distribution；q_pred_B 来自 noisy-train linear teacher 在球内 all-node 概率均值；q_mix = 0.5*q_label_B + 0.5*q_pred_B。conflict gate 触发条件为 q_mix[noisy_y_i] <= 0.35 且 max(q_mix) >= 0.55。alpha 方法用 target=(1-alpha)*noisy_onehot+alpha*q_mix；replace_qmix 直接用 q_mix。v2.3 只在 gated nodes 的 target update 强度、选择预算和安全条件上做校准，不改 qmix 来源、不改 GAGB grouping。

4. Clean-Label And Data-Leakage Boundary

clean labels 只能用于 diagnostics / evaluation：NCR、CDR、per-class accuracy、confusion matrix、failure report。clean labels 不得进入 grouping、teacher training、target construction、class cap、class-balanced budget、boundary-safe gate、replay sampling 或 classifier training。gagb_replay_same_class_count 因需要 clean class count，不作为 trainable method，只能作为离线诊断设想。
