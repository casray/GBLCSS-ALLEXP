## 0. 方向（已定）与本计划目标

正式主表第一阶段显示：`sel_topk`（邻域一致性 reliability + commit 选择）在 **symmetric** 噪声下稳定显
著优于 co-teaching（Cora +9.05pp、CiteSeer +1.24pp，SIG），但在 **pair（结构化）噪声**下不稳定
（CiteSeer pair co-teaching 反超）。诊断发现根因机制：

> **邻域一致性可靠性信号只在「噪声与局部结构相对独立」时有效；当噪声本身有结构性（pair/asymmetric）
> 时，它会把「局部一致的错误」误判为可信样本。** 证据：pair0.6 下 sel_topk selection precision 跌到随
> 机基准甚至更低（Cora 0.283 < 随机 0.40、CiteSeer noise_excl_recall=0.000）。

**论文转向（已与用户确认）**：从「方法 SOTA」转为 **「邻域一致性去噪的有效性与失效边界」分析论文**。
**核心贡献 = 三件事（完整版）**：
1. **正向**：symmetric 下 local-consistency selection 稳定显著优于 co-teaching / small-loss。
2. **边界+机制**：pair 下失效，且 (a) 用 **label-free 失效预警指标**预测失效（**核心贡献**，因为部署时
   没有 clean label）；(b) 闭合因果链：pair 噪声→邻域出现一致的错误→kNN 共识误判为可信→选错→下游掉。
3. **深层洞察**：commit-style 选择的「选择质量 vs 下游收益」非单调（Cora pair0.6：precision 0.283 <
   随机，但 test 0.2721 > CE 0.2506）——解释为何 commit 选择即便选错仍有正则作用。

工作标题：**On the Validity Boundary of Local-Consistency Reliability for Noisy-Label Node
Classification**（粒球仅作 reliability unit 的一种实现，非主角；`sel_topk` 为主方法，`sel_dcgb` 作 ablation）。

## 2. 必须新建：label-free 失效预警指标（核心贡献）

**动机**：部署时没有 clean label，必须能"不看 clean label 就预测邻域一致性现在靠不靠谱"。

新文件 `src/noisy_label_gb_grace/evaluation/failure_signal.py`，实现至少两个**只用 noisy label +
表示几何**的量（per-setting 标量，越大越"危险/越可能失效"）：

- `neighborhood_majority_self_disagreement(emb, noisy_labels, train_mask, k)`：每个 train 节点，看其
  kNN 训练邻居的 noisy-label 多数票是否 ≠ 自己的 noisy label；返回**全局不一致率**。直觉：symmetric 噪声
  让邻域多数票随机化（不一致率高、且无方向）；pair 噪声让邻域系统性偏向错类（不一致率呈现特定结构）。
- `neighborhood_majority_confidence(emb, noisy_labels, train_mask, k)`：每个 train 节点 kNN 邻域 noisy
  多数票的**占比（confidence）**的均值。直觉：pair 噪声制造"高 confidence 但错"的邻域 → 这个量在 pair
  下偏高且与真实可靠性脱钩。
- （可选第三个）`reliability_margin_collapse`：sel_topk 的 rel 分布的"双峰性/方差"——一致性信号失效时
  rel 区分度塌缩。

**关键**：这些函数签名**不得包含 clean_labels**（单测断言），全部用 noisy label + 表示。
单测 `tests/test_failure_signal.py`：①签名无 clean；②输出标量、范围合理；③在构造的 pair-like 玩具数据上
confidence 高于 symmetric-like 数据（验证它能区分噪声结构）。

**验证目标（论文要回答的）**：跨 6–12 格，**label-free 预警量 vs 真实失效**（=clean-label 的
selection_precision − 随机基准，或 test−CE）是否**强相关**（报 Pearson/Spearman r）。若强相关 → 预警指标
成立，可作核心贡献；若不相关 → 降级为 future work，论文仍靠机制图（§3 诊断2）。

## 8. 护栏（硬约束，违反即作废）

1. clean label 只用于 val/test 评估与 selection_precision/noise-recall/诊断2 的**事后核对**；
   **label-free 预警指标（§2）签名禁止含 clean_labels**（单测强制）。
2. 所有方法同 frozen H、同 keep-ratio 调度、同 epochs/lr/patience；唯一差别是 reliability 来源/选择机制。
3. 不 threshold/formula-shopping：调度/lr/k 一次性固定，不为过判定调参。
4. 判定一律 5-seed paired；paired delta **必报 t 值与 SIG/ns**（生方法主表的教训：wins/mean 掩盖不显著）。
5. 协议分离：minival（ratio-split / 只污染 train）数字绝不与 NoisyGL 数字同表。
6. pair 噪声用标准 pair-flip（c→(c+1)%C，已实现已单测）；新增代码补单测、保持全绿。
7. test 一律 `test_acc_at_best_val`；数字直接来自 CSV，禁止手填/记忆。
8. 不碰 PubMed/NoisyGL；不自行扩超出 §4 的格子。
9. 不再让 sel_dcgb/粒球当主方法（三次实验一致 sel_topk ≥ sel_dcgb）；不再把 pair/高噪声说成"主场"。
