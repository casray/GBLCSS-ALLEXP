## 0. 背景与目标（一段话）

论文主线（已定，方向 3 = 方法 + 机制）：**Local Consistency Reliability Guided Sample Selection for
Noisy-Label Node Classification** —— 在 frozen 自监督图表示（GRACE）上，用 label-free 的**邻域一致性**
（互惠-kNN / kNN 共识）作可靠性信号，驱动 **commit-style（co-teaching 式）样本选择**做标签去噪。粒球仅作
一种 reliability unit，**不作标题主角**。

当前正向证据只赢了自己的破坏性对照（no-ball/shuffled/random，差 8–9pp），但相对 CE/gb_soft 增量小
（sel_dcgb 0.8002 vs CE 0.7935），**且尚未与任何真实噪声学习方法比过**。本计划用两格最便宜的实验排掉致命
风险：**能否打过最接近的真基线 co-teaching（生死格1）+ 在结构化/高噪声主场是否拉开差距（生死格2）**。
通过才铺 3 数据集主表；不过则论文收缩为机制/分析论文。

## 2. 必须新建的代码

### 2A. minival 内的 co-teaching 基线（生死格1的核心对照）

co-teaching = 两个网络，各自用对方挑的 small-loss 样本更新。我们已有的 selection trainer 是单网络
small-loss + reliability。**新增一个双网络 co-teaching 训练器**作为同协议真基线：

- 新文件 `src/noisy_label_gb_grace/evaluation/coteaching.py`，函数
  `train_coteaching(embeddings, clean_labels, noisy_labels, num_classes, train_mask, val_mask,
  test_mask, seed, keep_ratio_final, warmup_epochs, ramp_epochs, epochs, lr, weight_decay, patience,
  device) -> dict`（返回与 `train_frozen_classifier_with_selection` 同结构的 dict，至少含
  `test_acc_at_best_val`）。
- 机制：两个相同结构的 `LinearClassifier`（复用 `evaluation/classifier.py:LinearClassifier`），每 epoch
  各算 per-node CE loss → **网络 A 把自己 loss 最小的 top-ρ 训练节点交给网络 B 更新，反之亦然**；ρ 用同一
  个 `keep_ratio_at_epoch` 调度（与 selection **完全相同**的 keep-ratio，保证公平）。模型选择用 clean val。
- **关键公平性**：co-teaching 与所有 sel_* 方法共用同一 keep-ratio 调度、同 epochs/lr/patience、同 frozen
  H。唯一差别是"双网络互选 small-loss" vs "单网络 small-loss × reliability"。
- 单测加进 `tests/test_coteaching.py`（确定性、keep-ratio 生效、clean label 仅用于 val/test eval）。

### 2B. pair（asymmetric）噪声生成（生死格2需要）

`src/noisy_label_gb_grace/noise/label_noise.py` 当前只有 `corrupt_symmetric_labels`。**新增**
`corrupt_pair_labels(labels, train_mask, num_classes, noise_rate, seed)`：pair/asymmetric 噪声 = 每个
类 c 的标签以概率 `noise_rate` 翻到一个**固定的下一类** `(c+1) % num_classes`（标准 pair-flip 定义）。
并在 `load_or_create_noisy_labels` 里把 `noise_type` 分派到 symmetric / pair（缓存路径已含 noise_type，
天然分开，不会串）。加单测：pair 噪声只改 train、按 c→c+1 翻、噪声率近似正确。

## 5. 预注册 gate（机械判定，三格统一）

对每个生死格，按 5-seed 结果机械计算（**delta 用 paired per-seed**）：

- **Gate A（打过真基线）**：`sel_topk` 或 `sel_dcgb` 至少一个 ≥4/5 seeds 超过 `coteaching`，且该方法的
  **mean test delta ≥ 0.5pp**。
- **Gate B（结构信号真实）**：`sel_topk`/`sel_dcgb` ≥4/5 seeds 超过 `sel_noball`（纯 small-loss）**且**
  ≥4/5 超过 `sel_shuffled` 与 `sel_random`。
- **Gate C（相对 CE 有实质增量）**：`max(sel_topk, sel_dcgb)` 相对 `ce` 的 mean delta：symmetric 格
  **≥1.0pp**；pair/高噪声格 **≥1.5pp**。

**判定规则**：
- 两格都满足 **A 且 B**（C 尽量满足）→ **方法论文可行**，进入 §6 主表。
- 任一格 **Gate A 不过** → 方法打不过 co-teaching → **论文收缩为机制/分析论文**（用现有 §12.4–§12.9
  + 这两格作支撑），不铺大表。
- A 过但 C 不过 → 方法稳健但增量小 → 论文 claim 改为"label-free / 即插即用 / 稳定"而非"SOTA 大涨"，
  并优先把主场放到 pair/高噪声。

## 8. 护栏（硬约束，违反即作废）

1. clean label 只用于 val/test 评估与 selection_precision/noise-recall 诊断，**绝不**进构球/可靠性/选择/
   co-teaching 的样本挑选/损失/目标。
2. co-teaching、所有 sel_*、CE 必须**同 frozen H、同 keep-ratio 调度、同 epochs/lr/patience**；唯一差别是
   可靠性信号来源 / 选择机制。否则不公平、作废。
3. 不 threshold/formula-shopping：warmup/ramp/ρ/lr 一次性固定，**不为过 gate 调参**。
4. 不从单 seed、不从 within-std 判成功；gate 一律 5-seed paired 机械判定。
5. 两条协议严格分离：minival（ratio-split / 自有 noisy 协议）的数字**绝不**与 NoisyGL co-teaching 数字
   同表。本计划 co-teaching 必须 minival 内自实现。
6. pair 噪声用标准 pair-flip（c→(c+1)%C），实现后必须单测核对，不能近似糊弄。
7. 报告里 test 一律 `test_acc_at_best_val`；所有数字直接来自 CSV，禁止记忆/手填。
