第一阶段实验设计 — 图级 GB 去噪可行性 Gate

创建日期：2026-06-08。作者：Claude。配合 00_graph_level_noisy_gbcl_handoff.html 阅读。

本阶段唯一目标：在图级 i.i.d. embedding 空间里，GB denoising 是否能稳定超过 kNN/kmeans denoising？
不是完整论文方法，不做 encoder coupling，不做 pair noise，不扩数据集。

0. 总体思路

本阶段采用 两步解耦 设计：

  1. Step A — 表示学习（一次性，不针对噪声调）：用 GIN encoder + GraphCL 风格的对比学习，在 不看标签 的情况下训练 graph-level encoder，得到每个图的 embedding 向量。L2 归一化后保存。
  2. Step B — 噪声鲁棒分类（本阶段核心比较）：在 frozen graph embedding 上注入标签噪声，用不同去噪策略（GB / kNN / kmeans / shuffled / random / CE / robust CE / clean oracle）训练线性分类器，比较 test accuracy。

两步解耦的好处：(1) 表示学习不受噪声影响，各方法严格同表示同 split 同噪声；(2) 快速迭代去噪策略，不用每次重训 encoder。

为什么先 frozen：旧实验教训表明，必须先确认 GB 在 embedding 空间里有没有 kNN 之外的独立信号。如果 frozen 下 GB 就输给 kNN，说明球的结构信息在这个空间里已被覆盖，再做 coupling 也救不了。反之，frozen 下 GB 赢 kNN，才有必要进入第二阶段做 coupling 放大优势。

Split 协议

  • 按 8:1:1（train:val:test）随机 stratified split。
  • 每个 seed 对应一个固定 split + 固定噪声实例 + 固定分类器初始化（三者由同一 seed 派生，保证可复现）。
  • 噪声只注入 train split 的标签；val/test 标签保持 clean。
  • Split 和噪声标签缓存到磁盘（路径含 dataset/seed/noise_type/noise_rate），避免重复生成。

2. Step A — 图对比表示学习

Encoder

  • GIN（Graph Isomorphism Network），5 层，hidden dim 128，global mean pooling → graph embedding dim 128。
  • 标准 PyG 实现（torch_geometric.nn.GINConv + global_mean_pool）。

对比学习

  • 采用 GraphCL 风格：对每个图生成两个增强视图（augmentation pair），用 NT-Xent（InfoNCE）loss 训练。
  • 增强方式（从 GraphCL 论文的四种中选两种组合）：
    • Node dropping（随机丢弃 20% 节点）
    • Edge perturbation（随机增删 20% 边）
  • Projection head：2 层 MLP（128 → 128 → 128），仅用于对比 loss，eval 时丢弃。
  • 训练 100 epochs，Adam lr=0.001，batch_size=128，temperature τ=0.2。
  • 完全无标签——对比学习阶段不看任何标签（clean 或 noisy 都不看）。

Embedding 提取与保存

  • 训练完成后，用 encoder（不含 projection head）对所有图提取 embedding。
  • L2 归一化后保存为 checkpoints/embeddings/{dataset}/pretrain{seed}/H.pt。
  • 同时保存 labels、split masks、num_classes。
  • 每个 seed 独立训练一个 encoder（因为 split 不同，对比学习看到的 train 图不同）。
注意：对比学习的超参（层数、dim、aug 比例、epochs、lr、τ）一次性固定，不为通过 gate 调参。 如果某个数据集上 GraphCL 本身表示质量很差（clean oracle 线性分类器都很低），应先排查表示学习，不归因于去噪方法。

3. Step B — 噪声鲁棒分类（核心比较）

噪声注入

  • 第一阶段只做 symmetric 0.4。
  • 标准 symmetric noise：train 中每个样本以概率 0.4 将标签随机替换为其他类（均匀）。
  • NCI1 是二分类，symmetric 0.4 = 每个 train 样本 40% 概率翻转标签。

分类器

  • 线性分类器（单层 Linear: 128 → num_classes），在 frozen graph embedding 上训练。
  • 优化器 Adam，lr=0.01，weight_decay=5e-4。
  • 训练 200 epochs，patience 30（val accuracy early stopping）。
  • 报告 test_acc_at_best_val。

方法集

方法名去噪策略角色
ce 标准 CE，不做任何去噪 下界基线
sce Symmetric Cross Entropy（SCE = CE + α·RCE） Robust loss 基线
sel_topk kNN 共识 reliability + commit-style sample selection
对每个 train 样本，算其 k 近邻（embedding 空间）中 noisy label 多数票占比作为 reliability， 结合 per-epoch loss 做 trust score = z(-loss) + z(rel)，按 keep-ratio schedule 选可信样本训练。		 kNN 对照（旧实验的赢家）
sel_kmeans kmeans 聚类 consensus reliability + 同上 commit selection
用 kmeans 把 embedding 聚成若干 cluster（cluster 数 = GB 的平均组数，matched）， cluster 内 noisy label 多数票占比作为 reliability。		 kmeans 对照
sel_gb Density-guided granular ball consensus reliability + commit selection
在 L2 归一化的 embedding 空间中，用密度引导的粒球构建（自适应多尺度，不需要预设 k）， 球内 noisy label 多数票占比作为 reliability。		 主方法（待验证）

Selection 机制细节（所有 sel_* 方法共享）

  • Keep-ratio schedule：warmup=20 epochs（保留全部），ramp=20 epochs（线性从 1.0 降到 ρ），然后保持 ρ=1−noise_rate=0.6。
  • Trust score：每 epoch 对 train 样本算 z-score(−loss) + z-score(rel)，取 top keep_ratio 的样本参与 CE loss。
  • 唯一差别是 reliability 的来源（kNN / kmeans / GB / shuffled / random / none）。
  • k 值（kNN 的 k、kmeans 的 cluster 数）与 GB 的平均组数 matched，确保"局部区域"大小一致。
为什么用 commit-style selection 而非 label smoothing？ 旧实验证明 commit-style selection 是唯一能有效转化局部可靠性的机制（soft-target/reweight 全部失败）。 第一阶段沿用已验证的转化机制，只换 reliability 来源（kNN → GB），保持其他变量不变。

4. 粒球构建算法

在 i.i.d. graph embedding 空间中构建粒球，不再依赖图拓扑。

Density-guided Granular Ball（DGB）

  1. 所有 train 样本的 L2-normalized embedding 作为输入点集。
  2. 从全集出发，递归二分：
    • 每个球计算内部 purity（基于 noisy label 的多数票占比）和半径。
    • 若 purity ≥ purity_threshold 且 球内样本数 ≤ max_size，停止分裂。
    • 否则用 2-means 分裂为两个子球。
  3. 最终得到自适应大小的球集合，每个球有 center（成员均值）、成员列表、majority noisy label。

与 kNN / kmeans 的关键区别

  • kNN：以每个样本为中心看 k 个邻居，区域大小固定（k），以查询点为中心。
  • kmeans：全局聚类，cluster 数固定，cluster 大小自适应但无密度约束。
  • GB（粒球）：自适应分裂，区域大小和数量都由数据密度/纯度决定， 密集纯净区域形成大球（统计更稳定），稀疏混杂区域形成小球（避免噪声扩散）。 这是 GB 可能优于 kNN/kmeans 的核心假设——自适应粒度。

超参（一次性固定，不调）

  • purity_threshold = 0.7（noisy-label majority ≥ 70% 停止分裂）
  • min_samples = 5（球内最少 5 个样本，防止过细）
  • max_size = 100（球内最多 100 个样本，防止过粗）
超参一次性固定的原则：purity_threshold / min_samples / max_size 在 seed0 冒烟时确定一次， 之后 5-seed gate 实验不允许再调。如果发现这些超参对结果敏感，本身就是 GB 方法的弱点，需如实记录。

5. 实验矩阵与执行顺序

Phase 0：管线搭建 + MUTAG debug

  1. 搭建项目结构（src/scripts/tests/configs/checkpoints）。
  2. 实现 GIN + GraphCL 对比学习训练脚本。
  3. 实现噪声注入 + split 缓存。
  4. 实现 frozen embedding 上的分类器 + selection 训练。
  5. 实现 GB / kNN / kmeans / shuffled / random 的统一 reliability 接口。
  6. 在 MUTAG 上跑通全管线（不看结果，只看不崩）。
  7. 写单元测试，全绿确认。

Phase 1：NCI1 seed0 冒烟

  • NCI1, symmetric 0.4, seed 0。
  • 先训 GraphCL encoder → 提取 embedding → 跑全部 8 个方法。
  • 记录：各方法 test_acc、selection_precision、noise_exclusion_recall、GB 的平均球数/球大小。
  • 冒烟 gate：
    • clean_oracle 与 ce 的差（headroom）≥ 3pp → 该设置有足够油水。
    • sel_gb 的 selection_precision > random_clean_rate (0.6) → GB 选择有信号。
    • 如果 headroom 太小或 GB precision 不如 random → 先排查表示质量，不盲目跑 5 seed。

Phase 2：NCI1 5-seed 正式 gate

  • NCI1, symmetric 0.4, seeds 0-4。
  • 每 seed 独立训 encoder → 独立提取 embedding → 独立跑全部方法。
  • 按 §6 的预注册判定机械判定。

Phase 3（仅 Phase 2 通过后）：PROTEINS 验证

  • PROTEINS, symmetric 0.4, seeds 0-4，同流程。
  • 验证 NCI1 的结论在不同数据集上是否成立。

6. 预注册 Gate 判定

Gate-1：GB 赢 kNN

sel_gb > sel_topk，5 seeds 中 ≥4 seeds 胜出，mean delta ≥ 0.5pp。
paired t-test 报 t 值 + SIG/ns（|t| > 2.78, df=4 为 SIG）。

Gate-2：GB 赢 kmeans

sel_gb > sel_kmeans，5 seeds 中 ≥4 seeds 胜出。

Gate-3：结构有效（非随机）

sel_gb > sel_shuffled 且 sel_gb > sel_random，各 ≥4/5 seeds。

Gate-4：reliability 有价值

sel_gb > sel_noball（纯 small-loss），≥4/5 seeds。

整体判定

结果行动
Gate 1-4 全过 GB 在图级空间有独立价值，进入第二阶段（encoder coupling + pair noise + 更多数据集）。
Gate 3+4 过但 Gate 1 或 2 不过（GB ≈ kNN/kmeans） GB 有信号但无独立增量。记录为"局部一致性 selection 在图级有效，但 GB 不比 kNN/kmeans 强"。 可考虑：(a) 改 GB 算法（密度加权、多尺度）再试一次；(b) 转向 GB 作为 encoder coupling 的结构先验（第二阶段直接 coupling，跳过 frozen gate）。
Gate 3 或 4 不过（GB 连 shuffled/noball 都赢不了） 图级空间里 GB 也没有信号。及时止损。

7. 每格必报指标

  • 各方法 5-seed mean ± std test accuracy（test_acc_at_best_val）。
  • Paired delta + t 值 + SIG/ns：sel_gb vs sel_topk、sel_gb vs sel_kmeans、sel_gb vs sel_shuffled、sel_gb vs sel_noball、sel_gb vs ce。
  • sel_gb 和 sel_topk 的 selection_precision（选中样本中 clean 比例，用 clean label 事后核算）。
  • sel_gb 和 sel_topk 的 noise_exclusion_recall（noisy 样本被排除的比例）。
  • GB 的 平均球数、平均球大小、最大/最小球（结构诊断）。
  • clean_oracle test（headroom 上限）。

10. 护栏（硬约束）

  1. Clean labels 只用于 val/test 评估 + selection_precision/noise_exclusion 的事后诊断，绝不进入 reliability 计算、样本选择、loss 或 target。
  2. 所有 sel_* 方法同 frozen embedding、同 split、同噪声实例、同 keep-ratio schedule、同 epochs/lr/patience；唯一差别是 reliability 来源。
  3. 不 threshold-shopping：GB 的 purity_threshold/min_samples/max_size、kNN 的 k、selection 的 warmup/ramp/ρ，全部一次性固定，不为过 gate 调参。
  4. 判定一律 5-seed paired；paired delta 必报 t 值与 SIG/ns。
  5. 不把 graph-level 结果与旧 node-level 结果混在同一张表。
  6. 不做 hard same-ball positive、prototype pulling、hard inter-ball negative。
  7. 不从单 seed 得结论（seed0 仅冒烟，确认管线 + headroom）。
  8. test 一律 test_acc_at_best_val；数字来自 CSV，禁止手填。
  9. 如果 GB 输给 kNN/kmeans，如实记录，不通过删对照或换 coverage 来伪造通过。
