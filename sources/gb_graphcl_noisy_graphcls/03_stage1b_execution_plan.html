Stage 1b 执行计划 — Selection 诊断 + 双路线对比冒烟

创建日期：2026-06-09。基于 Stage 1 NCI1 seed0 冒烟结果。

本阶段目标：回答两个硬问题，然后把更好的去噪转化机制和原始 GB/kNN/kmeans 对比重新跑一次冒烟。
Q1：selection 输给 CE，是因为"扔样本太多导致泛化损失 > 纯度收益"吗？
Q2：如果不扔样本（label smoothing），GB 能否提供 kNN/kmeans 之外的增量？

0. Stage 1 冒烟结论回顾

观察数据含义

1. 本阶段设计：两条路线并行冒烟

核心思路：原始 gate 用 commit-style selection 作为去噪转化机制，但诊断表明该机制在 frozen graph embedding + linear classifier 场景下是负效应的。 本阶段不修改原 gate 判定，而是：
  1. 路线 A（soft selection）：保留 selection 框架，但改用 reweighting 而非 hard drop——让不可信样本参与训练但降权，避免样本量损失。
  2. 路线 B（label smoothing）：完全不扔样本，用球/kNN/kmeans 内多数票做 soft target，替换去噪转化机制。
两条路线与原始 CE/SCE/clean_oracle 在同一个脚本中一起跑，保持同 embedding、同 split、同噪声。

为什么不直接调 rho/warmup？

直接在原 gate 框架内调 rho 容易变成 post-hoc threshold shopping，违反预注册精神。我们的做法是： 明确定义两种 新的去噪转化机制（reweight 和 smoothing），作为独立的 ablation 对比， 与原 selection 机制平行报告。如果新机制能让 sel_* 赢 CE，再回到 GB vs kNN/kmeans 的核心问题。

2. 路线 A — Soft Selection（Reweighting）

原理

原 selection 的问题是 hard drop：trust score 低的样本直接排除，导致样本量从 3288 减到 1973。 Reweighting 改为给每个样本一个 [w_min, 1.0] 的权重，不可信样本降权但仍参与训练。

具体实现

# 在 selection.py 中新增 train_with_reweight() 函数

def train_with_reweight(
    embeddings, noisy_labels, clean_labels,
    train_idx, val_idx, test_idx,
    reliability, num_classes, device,
    epochs=200, lr=0.01, wd=5e-4, patience=30,
    warmup=20, ramp=20, w_min=0.1, seed=0, trace=False,
):
    """
    与 train_with_selection 的区别：
    - 不扔样本，所有样本都参与 loss
    - trust_score 同样 = z(-loss) + z(reliability)
    - 权重 = 线性映射到 [w_min, 1.0]：w_i = w_min + (1-w_min) * (trust_i - min) / (max - min)
    - warmup 阶段权重全 1.0
    - ramp 阶段逐渐引入权重：actual_w = 1.0 * (1-progress) + w_i * progress
    - loss = (w * per_sample_loss).sum() / w.sum()
    """

  • 其他分类器超参与原 gate 完全相同

3. 路线 B — Label Smoothing

原理

完全不扔样本，也不改权重。改变的是 training target： 用球/kNN/kmeans 内邻域的 noisy label 投票分布来平滑 one-hot target。

具体实现

# 在 selection.py 中新增 train_with_smoothing() 函数

def train_with_smoothing(
    embeddings, noisy_labels, clean_labels,
    train_idx, val_idx, test_idx,
    soft_targets,  # Tensor[num_train, num_classes], 邻域投票分布
    num_classes, device,
    epochs=200, lr=0.01, wd=5e-4, patience=30,
    warmup=20, ramp=20, seed=0, trace=False,
):
    """
    - warmup 阶段用 hard one-hot noisy label（标准 CE）
    - ramp 阶段逐渐从 one-hot 过渡到 soft_targets：
      target = (1-progress) * one_hot(noisy_label) + progress * soft_targets
    - 之后固定用 soft_targets
    - loss = -sum(target * log_softmax(logits), dim=-1).mean()
    - 不扔样本，全部 train 样本参与
    """

soft_targets 的计算

def compute_soft_targets(method, embeddings, noisy_labels, train_indices, num_classes, **kwargs):

7.1 train_with_reweight()

def train_with_reweight(
    embeddings, noisy_labels, clean_labels,
    train_idx, val_idx, test_idx,
    reliability,   # Tensor[num_train], 与 train_with_selection 同义
    num_classes, device,
    epochs=200, lr=0.01, wd=5e-4, patience=30,
    warmup=20, ramp=20, w_min=0.1, seed=0, trace=False,
):
    """
    训练线性分类器，用 reliability 引导的 sample reweighting（不丢弃样本）。

    核心逻辑（每 epoch）：
      1. logits = Linear(embeddings[train_idx])
      2. per_sample_loss = CE(logits, noisy_labels[train_idx])  # reduction="none"
      3. trust = z_score(-per_sample_loss) + z_score(reliability)
         如果 reliability 全零则 trust = z_score(-per_sample_loss)
      4. w_raw = linearly map trust to [0, 1]: (trust - min) / (max - min)
         w = w_min + (1 - w_min) * w_raw          # 映射到 [w_min, 1.0]
      5. progress = ramp_progress(epoch, warmup, ramp)  # 0.0 → 1.0
         actual_w = (1.0 - progress) * 1.0 + progress * w   # warmup 全 1.0, ramp 后用真实权重
      6. loss = (actual_w * per_sample_loss).sum() / actual_w.sum()
      7. 反向传播 + val early stopping

    返回同 train_with_selection 的 dict 结构，包含 trace（如启用）。
    selection_precision / noise_exclusion_recall 基于低权重（<0.5）样本计算，
    或保持与原格式兼容：
      - selection_precision = 权重加权的 clean 比例
      - noise_exclusion_recall = 权重 < 0.5 的样本中 noisy 样本的比例
    """
    pass

7.2 compute_soft_targets()

def compute_soft_targets(
    method: str,
    embeddings: Tensor,
    noisy_labels: Tensor,
    train_indices: list[int],
    num_classes: int,
    **kwargs,
) -> Tensor:
    """
    计算每个 train 样本的邻域 label 投票分布。
    返回 Tensor[num_train, num_classes]，每行 sum ≈ 1.0。

    method = "topk":
      对每个 train 样本，找 k 近邻（含自身），统计 noisy label 分布。
      kwargs: k=int

    method = "kmeans":
      对 train embedding 做 kmeans(n_clusters)，统计 cluster 内 label 分布。
      kwargs: n_clusters=int

    method = "gb":
      统计同球内 noisy label 分布。
      kwargs: group_ids=Tensor

    method = "shuffled":
      用 shuffled group_ids 统计。
      kwargs: group_ids=Tensor, seed=int

    method = "random":
      用 random group_ids 统计。
      kwargs: group_sizes=list, seed=int

    method = "none":
      返回 one-hot(noisy_labels[train_indices])，即不做平滑。

    注意：计算邻域分布时包含自身。这样单样本球会退化为 one-hot，
    大球会产生更强的平滑效果——这正是 GB 自适应粒度的优势假设。
    """
    pass

7.3 train_with_smoothing()

def train_with_smoothing(
    embeddings, noisy_labels, clean_labels,
    train_idx, val_idx, test_idx,
    soft_targets,  # Tensor[num_train, num_classes], 预计算的邻域分布
    num_classes, device,
    epochs=200, lr=0.01, wd=5e-4, patience=30,
    warmup=20, ramp=20, seed=0, trace=False,
):
    """
    训练线性分类器，用邻域投票分布平滑训练目标（不丢弃样本）。

    核心逻辑（每 epoch）：
      1. logits = Linear(embeddings[train_idx])
      2. one_hot = one_hot(noisy_labels[train_idx], num_classes).float()
      3. progress = ramp_progress(epoch, warmup, ramp)  # 0.0 → 1.0
         target = (1.0 - progress) * one_hot + progress * soft_targets
         target = target / target.sum(dim=-1, keepdim=True)  # 确保归一化
      4. log_prob = log_softmax(logits, dim=-1)
         loss = -(target * log_prob).sum(dim=-1).mean()
      5. 反向传播 + val early stopping

    返回 dict：
      test_acc_at_best_val: float
      selection_precision: 0.0  （不适用，占位）
      noise_exclusion_recall: 0.0  （不适用，占位）
      loss_history: list
      trace: list[dict] 如启用
      stopped_epoch: int 如启用

    trace 中额外记录：
      target_entropy: float  # 当前 epoch 的平均 target 分布熵
    """
    pass

7.4 辅助函数

def _ramp_progress(epoch: int, warmup: int, ramp: int) -> float:
    """
    返回 [0.0, 1.0] 的进度值：
    epoch < warmup: 0.0
    warmup <= epoch < warmup+ramp: (epoch - warmup) / ramp
    epoch >= warmup+ramp: 1.0
    """
    if epoch < warmup:
        return 0.0
    if epoch >= warmup + ramp:
        return 1.0
    return (epoch - warmup) / float(ramp)

10. 冒烟判读逻辑

好的信号（至少满足一条才继续 5-seed gate）：
  • 路线 A 或 B 中至少一个方法稳定赢 CE ≥ 1pp
  • 该路线中 gb 方法 ≥ topk 方法（哪怕微弱，也说明 GB 在新机制下有信号）
  • shuffled/random 比 gb 差（结构有效性）
中等信号（记录但需要思考下一步）：
  • 路线 A 或 B 的最佳方法 ≈ CE（±0.5pp 内）
  • gb ≈ topk ≈ kmeans（GB 无独立增量，但 selection/smoothing 本身不伤害）
坏的信号（及时止损）：
  • 路线 A 和 B 全部输给 CE（说明在 frozen graph embedding + linear classifier 下，任何 local consensus 去噪都没用）
  • sm_noball（= CE）≈ sm_gb（说明邻域 soft target 没有贡献）
