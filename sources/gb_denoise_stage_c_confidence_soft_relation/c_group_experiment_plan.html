C组实验计划：带保护的粒球反向约束 encoder

保存日期：2026-05-21。目标：把 B1/B2 的负结果转化为下一轮更稳的实验设计，验证粒球是否能作为 soft local prior（软局部先验）帮助 encoder（编码器），而不是作为强制压紧目标。

核心判断： B组已经说明，只做粒球 compactness（紧凑性）会让局部球变小，但不稳定提升语义质量。C组不再继续单纯调小 lambda_gb 或刷新间隔，而是测试三个保护机制：稳定 encoder、置信度加权、防塌缩和软关系对齐。

1. 研究问题

当前问题不是“粒球有没有作用”。B1/B2 已经证明粒球 loss（损失）确实能反向影响 encoder，且 compactness 被真实激活。真正的问题是：这种影响如果只表现为球内拉近，就可能牺牲全局语义可分性。

C组要验证的是：

  1. 如果换成更稳定的 encoder baseline（基础模型），原始粒球 compactness 是否还会伤害表示空间？
  2. 如果只让高置信度粒球参与约束，是否能降低错误球 assignment（分配）的伤害？
  3. 如果加 anti-collapse gate（防塌缩门控），是否能避免 effective rank（有效秩）下降？
  4. 如果不用硬拉近，而改成 soft ball relation alignment（软粒球关系对齐），是否更稳？

2. 文献依据和B组教训

来源 关键机制 对C组的启发
CGBC contrastive pretraining（对比预训练）后建球；球内 compactness；球间 separation（分离）；supervised purity（有监督纯度）；SCE（对称交叉熵）抗噪声。 不能只学球内拉近。需要球质量筛选、球间分离或防塌缩保护。监督 purity 不能直接用，要改成 label-free confidence（无标签置信度）。
GBmooer hypersphere contrastive learning（超球面对比学习）；angular distance（角距离）；局部 label smoothing（标签平滑）；球内局部软标签。 粒球更适合做局部软约束，而不是 hard same-ball label（硬同球标签）。球质量、角半径和局部分布可以转成 soft confidence（软置信度）。
B1/B2实验 真实粒球 compactness 可激活，但小权重和动态刷新仍不稳定。 单独优化局部紧凑性不够。下一轮必须同时检查 accuracy（准确率）、effective rank、purity（纯度）和 AD（平均角距离）。

3. C组总设计

C组由 C0-C4 五个方法组成，按从基础对照到更保守约束递进。第一轮建议只跑 Cora 和 CiteSeer，seeds 固定为 0、1、2，不跑 PubMed，避免计算成本过大。

方法 中文含义 验证目的 对应前面方案
C0 稳定 encoder baseline 建立稳定表示空间参照，不加粒球约束。 方案B：全局分离 / 防塌缩基础
C1 稳定 encoder + 原始粒球紧凑约束 检查 B1 失败是否主要来自 raw negative-free encoder。 诊断桥梁
C2 稳定 encoder + 置信度加权紧凑约束 只让可靠粒球参与 compactness，降低错误 assignment 伤害。 方案A
C3 C2 + 防塌缩门控 如果表示空间 rank 或 feature std（特征标准差）下降，就自动减弱粒球损失。 方案A + 方案B
C4 软粒球关系对齐 不用硬拉近节点到球心，而是对齐 weak view（弱视图）和 strong view（强视图）的 node-to-ball distribution（节点到粒球分布）。 方案C

5. C0：稳定 encoder baseline

目的

C0 是所有 C 组方法的 paired baseline（成对基线）。它不加任何粒球训练约束，只训练稳定 encoder。第一轮建议使用 InfoNCE，因为它保留负样本排斥力，有助于全局语义可分性。

配置

method: C0
ssl_objective: infonce
use_bn: false
lambda_gb: 0.0
ball_constraint: none
results_dir: results_stage_c/C0_infonce

必须输出

  • linear_eval_acc：线性分类准确率。
  • effective_rank：有效秩，判断是否坍缩。
  • feature_std_mean：特征标准差均值。
  • mean_radius、mean_average_angular_distance、label_purity_diagnostic：只做后验粒球诊断。

6. C1：稳定 encoder + 原始粒球紧凑约束

目的

C1 用来回答：如果 encoder 本身更稳定，B1 那种原始 compactness 是否还会导致不稳定？这一步不是最终方法，而是定位问题来源。

机制

loss = contrastive_loss + lambda_gb * compactness_loss

其中 compactness_loss 仍然是同一个粒球内部节点到球心的距离损失。球心和 assignment 建议 detach（截断梯度），只让 loss 更新 encoder。

配置

method: C1
ssl_objective: infonce
lambda_gb: 0.0005
ball_constraint: compactness
confidence_weighting: false
anti_collapse_gate: false
results_dir: results_stage_c/C1_infonce_compact

判定

如果 C1 仍然明显低于 C0，说明 compactness 本身风险很高；如果 C1 接近或略高于 C0，说明 B1 的失败和 raw negative-free encoder 关系较大。

7. C2：置信度加权粒球紧凑约束

目的

C2 是从 CGBC 的 supervised purity（有监督纯度）迁移出来的无标签版本。由于不能用标签判断球是否可靠，所以改用 label-free confidence（无标签置信度）。

球置信度定义

每个粒球 GB_k 计算一个置信度 q_k，范围为 0 到 1。第一轮建议使用简单、可解释、可消融的乘法形式：

q_k = q_size(k) * q_ad(k) * q_radius(k) * q_stability(k)
项 含义 第一轮实现
q_size 球大小是否合理 如果 3 <= size <= 256，取 1，否则取 0。
q_ad 球内平均角距离越小越可靠 q_ad = 1 - percentile_rank(AD_k)，AD 越小分数越高。
q_radius 半径越小越可靠 q_radius = 1 - percentile_rank(radius_k)。
q_stability 刷新前后 assignment 越稳定越可靠 第一轮如果没有历史 assignment，先取 1；实现动态刷新后再改成 1 - churn_k。

损失形式

loss_gb = mean_i q_assignment(i) * distance(h_i, center_assignment(i))^2
loss = contrastive_loss + lambda_gb * loss_gb

配置

method: C2
ssl_objective: infonce
lambda_gb: 0.0005
ball_constraint: confidence_weighted_compactness
confidence_keys: [size, ad, radius]
anti_collapse_gate: false
results_dir: results_stage_c/C2_infonce_conf_compact

关键消融

C2 至少要和 C1 比较。如果 C2 优于 C1，说明“不是所有球都同等可信”这个判断成立。如果 C2 仍然低于 C0，说明仅靠置信度加权还不够。

8. C3：C2 + 防塌缩门控

目的

C3 用来解决 B1/B2 中最危险的问题：球内压紧可能让表示空间过度压缩。anti-collapse gate（防塌缩门控）不是为了提高粒球 compactness，而是为了在 rank 或 feature std 变差时自动降低粒球 loss。

门控指标

指标 中文含义 用途
effective_rank_snapshot 训练中定期计算的有效秩快照 如果低于 C0 同 epoch 参考值太多，说明表示可能坍缩。
feature_std_mean 特征标准差均值 如果接近 0，说明样本表示过度相似。
mean_pairwise_cosine 平均两两余弦相似度 如果过高，说明全局表示被压得太紧。

第一轮门控规则

rank_floor = 0.8 * rank_at_warmup
std_floor = 0.8 * feature_std_at_warmup

if effective_rank_current < rank_floor or feature_std_current < std_floor:
    gate = 0.0
else:
    gate = 1.0

loss = contrastive_loss + gate * lambda_gb * confidence_weighted_compactness

第一轮建议先用硬门控，因为容易解释。后续如果有效，再改成连续门控。

配置

method: C3
ssl_objective: infonce
lambda_gb: 0.0005
ball_constraint: confidence_weighted_compactness
anti_collapse_gate: true
rank_floor_ratio: 0.8
std_floor_ratio: 0.8
results_dir: results_stage_c/C3_infonce_conf_gate

9. C4：软粒球关系对齐

目的

C4 是最不同的一组。它不再直接把节点拉向球心，而是让 weak view 上的粒球关系作为 teacher（教师信号），指导 strong view 学到相似的 node-to-ball distribution（节点到粒球分布）。这更接近 GBmooer 的局部软约束思想，也符合 CLSA 的 weak teacher 思路。

机制步骤

  1. 生成 weak view 和 strong view。
  2. 用 weak view 的 encoder output 建粒球，得到球心 C 和置信度 q_k。
  3. 计算 weak view 中每个节点到最近 K 个球心的 soft assignment（软分配）。
  4. 用 stop-gradient（停止梯度）固定 weak view 的分布，作为 teacher。
  5. strong view 计算到同一组球心的 soft assignment，作为 student（学生）。
  6. 最小化两者的 KL divergence（KL散度）或 MSE（均方误差）。

损失形式

P_teacher = stopgrad(softmax(-distance(h_weak, centers) / tau_ball))
P_student = softmax(-distance(h_strong, centers) / tau_ball)

loss_relation = KL(P_teacher || P_student)
loss = contrastive_loss + lambda_rel * confidence_weighted(loss_relation)

配置

method: C4
ssl_objective: infonce
ball_constraint: soft_relation_alignment
lambda_rel: 0.001
topk_centers: 8
tau_ball: 0.2
teacher_view: weak
student_view: strong
use_confidence_weight: true
results_dir: results_stage_c/C4_infonce_soft_relation

为什么 C4 重要

C4 可以避免 C1/C2/C3 的一个根本问题：直接把节点压向球心。它学习的是“这个节点和哪些球更相关”的分布，而不是“这个节点必须属于某一个球”。如果 C4 比 C1/C2 稳，说明粒球更适合作为 soft relation teacher（软关系教师），而不是 compactness loss。

13. 汇总指标

指标 中文解释 判断方式
delta_linear_eval_acc 相对 C0 的线性分类准确率变化 不能明显为负；最好多数 seed 不低于 C0。
delta_effective_rank 有效秩变化 不能同步明显下降。
delta_feature_std_mean 特征标准差变化 防止表示过度压缩。
delta_mean_average_angular_distance 平均角距离变化 可以下降，但不能以 accuracy / rank 下降为代价。
delta_label_purity_diagnostic 标签纯度诊断变化 训练不用标签，评估时检查语义一致性。
confidence_mean 平均粒球置信度 如果过低，说明粒球本身不可靠。
gate_off_epochs 防塌缩门控关闭轮数 如果经常关闭，说明 compactness 仍然危险。
assignment_churn 粒球分配变化率 如果刷新后变化过大，说明动态粒球不稳定。

14. 成功标准和失败标准

成功标准：
  • 至少一个方法在 Cora/CiteSeer 的 6 个 dataset-seed pair 中，4 个或以上不低于 C0。
  • 平均 accuracy 不低于 C0，且 effective rank 没有明显下降。
  • AD/radius 改善时，label purity diagnostic 不下降或小幅上升。
  • C2 明显优于 C1，说明置信度加权有实际价值；或 C4 明显优于 C1，说明软关系对齐更安全。
失败标准：
  • C1-C4 都只有 3/6 或更少 pair 不低于 C0。
  • 方法只降低 AD/radius，但 accuracy、effective rank 或 feature std 同步下降。
  • C2 不优于 C1，说明当前置信度 proxy 没有筛掉错误球。
  • C4 不优于 C1，说明软关系 teacher 也可能被错误粒球污染。
  • C3 经常关闭 gate，说明 compactness 与当前 encoder 仍然严重冲突。

15. 结论边界

结果类型 可以怎么写 不能怎么写
C2 成功 无标签粒球置信度可以降低错误 compactness 的伤害。 粒球 compactness 本身稳定有效。
C3 成功 防塌缩门控有助于平衡局部紧凑和全局可分。 粒球约束不会导致塌缩。
C4 成功 粒球更适合作为 soft relation teacher，而不是 hard pulling target。 same-ball membership 可以直接当正样本。
全部失败 当前粒球反向约束 encoder 的路径仍缺少可靠机制，应转向诊断或噪声场景。 粒球与图对比学习完全不兼容。

16. 最推荐的执行顺序

  1. 先实现 C0 和 C1，确认稳定 encoder 上原始 compactness 是否仍然危险。
  2. 再实现 C2，验证置信度加权是否能改善 C1。
  3. 如果 C2 有改善但仍偶尔崩，加入 C3 防塌缩门控。
  4. 并行或下一轮实现 C4，因为它是不同机制，不是 C2/C3 的简单调参。
  5. 第一轮只跑 Cora/CiteSeer seeds 0/1/2，结果达标后再扩展 PubMed 或 noisy graph。
一句话总结： C组不是继续证明“粒球会让球更紧”，而是验证“在有全局分离和置信度保护的情况下，粒球能不能作为温和的局部结构先验帮助 encoder”。如果 C4 比 C1/C2 更稳，后续论文主线应转向 soft relation teacher，而不是 compactness loss。
