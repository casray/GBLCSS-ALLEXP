二、一页总览：这批文献到底告诉当前项目什么

最重要的正向启发

  • 粒球更适合作为局部统计证据，而不是硬标签。 BNO-GB、MgBIF、MgCNL、G-GBC、GEAF 都在用球内一致性、纯度、权重或局部密度来判断“可信程度”。
  • 先学表征、再构粒球，是主流可迁移模式。 G-GBC 在 CNN feature 上构球，MgCNL/MgBIF 在 latent feature space 上构球，当前项目在 frozen GRACE H 上构球是合理同构。
  • 硬划分是明确风险。 SAGBC 明确指出 hard partition 会制造人工边界；IMVGCR 与 G-GBC 都在用权重、软归属或球级锚点降低单点噪声。
  • 椭球解决的是真实局部结构非球形问题。 孙旭论文的粒椭球模型和 G-GBC 的 Mahalanobis/GMM 都支持“同一球内贡献不等、沿主方向偏移不应被过度惩罚”的直觉。
  • 噪声过滤必须同时看“修正噪声”和“伤害干净样本”。 GEAF 的 NRR/CSIR 思路直接对应当前项目的 NCR/CDR。

最重要的警告

  • 这些文献不能直接证明 SoftDist 在图节点分类上有效。 任务域大多不是 citation/coauthor/amazon 图节点。
  • 很多方法使用标签纯度或全监督信息。 当前 SoftDist 要保持 train noisy label 限定、clean label 只用于诊断，不能引入泄漏。
  • 硬纠正/硬筛样在当前图实验里已经很危险。 GEAF 在 UCI 上强，但当前项目的 Coauthor/PubMed/DBLP/Amazon 下游未稳定支持。
  • GMM/椭球/soft affiliation 会增加复杂度和调参。 若 real-vs-shuffled 不稳，不能 claim 几何贡献。
  • offline target diagnostic 不等于 downstream 提升。 DBLP 和 Amazon 的椭球实验已经说明 target 指标正信号可被训练过程吸收或抵消。

1. BNO-GB：Beneficial Noise Learning for Open Intent Classification via Granular-Ball Representation

Pattern Recognition 2026open intent classificationIND/OOD noisegranular-ball representation

核心问题

开放意图分类不仅要分类已知意图，还要识别未知意图。现实训练数据同时存在两类噪声：IND noise，即已知类样本被错标成另一个已知类；OOD noise，即未知分布样本被错误标为已知类。传统 noisy-label 方法多依赖 small-loss、prediction consistency、prototype distance 等单一标准，缺少局部邻域证据，也很少考虑噪声本身是否能成为有益表征信号。

方法结构

  • 先进行无监督粒球聚类，得到较抗噪的粒球表示。
  • 设计两个互补指标：G-ODT（Granular-ball-level Outlier Distribution Tendency）衡量一个球偏离已知类分布、可能被 OOD 噪声主导的程度；S-ICD（Sample-level Inlier Consistency Degree）衡量样本与其所属球/邻域的一致程度。
  • 用 G-ODT 与 S-ICD 将样本分为 clean、IND noise、OOD noise、uncertain。
  • 对不同噪声类型采用不同学习策略：OOD Dispersion Loss、Prototype Softmax Loss、Prototype Margin Loss 联合优化。

核心创新点

  • 不是“发现噪声就删除”，而是把噪声细分为 IND/OOD/uncertain，并区分使用。
  • 把粒球属性和邻球关系用于噪声类型识别，而不是只看单点损失或单点到 prototype 的距离。
  • 强调 beneficial noise：某些噪声可帮助形成更好的表征边界。

对当前 SoftDist 的启发

  • 当前 SoftDist 只构造一个 ball label distribution，再用 alpha 混合 noisy one-hot；BNO-GB 启发我们：球级统计可以不止用于投票，还可以输出“噪声类型”或“可信结构类型”。
  • 这支持当前项目中 NCR/CDR、s_ball_loo、pseudo NCR/CDR、soft_clean_mass_delta 这类诊断指标，而不是只报准确率。
  • 它也提醒：噪声不一定都应修正，某些不一致可能是边界信息。当前 GEAF 硬纠正失败的原因之一可能就是过度把边界/有益不一致当成错误。

不能直接照搬的地方

  • 任务是文本开放意图分类，不是图节点分类。
  • 它包含 OOD intent 的特定训练和测试设定，当前 NoisyGL uniform noise 不等价。
  • Prototype losses 会显著改变训练目标，不适合直接塞进当前轻量 SoftDist 主线。

2. G-GBC：Gaussian Mixture-based Granular Ball Computing for Robust CNN Classification under Noisy Labels

Knowledge-Based Systems 2026CNNGMMMahalanobispurity/weight

核心问题

深度 CNN 容易记忆错误标签；已有噪声鲁棒方法常依赖噪声率假设、样本预筛、loss 修正或额外训练复杂度，且缺少可解释的训练过程。G-GBC 试图用粒球的多粒度鲁棒性和可解释性来提高 noisy-label 图像分类表现。

方法结构

  • 用 CNN 作为 feature extractor。
  • 在 CNN feature space 中用 Gaussian Mixture Model 生成概率式粒球/组件。
  • 用 GMM 的均值、协方差与 Mahalanobis distance 表达局部椭球结构。
  • 计算粒球纯度、权重、score，并把它们用于分类过程。
  • 训练中动态调整粒球结构，论文还强调可视化球中心、球大小、球权重随训练变化，以增强解释性。

核心创新点

  • 把传统“球形粒球”升级为 GMM 椭球式概率组件，天然建模协方差结构。
  • 不用简单丢弃低纯度区域，而是用 purity-weighted adjustment 降低不可靠粒球影响。
  • 用 Mahalanobis distance 体现“沿主方向偏离”和“垂直主方向偏离”的差异。
  • 把粒球视为动态解释对象：模型训练过程中的粒球演化可被观察。

对当前 SoftDist 的启发

  • G-GBC 最直接启发了两个方向：椭球化 SoftDist 和 GMM-RespSoftDist。
  • 椭球化 SoftDist：保留当前 hard ball assignment，只在球内用协方差/Mahalanobis 给 train vote 加权。
  • GMM-RespSoftDist：用 responsibility 代替 hard membership，令节点 target 为多个组件 label distribution 的加权和。
  • 当前项目已有实验证明：椭球 offline target 在 Amazon/DBLP/PubMed 有正信号，但 downstream 不稳定；这说明 G-GBC 的机制不能无条件迁移。

当前项目的批判性边界

  • G-GBC 是 CNN 图像分类，且动态训练中更新 GMM/粒球；当前项目多次发现模型反馈和动态硬纠正容易自强化。
  • GMM 不只是“椭球”，还引入 soft assignment、component 数量、协方差估计、EM 初始化和数值稳定性问题。
  • 如果 GMM-RespSoftDist 做实验，必须先 offline diagnostic，且 real 必须优于 shuffled；否则只是复杂化的 H-kNN/cluster smoothing。

3. MgBIF：Like Draws to Like: Multi-granularity Ball-Intra Fusion for Fault Diagnosis under Noisy Labels

Advanced Engineering Informatics 2024fault diagnosispseudo labelDSmT fusionsample selection

核心问题

工业故障诊断依赖高质量标签，但自动标注或低成本标注容易产生噪声。若直接监督训练，错误标签会误导潜在空间的分类边界，导致过拟合和泛化下降。MgBIF 目标是在不知道具体噪声比例的情况下，通过粒球内部信息融合和高置信样本选择提升鲁棒训练。

方法结构

  • 在 latent feature space 中，为每个样本构建专属粒球或邻域粒球。
  • 聚合球内其他样本标签，形成 pseudo-label。
  • 用 DSmT 证据融合思想，将原始标签和球内伪标签融合成 corrected label。
  • 从修正后的数据中选择高置信样本用于监督训练。
  • 根据估计噪声强度调整粒度：噪声越强，粒度更粗，以提升伪标签可靠性；噪声较低时可以使用更细粒度。

核心创新点

  • 把“球内标签分布”与“原标签”作为两个证据源，而不是完全相信其中一个。
  • 把标签修正和样本选择结合：先融合修正，再筛高置信训练。
  • 用噪声强度控制多粒度，而不是固定单一粒度。

与 SoftDist 的关系

  • SoftDist 的公式本质也是“原 noisy one-hot + ball distribution”的软融合，只是用 alpha 控制，而不是 DSmT。
  • MgBIF 支持当前方法的叙事：球内分布可以作为原标签的局部证据源。
  • 但 MgBIF 的高置信硬筛样与当前图实验边界冲突：当前项目已发现强筛样/硬纠正容易造成 clean damage。

不能直接照搬的地方

  • 故障诊断时间序列和图节点分类不同。
  • 它依赖动态训练和样本选择，当前主线是静态 frozen H target。
  • 如果引入“高置信样本”，必须同时报告 NCR/CDR 或 clean damage；不能只看准确率。

4. MgCNL：Sample Separation via Multi-Granularity Balls for Fault Diagnosis with Noisy Labels

IEEE TASE 2025fault diagnosissupervised contrastive learningsample separation

核心问题

工业故障诊断中，专家标注成本高，自动标注含噪。MgCNL 希望在未知噪声比例下，从 noisy dataset 中选出高置信标签样本用于监督学习，避免错误标签误导模型。

方法结构

  • 先用对比学习学习较稳定的 representation。该阶段使用全部样本，但忽略标签信息，以保证模型收敛并避免标签噪声直接干扰表征。
  • 在 learned representation 上构建多粒度粒球。
  • 基于粒球评估标签置信度，动态选择高置信样本进入监督训练。
  • 不需要预先知道噪声比例。

核心创新点

  • 把对比学习作为“表征预热/去标签化阶段”，再用粒球进行标签置信评估。
  • 粒球不直接当正样本标签，而是作为 sample separation 和 confidence estimator。
  • 强调多粒度下的样本置信，而不是单一邻域/单一阈值。

对当前 SoftDist 的启发

  • 它高度支持当前 frozen GRACE H 的设计：先用 label-free contrastive learning 得到 H，再在 H 上构球。
  • 它也支持“粒球的贡献在弱下游更明显”的观察：如果下游本身没有 H 或图传播，粒球 target 能提供更多额外结构。
  • 但它偏 sample selection，而当前 SoftDist 更偏 soft target；当前实验已经表明硬选择/硬纠正不应成为主线。

5. GBD：Research on Classification Label Denoising Algorithm Based on Granular Ball

classification label denoisingpurity thresholdhard filteringsampling

核心问题

传统分类数据存在标签噪声，直接训练会降低分类器准确率。GBD 通过自适应超球覆盖数据空间，移除球外点和球内疑似噪声点，只用去噪后的粒球/采样数据训练分类器。

方法结构

  • 用 self-adaptive hypersphere 覆盖数据空间。
  • 按纯度阈值递归分裂粒球。
  • 删除球外点和球内噪声点。
  • 用去噪后的球数据/采样数据训练 LR、DT 等分类器。

核心创新点

  • 早期明确把粒球用于分类标签去噪。
  • 强调粒球作为压缩、过滤、采样单元，具有 classifier-agnostic 特性。
  • 文中报告无噪声时可小幅提升，有噪声时提升更明显。

对 SoftDist 的意义

  • 它是“粒球用于标签噪声过滤”的基础背景，可用于 related work。
  • 但它偏硬删除/硬采样，和当前 SoftDist 的软混合边界不同。
  • 当前项目不能回到“删点后训练”的主线，因为图节点任务中删除/硬纠正容易破坏 split 和图传播语义。

6. Three-Level Noise-Tolerance Granular-Ball Distinguishing Measures and Feature Subset Selection

IEEE TFS 2026feature selectionfuzzy rough setnoise-tolerant measure

核心问题

传统 fuzzy rough set 特征选择在高聚集区域容易被噪声样本误导，忽略了样本分布和粒度结构。该文献提出三层噪声容忍粒球区分度量，用于特征子集选择。

方法结构

  • 代数层：基于相对距离粒球 fuzzy dependency。
  • 信息论层：基于 variable-precision 粒球 fuzzy entropy。
  • 粒计算层：利用粒球化机制刻画局部结构。
  • 最终以 dependency + conditional entropy 等综合评价候选特征。

核心创新点

  • 把抗噪性定义成可度量的局部区分能力，而不是只做标签投票。
  • 引入 variable precision，承认局部不一致可被容忍。
  • 把粒球的局部结构转成特征选择判别指标。

对 SoftDist 的启发

  • 适合用作 theoretical related work：粒球可作为噪声容忍的局部统计单元。
  • 不建议直接把复杂 fuzzy entropy 公式加入 SoftDist。当前方法优势是简单、静态、可复现。
  • 可启发未来 diagnostic：用“球内结构区分度”判断哪些 ball target 可被信任。

7. 王炳贵硕士论文：多粒度标签噪声过滤学习算法研究

硕士论文SPRDMSPRDGBSmulti-granularity

核心问题

相对密度 RD 是标签噪声检测中的有效思想，但全局 kNN 计算复杂度高，难以扩展到大数据。该论文围绕“如何低成本、多粒度地过滤标签噪声”设计多条路线。

主要方法线

  • SPRD：基于空间划分的快速相对密度，在局部分区内部计算相对密度，降低全局 kNN 搜索成本。
  • MSPRD：多层空间划分相对密度，在多个划分粒度下计算 RD，并通过投票降低单一划分误判。
  • GBS：粒球采样，用粒球边界/采样同时压缩样本、过滤标签噪声并缓解类别不平衡。

核心创新点

  • 多粒度共识优于单粒度判断。
  • 空间划分/粒球压缩能同时服务效率和抗噪。
  • 用投票/集成减少局部划分的不稳定。

对 SoftDist 的启发

  • 当前 SoftDist 固定约 64 个 2-means hard balls，可能过度依赖单一粒度；标签率和大图实验已经说明粒度/coverage 影响很大。
  • 但多粒度投票会引入更多调参，必须有 real-vs-shuffled 与 downstream 验证，否则只是复杂化。
  • 适合作为论文中“多粒度是文献共识，但本文选择最小静态版本”的边界解释。

  • 强调局部一致性不是离散标签专属，也可以转化为连续标签的局部偏离判断。

9. 孙旭硕士论文：Granular Ellipsoid Model and Its Application in Classification Problems

硕士论文 2026granular ellipsoidGECGEB/GED-SMOTEGEAF

核心问题

传统粒球用中心和半径表达局部区域，天然假设局部结构近似球形；面对非球形、不规则或高维局部分布时会损失信息。孙旭论文将粒球扩展为粒椭球，以形状矩阵表达各方向尺度，从而更紧凑、更精确地覆盖数据分布。

三条主线

  • 粒椭球模型与分类器：定义粒椭球数学表达，基于 GBkNN 替换为粒椭球，加入基于粒椭球大小的距离加权，提出 GEC。
  • 粒椭球 + 不平衡分类：优化形状矩阵求解，用协方差矩阵 + 正则项解决高维小样本粒椭球构建不稳定；提出 GEB-SMOTE 与 GED-SMOTE。
  • 粒椭球 + 标签噪声：提出无标签信息、无纯度阈值依赖的自适应粒椭球划分，并进一步提出 GEAF 进行标签噪声过滤与修正。

与当前椭球 SoftDist 的直接关系

  • 当前“椭球化 SoftDist”只借用了最小部分：在已有 hard balls 内估计 H 空间协方差，用 Mahalanobis distance 降低边界/离群 train vote 权重。
  • 孙旭论文中真正的粒椭球划分更彻底：椭球本身是生成/划分对象，而当前项目没有替换 2-means hard balls。
  • 因此当前椭球 SoftDist 的负结果不能否定粒椭球模型本身，只能说明“在当前 hard ball 上加 Mahalanobis 投票权重”下游不稳。

GEAF 第五章要点

  • 现有粒划分依赖纯度阈值和标签信息；在标签噪声下，用错误标签计算纯度会导致错误划分。
  • GEAF 先忽略标签，只用数据分布进行粒椭球自适应划分。
  • 每个局部粒椭球内做多数/一致性修正，把样本标签改为粒椭球标签。
  • GEAF 与全局聚类去噪不同：目标不是一次性找到全局类别簇，而是发现细粒度、内部一致的局部结构。
  • 论文引入 NRR（噪声修正率）与 CSIR（纯净样本损伤率），强调不能只看最终分类精度。
  • 论文也指出高噪声下失败常来自高维低相关、复杂类边界、噪声集中在边界区域。

对当前项目的启发

  • 支持当前使用 NCR/CDR 判断 hard correction 是否伤害干净样本。
  • 支持“椭球在 H 空间聚类程度高、局部线性结构明显的数据上更可能有效”的假设。
  • 但当前 GEAF 桥接实验显示：Coauthor-CS offline 通过但 downstream 低于 SoftDist；AmazonCom seed0 conf=0.7 有正信号但未 5-seed 验证。不能 claim GEAF 已适合图节点任务。

10. 一种稳定的加速自适应粒球生成方法（张清华，CAJ）

CAJaccelerated GB generationadaptive partition需复核

读取状态

该 CAJ 文件的抽取文本不可读。因此本文只使用孙旭论文中对相关方法的转述，细节需后续用 CAJ 阅读器或 OCR 复核。

从孙旭论文可确认的相关思想

  • 加速粒球划分：以全数据为初始粒球，当粒球纯度低于阈值时，从不同类别中选代表性样本作为 k-means 初始质心，并只执行一次 k-means 迭代生成子粒球；最后通过一次全局划分微调球中心，以降低反复迭代开销。
  • 基于加权纯度和的自适应划分：不直接预设纯度阈值，而是比较父粒球纯度与子粒球加权纯度和。若分裂后加权纯度和提升，则保留子粒球并继续递归；否则停止。
  • 局限：即使不手动设置阈值，仍依赖标签纯度来判断分裂是否成立；在标签噪声存在时，纯度本身可能不可靠。

对 SoftDist 的启发

  • 当前 SoftDist 使用固定 max_balls/2-means 结构，未来若重做 ball generation，可考虑“分裂是否真的提升球质量”的自适应准则。
  • 但如果准则依赖 noisy label purity，会和当前 label-noise 目标冲突。
  • 更适合迁移的是“分裂收益诊断”思想，而不是“纯度阈值本身”。

11. SAGBC：Structure-aware Granular Ball Clustering

Information Sciences 2026clusteringsoft affiliation graphdual-constraint connectivitylarge-scale

核心问题

传统粒球聚类面临三个问题：大规模数据上递归分裂成本高；hard partition 把每个点硬分配给一个球，容易制造人工边界；球间连接常只看单一距离准则，忽略底层拓扑连接信息。

方法结构

  • 从全数据中采样 representative subset，用其生成结构感知粒球中心，降低 full-data dependency。
  • 构建基于 Gaussian kernel 的 soft affiliation graph，让每个点可与多个粒球建立非排他关联。
  • 用 dual-constraint connectivity criterion 连接粒球：同时考虑 spatial proximity 和 structural similarity。
  • 最终由粒球连通分量得到 cluster，再通过 soft affiliation graph 把点分配给最强从属的球/簇。

核心创新点

  • 明确从 hard membership 转向 soft affiliation。
  • 把点-球关系和球-球关系拆开：点到多个球的软归属，球之间用空间和结构双约束连接。
  • 在 17 个 synthetic/real-world 数据集和 10 个 baseline 上报告聚类准确率与效率优势。
  • 消融显示去掉 soft affiliation 后，硬分配会导致连通性/边界信息严重损失。

对当前项目的启发

  • 它是对 GMM-RespSoftDist 的最强文献支持之一：问题可能不在“球内怎么投票”，而在“节点为什么只能属于一个 hard ball”。
  • 它也提示可设计 soft affiliation 版 target：节点 target = 多个球 label distribution 的加权和。
  • 但 SAGBC 是无监督聚类，不是 noisy-label node classification；soft affiliation 提升聚类 ACC/NMI 不等于提升 GCN downstream。

可迁移但必须验证的指标

  • max affiliation / affiliation entropy：边界节点是否更高熵。
  • dominant support：主从属球是否有足够 train label support。
  • real-vs-shuffled target quality：软从属是否真的利用 H 几何，而非只做平滑。

12. IMVGCR：Incomplete Multi-view Granular Ball Contrastive Clustering via View Recovery

投稿稿件 2026incomplete multi-view clusteringview recoveryweighted GB contrastive learning

核心问题

不完整多视图聚类中，缺失视图恢复容易导致 latent space 过平滑和类别边界模糊；实例级 contrastive alignment 又会把不稳定重建视图与原始视图强行对齐，引入 feature pollution 和 false negative conflicts。

方法结构

  • 用带 self-attention 的 autoencoder 提取高阶语义并恢复缺失视图。
  • 引入 weighted granular-ball contrastive learning module。
  • 把 fine-grained instances 替换为 coarse-grained granular balls 作为 contrastive anchors。
  • 对真实数据和重建缺失数据赋不同权重；计算 weighted centers 和 weighted radii。
  • 建立 granular ball correlation relationship，用球级关系定义正负关系并计算 weighted contrastive loss。

核心创新点

  • 用球级锚点代替实例级锚点，降低缺失视图恢复噪声。
  • 把粒球引入 deep incomplete multi-view clustering 的 joint optimization。
  • 用 weighted centers/radii 避免重建数据质量不稳定导致球偏移。
  • 论文在 6 个多视图数据集上报告优于 IMVC SOTA，并通过消融证明 weighted granular ball contrastive module 的必要性。

对当前 SoftDist/GB-GCL 的启发

  • 它直接支持“粒球作为 contrastive anchor / weak view relation teacher”的研究定位。
  • 它也解释了为什么 same-ball hard positive 风险大：实例级对比会有 false negatives，球级锚点的价值是降低噪声而不是强行把所有同球点拉近。
  • 对当前项目最可迁移的是“球级结构作为弱教师/软约束”，而不是复制完整多视图恢复框架。

当前项目边界

  • IMVGCR 是聚类和 view recovery，不是 noisy train labels 下的 semi-supervised node classification。
  • 当前项目已多次验证强 positive pulling 不稳，因此不能把它作为直接恢复 GB contrastive loss 的理由。
  • 它更适合 future work：从 SoftDist target 过渡到 “ball-level weak relation teacher”。

七、对 SoftDist / 椭球 / GEAF 的具体映射

可以吸收进论文叙事的文献启发

  • SoftDist 的核心定位：由 GBD/MgBIF/MgCNL/BNO-GB 支持，可写成“粒球将单点 noisy label 转化为局部标签分布证据”。
  • frozen H 的合理性：由 MgCNL/G-GBC/IMVGCR 支持，可写成“先获得较稳定表征，再在表征空间中提取粒度结构”。
  • alpha/confidence 的必要性：由 BNO-GB、MgCNL、GEAF 支持，不能对所有球同等信任。
  • 椭球实验的动机：由 G-GBC 和孙旭论文支持，球形假设可能忽略局部各向异性。
  • GMM/soft affiliation 的动机：由 SAGBC 和 G-GBC 支持，hard membership 可能制造边界错误。
  • 负结果解释：GEAF 和 SAGBC 都提示：高维低聚类、边界复杂、support 不足时，局部多数/局部几何会失效。

  • 不能说“文献证明粒球去噪适合图节点分类”。这是当前项目自己的实验必须证明。

  • 不能说“GEAF 在 UCI 成功，所以当前图实验应硬纠正”。当前 GEAF bridge 只有 AmazonCom seed0 有明显正信号。
  • 不能说“椭球在大图 offline 正信号说明大图更适合椭球”。DBLP/Amazon downstream 已显示不稳定。
  • 不能把 same-ball membership 写成语义正样本。IMVGCR 的球级锚点是降噪，不等价于所有同球点都应强拉近。

八、实验与论文边界：给 GPT 必须知道的约束

不要让 GPT 给出这些错误建议

  • 不要建议直接把 GEAF 硬纠正作为主方法。当前图实验没有稳定支持，且硬纠正容易高 CDR。
  • 不要建议继续无限调椭球参数。当前 evidence 表明 offline target improvement 可能过小或不对齐 downstream。
  • 不要建议把 same-ball node pairs 当强正样本恢复 GB-GCL。历史实验已经多次削弱该方向。
  • 不要建议改变 split 或 baseline evaluation 来制造提升。
  • 不要建议用 clean label 构球、调 alpha 或筛样。clean label 只能用于诊断/评估。
  • 不要把文献中的 UCI/CNN/IMVC/OIC 结果包装成当前图节点任务上的证据。

  • 如果 SoftDist 的主贡献不是 SOTA，而是“轻量、静态、可解释的 local soft target”，论文怎么组织最诚实？
  • 当前文献更支持“软标签”还是“硬纠正”？结合当前实验，哪个方向更能形成可信论文边界？
  • SAGBC/G-GBC 支持 soft membership，但当前项目是否值得做 GMM-RespSoftDist？最小 gate 应该是什么？

  • 椭球文献支持非球形局部结构，但当前 downstream 不稳定，是否应把椭球写成 negative diagnostic 而非主方法？
  • 这些文献如何帮助解释“SoftDist 在 MLP(X) 上更强、在 GCN[X‖H] 上更小”的机制？

九、最重要的 8 条文献结论

  1. 粒球噪声学习的核心不是“投票得硬标签”，而是“局部一致性产生置信证据”。
  2. 最接近 SoftDist 的文献机制是 MgBIF 的原标签 + 球内伪标签融合，以及 MgCNL 的先表征后球置信选样。
  3. 最能解释椭球实验动机的是 G-GBC 和孙旭粒椭球：球形假设弱，协方差结构有价值。
  4. 最能支持 GMM/soft responsibility 的文献是 SAGBC：hard partition 会导致人工边界，点应能关联多个球。
  5. 最能解释 GEAF 当前风险的是 GEAF 自己的局限分析：高维低相关、边界复杂、噪声集中会导致局部多数标签不可靠。
  6. 多粒度是文献共识，但当前项目不能变成无止境粒度调参；必须用 shuffled 和 downstream gate 控制。
  7. 深度表征空间构球有文献支持，因此 frozen GRACE H 是合理选择；raw X-space ball 失败并不否定粒球思想。
  8. 这些文献支持“机制动机”和“related work”，但不能替代当前项目自己的 5-seed、same split、same H、real-vs-shuffled 证据。
