GAGB / GB-GCL 全实验思想包

生成日期：2026-06-02。用途：把到目前为止的 GAGB、GB-GCL、noisy-label local smoothing、target repair、失败模式和研究边界打包给 Claude 思考。本文件是 self-contained 版本，Claude 不需要访问本地代码、CSV、日志或历史文档。

一句话总判断： 当前最有价值的不是“GAGB 已经成功”，而是一个清晰的研究收缩：粒球不能当硬语义标签、不能强改 view generation、不能只追求 compactness；Graph-aware Granular Ball 更合理的定位是 frozen / host classifier 阶段的 soft local prior、soft-label generator、confidence signal 和诊断对象。最新 v2.1 结果显示 target repair 能产生正 NCR 且 CDR 受控，但 GAGB-specific value 只被部分支持，尚未达到主方法 claim。

当前可支持

GAGB 分组能降低 noisy-label entropy、提高局部纯度；conflict-gated target repair 可把 pre-alpha correction signal 转成正 NCR；clean damage 在 v2.1 中保持在 CDR < 0.03。

当前不支持

不能说 GAGB 稳定优于所有 fair controls；不能说 same-ball 是语义真值；不能把小于 std 的 accuracy gain 写成显著提升；不能把 ordinary GB 或 kmeans/topk 也能解释的收益归因给 GAGB。

下一步核心问题

不是继续堆公式，而是验证：GAGB target repair 是否真的优于 intervention-strength-matched shuffled / kmeans / topk / khop controls，并解释 Cora 0.4 的 class 1 / class 6 间接边界移动。

2. 研究目标与角色收缩

最初目标是把 Granular Ball Computing 与 GRACE 或类似节点级图对比学习结合，形成一条可投稿的研一阶段论文主线。多轮实验后，研究角色已经发生收缩：

粒球角色当前判断原因
hard positive label / hard semantic truth放弃same-ball membership 过粗，直接拉近同球节点、prototype pulling、hard positive、hard negative suppression 多次不稳。
view generator / augmentation controller放弃GB 深度介入 view generation 多次低于健康 GRACE，可能破坏原本有效的 augmentation distribution。
pure edge denoise rule放弃主线same/cross-ball membership 命中噪声边弱，容易误伤 clean edges；x-space percentile 更强但不是 GB 贡献。
loss-side conservative prior保留弱主线GB-FN topk-soft 是历史上最安全的 GB+GCL 用法，但 gain 很小、no-ball topk 接近。
local relation regularizer可继续验证RDCL 在 PubMed 有正信号，但需要 fixed / random / shuffled / size-matched partition 控制。
soft-label generator / confidence signal当前 GAGB 主线GAGB v2 target repair 显示局部 q_mix 与 teacher 信号能识别部分 noisy nodes，但仍需证明 GAGB grouping 的独立价值。

3. 历史 GB-GCL 实验链

下面这些方向来自多份 02_experiment_history_and_lessons*.md、03_cross_direction_meta_review.md 和导师汇报的整合。它们不是单个 seed 的印象，而是跨项目复盘后形成的边界。

方向粒球怎么用关键结果结论
GB-guided view generation 用 same-ball / cross-ball 控制删边、特征扰动、view schedule。 active balls 不等于表示变好；长训、decay、freeze、anchor/explore、stronger recovery 后仍多次低于 GRACE。 abandon 负结果可作为 motivation，不能继续作为主线调参。
GB-BGRL / GB-GBT 把 GB view 接入 bootstrap / redundancy reduction objective。 GB-BGRL 不稳定；GB-GBT 稍稳但仍低于 GRACE。换 objective 没修复 GB view mismatch。 abandon 不要用换目标函数修 view-side 失败。
Hard / broad same-ball relation same-ball positive、prototype、direct consistency、full/ratio suppression。 Cora/CiteSeer 未稳定提升，部分下降；GB-PCL 只有 Cora single-seed 正信号。 abandon / inconclusive same-ball 只能是 weak prior。
GB-FN-GRACE topk-soft 只在 loss 中对少量同球、高相似 false negatives 降权。 Cora 约 +0.0014，CiteSeer 约 +0.0010，PubMed 持平；std overlap，no-ball topk 接近。 weak positive 最安全但不是强胜利，必须补 no-ball/candidate overlap 机制证明。
Pure GB edge denoise 同球边保留、跨球边降权或删除。 downweight precision 约 0.5596、recall 约 0.2272；quick val 低于 GRACE。 abandon main method GB 可做 edge scorer feature，但不能当硬规则。
RDCL local relation consistency 用 GB/kmeans 分组构造局部关系一致性正则。 PubMed 3-seed 有 +0.0030 / +0.0025 正信号；random / shuffled 接近主方法。 modify 可继续，但 claim 要降级为 local regularizer，先做 fixed/size-matched controls。
Diagnostics 用粒球分析 purity、candidate precision、edge risk、assignment collapse。 高 protected_precision、高 ball activation、健康 ball count 不等于下游有效；ball-topk 不一定优于 no-ball topk。 keep 诊断必须先于 formal run。

4. Stage A/B/C：为什么转向后处理和 target repair

Stage A：InfoNCE vs negative-free 表示空间诊断

Stage A 比较 GRACE InfoNCE 与 raw negative-free 表征对粒球结构的影响。标签只用于后验诊断，不参与 SSL 训练或构球。

  • raw negative-free 的球半径和平均角距离更小，但 effective rank、feature std、linear eval accuracy 明显变差，说明“紧凑”可能来自表示过压缩。
  • Cora 上 InfoNCE plain 在 Stage-A augmentation 下 acc 约 0.7880、effective rank 约 135.45；negfree plain acc 约 0.3557、effective rank 约 2.215。
  • 加入 BN 后 negative-free 可恢复语义可分性，例如 Cora negfree BN acc 约 0.7910、effective rank 约 131.89，但半径/AD 也变大，紧凑优势消失。
  • 结论：不能只优化 compactness；局部紧凑性必须与全局可分性、anti-collapse、effective rank 一起看。

Stage B：GB compactness 约束与动态刷新

B 组尝试把粒球作为 soft structural constraint 反向约束 encoder。B2 验证“动态刷新粒球 assignment 是否能修复静态 B1 不稳定”。

设置相对 B0 平均 acc 差值acc_ge_b0结论
lambda=0.0005, refresh=50-0.0353 ± 0.12943/6最好也只是持平一半，未过成功标准。
lambda=0.0005, refresh=100-0.0443 ± 0.10462/6仍不稳定。
lambda=0.001, refresh=50-0.1400 ± 0.11800/6明显过强。
lambda=0.001, refresh=100-0.1602 ± 0.12350/6明显过强。

结论：动态刷新不能解决 B1 不稳定；单纯 compactness loss 仍容易牺牲全局语义可分性。后续设计应把粒球放到更弱的位置，例如 frozen embedding 后处理、soft target、confidence weighting，而不是强行训练 encoder。

Stage C：confidence soft relation 计划

C 组计划不是已完成主结果，而是从 B 组负结果导出的设计方案：稳定 encoder baseline、置信度加权 compactness、防塌缩门控、soft ball relation alignment。它的思想后来与 GAGB 的 soft local prior、confidence signal、target repair 方向一致。

5. Noisy-label GB validation：GAGB 前的普通 GB gate

这个阶段的任务是 frozen GRACE embedding 上的 noisy-label node classification。普通 GB 用作 classifier-stage local reliability unit，不参与 GRACE pretraining、view generation、hard positive、hard negative filter 或 split/evaluation 修改。

协议内容
数据集Cora, CiteSeer

noisesymmetric label noise 0.2/0.4
seeds0,1,2,3,4

主要发现：

  • coverage-aware 变体达到 full train-node coverage，但实际 alpha 很小：Cora gb_ca_ce 的 alpha_mean_all_train 约 0.0593-0.0774，CiteSeer 约 0.0560-0.0678。
  • 在 Cora train=0.2 noise=0.4，普通 gb acc 0.7974 ± 0.0054，高于 CE 0.7935 ± 0.0082 和 kmeans 0.7945 ± 0.0062，这是 Cora 局部正信号。
  • 在 CiteSeer 上不稳定：例如 train=0.2 noise=0.2，gb_ca_ce acc 0.7009 ± 0.0129，低于 global 0.7082 ± 0.0055 和 gb_ca_global 0.7093 ± 0.0063。
  • 最终结论：simple confidence-weighted GB smoothing 不能作为主方法；后续必须和 CE/global/kmeans/topk matched 同协议比较。

6. Graph-aware Granular Ball 方法定义

GAGB 的动机是：ordinary GB 只看 embedding-space compactness，不显式使用图拓扑和预测一致性；图节点不是独立样本，局部连通、K-hop/PPR 邻近、teacher prediction consistency 也应参与定义“可靠局部区域”。

形态构球信号标签角色风险
ordinary GBembedding 距离和半径收益无标签构球忽略拓扑和预测一致性。
SGBGC 类connected subgraph + supervised purity threshold强监督 splitnoisy-label 场景有 leakage 风险。
GAGB v1/v2embedding similarity + topology proximity + 后续 teacher/noisy targetnoisy labels 只在构球后弱参与 target必须证明优于 khop/kmeans/topk/shuffled controls。

核心定义

给定 frozen GRACE embedding H、图边 E 和 teacher prediction P，GAGB membership score 可写为：

s(i, B) = lambda_h * s_h(i, B) + lambda_t * s_t(i, B) + lambda_p * s_p(i, B)

s_h(i, B) = (1 + cos(h_i, mu_B)) / 2
s_t(i, B) = topology proximity, e.g. K-hop / PPR proximity to center c_B
s_p(i, B) = 1 - JS(p_i, pbar_B) / log(C)

当前已实现的 v1 更接近 lambda_h=0.7、lambda_t=0.3、lambda_p=0 的 embedding + topology greedy grouping；v2 主要改的是 target construction，而不是构球本身。

target construction 思想

q_B      = ball-level target distribution
q_pred_B = teacher / prediction-informed ball prior
q_mix    = beta * q_label_B + (1 - beta) * q_pred_B

conflict gate:
  edit train node i only if q_mix[noisy_y_i] <= 0.35 and max(q_mix) >= 0.55

old alpha03 update:
  target_i = (1 - alpha_i) * one_hot(noisy_y_i) + alpha_i * q_mix

repair variants:
  alpha09:       use stronger alpha on gated nodes
  replace_qmix:  replace target with q_mix on gated nodes
  margin_replace: replace only if q_mix margin is large enough

clean labels 不参与构球、teacher 训练、target construction 或 classifier training；只用于 diagnostics / evaluation，例如 NCR、CDR、clean purity、per-class failure analysis。

13. GAGB v2.2 / v2.3：Cora 0.4 失败与 class-safe calibration

v2.2 诊断 Cora noise=0.4：为什么 positive NCR 反而 accuracy 不稳或下降。clean labels 仅用于诊断。

  • 失败不是主要由 aggregate CDR 高造成。GAGB alpha09 / replace 的 direct clean damage 主要集中在 class 0，CDR 约 0.0202；但最大 test accuracy drop 是 class 1。
  • class 1 最差：alpha09 vs gb delta -0.0592，replace vs gb delta -0.0868；但 class 1 平均只有约 0.4 gated noisy nodes 和 0.0 gated clean nodes，说明下降大于直接干预 footprint。
  • class 6 也下降，但 GAGB repair 对 class 6 有 0 gated noisy 和 0 gated clean，属于 indirect classifier-boundary movement。
  • khop repair 改动更多 class 且 direct CDR 更高，但某些 class-level accuracy 反而没 GAGB 那么差，这削弱强 GAGB-builder claim。

v2.3 测试 class-safe target calibration：alpha06/07/08、class_capped_alpha09、class_balanced_alpha09、boundary_safe_alpha09、以及 replay random same-count diagnostic。它主要服务于 Cora 0.4 的边界敏感性诊断。

14. 指标定义与判断门槛

指标定义 / 用途注意事项
Accuracy mean/std5 seeds 的 test accuracy at best validation。小于 std 或 seed wins 不稳不能写强 claim。
Paired delta同 split/noise/seed 下 method - baseline。比单纯 mean 更重要。
Clean purity用 clean labels 后验统计球内纯度。只用于诊断，不能作为训练信号。
Noisy-label entropy球内 noisy train label 分布熵。低熵不等于下游有效。
Noise detection AUROC用 suspicion score 区分 noisy / clean train nodes。v1 GAGB AUROC 不稳定优于 ordinary GB。
NCRnoisy train nodes 中 target argmax 被改到 clean label 的比例。clean label 只用于评估；NCR 高但 CDR 高也不可接受。
CDRclean train nodes 中 target argmax 被改错的比例。v2.1 要求 CDR < 0.03 或至少 < 0.05。
Possible before alphaq_mix 在 alpha mixing 前可纠正 noisy node 的比例。解释 old alpha03 为什么 NCR=0。
Lost by alphapre-alpha 可纠正但 convex update 后没改变 argmax 的比例。target repair 的直接动机。
Coverage / alpha stats多少节点被 local target 影响，影响强度多大。coverage 高不等于 GB-specific value。
Class-level diagnostics每类 NCR/CDR/changed/test acc/confusion matrix。用于发现 Cora 0.4 的 indirect boundary movement。

15. 已支持、尚未支持与负结果

实验支持的结论

  • 强行把 GB 用在 view generation、hard positive、hard edge rule 上不可靠。
  • compactness alone 容易与 global separability 冲突。
  • ordinary GB / coverage-aware smoothing 只有弱信号，Cora 局部正向、CiteSeer 不稳。
  • GAGB v1 能产生更纯、低熵局部区域，但不能证明 independent value。
  • v2 conflict gate 能选中高 noisy ratio 节点；old alpha03 是 NCR=0 的主要原因。
  • target repair 能让 NCR 转正且 CDR 受控。

合理但未证明的解释

  • GAGB 的价值可能在 target repair 的 conservative local correction，而不是 grouping purity 本身。
  • Cora 0.4 失败可能来自 target update 对 classifier boundary 的间接扰动。
  • class-capped / boundary-safe update 可能比 replace_qmix 更稳。
  • prediction consistency 和 Q(B) 可能改善 GAGB grouping，但还没被当前 v2 证明。

当前不能写的 claim

  • 不能说 GAGB 显著、稳定优于 GB/kmeans/topk/khop/shuffled。
  • 不能说 GAGB 已经是 paper-ready main method。
  • 不能把 purity/entropy/AUROC 诊断直接等同于下游有效。
  • 不能把 x-space percentile robustness 写成 GB 贡献。
  • 不能用 Cora 单设置或 single-seed 支撑主结论。

16. 当前最稳的论文叙事

保守但可辩护的叙事是：

方法定位：我们不把 granular balls 当作硬语义标签或 view generator，而是定义 graph-aware granular balls 作为 noisy-label node classification 中的 local soft-label and confidence prior。GAGB 结合 frozen representation similarity 和 graph topology proximity，随后通过 teacher-aware target construction 与 conflict gate，只在高冲突节点上进行保守 target repair。

实验定位：历史 GB-GCL 负结果说明强 GB 机制会破坏 GCL；普通 GB local smoothing 只有弱信号；GAGB v1 提供更纯局部区域但独立价值不足；v2 target repair 首次证明 correction signal 可以从 pre-alpha q_mix 转为正 NCR 且 CDR 受控。

claim 边界：当前只支持 mechanism-positive 和 partially method-positive，不支持 strong main method claim。下一步如果 fair controls 和 class-safe calibration 都通过，才可以升级为主方法。

18. 下一步最小实验建议

优先级实验只改什么成功标准失败标准

4 GAGB construction v3 with Q(B) / prediction consistency 只有在 target repair gate 通过后，再加入 Q(B)、prediction consistency 或 PPR。 新增构球机制稳定提升 NCR/AUROC/accuracy，并优于 ordinary GB/kmeans/khop/PPR-only。 若只提升 purity/entropy 而不提升下游或不胜 controls，停止。

项目背景：
- 研究目标是把 Granular Ball Computing 与 GRACE 或类似节点级图对比学习结合，用于研一阶段可投稿论文。
- 多轮历史实验已经否定了强 GB 路线：GB 不适合直接当 view generator、hard positive label、hard negative filter、prototype pulling target、pure edge denoise rule。
- 当前保守定位：GB/GAGB 只作为 soft local prior、soft-label generator、confidence signal、diagnostic object。

历史 GB-GCL 结论：
- GB-guided view generation 多次低于健康 GRACE，应 abandon。
- GB-BGRL / GB-GBT 没有修复 view-target mismatch，应 abandon。
- hard/broad same-ball positive、prototype、direct consistency 不稳，应 abandon 或只作负结果。
- GB-FN topk-soft 是历史上最安全 GB+GCL 形式，但 Cora 约 +0.0014、CiteSeer 约 +0.0010、PubMed 持平，std overlap 且 no-ball topk 接近，所以只能弱 claim。
- pure GB edge denoise 命中弱，downweight precision 约 0.5596、recall 约 0.2272；x-space percentile 更强但不是 GB 贡献。
- RDCL PubMed 有 +0.0030/+0.0025 正信号，但 random/shuffled 控制接近主方法，因此只能说 local relation regularizer 可能有效，不能说语义粒球已证明必要。

Stage A/B 背景：
- raw negative-free SSL 会产生很小粒球半径和 AD，但 effective rank、feature std、linear acc 明显下降，说明 compactness 可能来自过压缩。
- Cora 上 InfoNCE plain acc 约 0.7880、effective rank 约 135.45；negfree plain acc 约 0.3557、effective rank 约 2.215。
- negative-free + BN 可恢复 acc/effective rank，但紧凑优势基本消失。
- Stage B 的 GB compactness 和动态刷新没有解决不稳定：lambda=0.001 动态刷新对 B0 是 0/6 pair 不低于 baseline，lambda=0.0005 最好也只是 3/6。
- 因此后续不再强行反向训练 encoder，而转向 frozen embedding / classifier-stage local target repair。

ordinary GB noisy-label validation：
- 协议：Cora/CiteSeer, train ratio 0.1/0.2, val 0.1, symmetric noise 0.2/0.4, seeds 0-4, frozen GRACE。
- methods: ce, global, kmeans, topk_matched, gb, gb_prior, gb_ca_ce, gb_ca_global。
- coverage-aware variants full coverage，但 alpha 很小，Cora gb_ca_ce alpha_mean_all_train 约 0.0593-0.0774，CiteSeer 约 0.0560-0.0678。
- Cora 有局部正信号，比如 train=0.2 noise=0.4 普通 gb acc 0.7974±0.0054，高于 CE 0.7935±0.0082 和 kmeans 0.7945±0.0062。
- CiteSeer 不稳，比如 train=0.2 noise=0.2 gb_ca_ce 0.7009±0.0129，低于 global 0.7082±0.0055 和 gb_ca_global 0.7093±0.0063。
- 结论：simple confidence-weighted GB smoothing 不能作为主方法。

GAGB 方法定义：
- GAGB = Graph-aware Granular Ball。ordinary GB 只看 embedding-space compactness；GAGB 想结合 frozen GRACE embedding similarity 与 topology proximity，并在 target construction 阶段结合 noisy-label teacher。
- membership score: s(i,B)=lambda_h*s_h + lambda_t*s_t + lambda_p*s_p；当前 v1/v2 实现主要是 lambda_h=0.7, lambda_t=0.3，尚未真正加入 prediction consistency Q(B) 主机制。
- target construction 中，q_mix 融合 noisy local label distribution 与 noisy-label-only teacher prediction。conflict gate 只在 q_mix[noisy_y] <= 0.35 且 max(q_mix) >= 0.55 时修改 train target。
- clean labels 不用于构球、teacher、target、classifier training，只用于 NCR/CDR/purity 等诊断。

GAGB v1 minival：
- 协议：Cora/CiteSeer, train ratio 0.2, val 0.1, noise 0.2/0.4, seeds 0-4, frozen GRACE, alpha 0.3。
- gagb vs ordinary gb paired deltas: CiteSeer 0.2 +0.00034, CiteSeer 0.4 +0.00043, Cora 0.2 +0.00011, Cora 0.4 -0.00232。
- gagb_ca_ce vs gb: CiteSeer 0.2 +0.00069, CiteSeer 0.4 +0.00103, Cora 0.2 +0.00106, Cora 0.4 -0.00211。
- GAGB clean purity 高于 ordinary GB，noisy-label entropy 低于 ordinary GB，但 noise AUROC 不稳定优于 GB；且没有稳定打过 khop_only 和 shuffled controls。
- v1 fair-control patch 加入 emb_only、kmeans_gagb_matched、topk_gagb_matched、gagb_shuffled_alpha_matched。结论：v1 没有通过 independent-value gate。

GAGB v2 target-only：
- 保持 GAGB grouping 不变，只改 target construction：加入 noisy-label-only linear teacher、q_pred、teacher_prior、conflict_gate。
- gagb_qb_conflict_gate vs gb: Cora 0.2 -0.00011, Cora 0.4 -0.00169, CiteSeer 0.2 +0.00747, CiteSeer 0.4 +0.00034。

Gated-node diagnostic：

  CiteSeer 0.4 gated noisy ratio 0.8812, possible before alpha 0.9032, lost by alpha 0.9032。

  Cora 0.4 gated noisy ratio 0.9664, possible before alpha 0.9875, lost by alpha 0.9875。
- 结论：NCR=0 不是 GAGB 没有 correction signal，而是 alpha03 convex update 太弱。

Target repair：
